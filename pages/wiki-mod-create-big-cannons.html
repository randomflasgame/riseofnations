CREATE BIG CANNONS

Create Big Cannons erweitert Create um großkalibrige Artillerie, Geschütze, Munition und technische Systeme für schwere Waffen. Die Mod verbindet die mechanische Welt von Create mit einem umfangreichen Artillerie- und Ballistiksystem.

01 // SYSTEM OVERVIEW

Was ist Create Big Cannons?

Create Big Cannons ist ein auf Create aufbauendes Artilleriesystem. Statt einer einzelnen fertigen Waffe werden Geschütze aus verschiedenen Komponenten aufgebaut.

Dadurch wird Artillerie zu einem technischen Bauprojekt: Rohr, Verschluss, Lafette, Munition und weitere Komponenten müssen gemeinsam geplant werden.

RISE OF NATIONS // ARTILLERY

Große Geschütze sollten als vollständige Waffensysteme betrachtet werden. Die Konstruktion ist genauso wichtig wie die eigentliche Munition.

02 // CREATE FOUNDATION

Voraussetzungen

Da Create Big Cannons stark mit Create verbunden ist, sollte man grundlegende Create-Mechaniken bereits verstehen.

  • Rotation
  • Contraptions
  • Mechanical Power
  • Redstone
  • Automatisierung
  • Item- und Flüssigkeitstransport

Besonders bei größeren Geschützen hilft es, wenn die technische Basis bereits zuverlässig funktioniert.

04 // BARREL ENGINEERING

Geschützrohre

Das Rohr ist eines der wichtigsten Bauteile eines Geschützes. Je nach verwendeter Konstruktion und Munition ergeben sich unterschiedliche Anforderungen.

Planung

Vor dem Bau sollte festgelegt werden, welche Munition das Geschütz verwenden soll. Daraus ergibt sich ein großer Teil der technischen Anforderungen.

Stabilität

Ein großes Geschütz sollte mechanisch sinnvoll aufgebaut werden. Die Lafette muss die Größe und Funktion des Systems berücksichtigen.

05 // AMMUNITION

Munition

Ein wesentlicher Unterschied zu einfachen Minecraft-Waffen ist die Vielzahl an Munitionsarten.

Je nach Geschütz und Version können unterschiedliche Projektiltypen verfügbar sein. Dazu gehören beispielsweise verschiedene Formen von Geschossen und spezielle Munitionsvarianten.

WICHTIG

Die konkrete Munition sollte immer über JEI geprüft werden. Rezeptnamen und verfügbare Varianten können sich zwischen Mod-Versionen unterscheiden.

06 // LOADING SYSTEM

Laden und Vorbereitung

Artillerie funktioniert nur zuverlässig, wenn der Ladevorgang korrekt durchgeführt wird.

Bei größeren Systemen empfiehlt es sich, den Ladeprozess zunächst manuell zu testen und erst danach zu automatisieren.

  1. Geschütz prüfen.
  2. Munition vorbereiten.
  3. Ladesystem prüfen.
  4. Geschütz ausrichten.
  5. Feuerbereitschaft herstellen.
  6. Nach dem Schuss System kontrollieren.
07 // CREATE AUTOMATION

Automatisierte Artillerie

Create ermöglicht es, viele vorbereitende Prozesse rund um die Artillerie zu automatisieren.

  • Materialproduktion
  • Munitionstransport
  • Nachschubsysteme
  • Lagerung
  • Redstone-Steuerung
  • Mechanische Bewegungen

Eine vollständig automatisierte Waffenanlage sollte erst gebaut werden, wenn das Grundsystem manuell zuverlässig funktioniert.

09 // CREATE AERONAUTICS

Integration mit Luftfahrzeugen

In RISE OF NATIONS kann Create Big Cannons gemeinsam mit Create Aeronautics besonders interessant werden.

Dadurch können technische Plattformen entstehen, die Artilleriesysteme mit beweglichen Konstruktionen kombinieren.

SYSTEM INTEGRATION

Komplexe Konstruktionen sollten immer zuerst als einzelne funktionierende Systeme getestet und anschließend miteinander verbunden werden.

10 // BALLISTICS

Ballistik verstehen

Artillerie ist nicht mit einem normalen direkten Minecraft- Angriff vergleichbar. Entfernung, Winkel und Projektilweg können eine wichtige Rolle spielen.

Für größere Entfernungen muss der Spieler daher lernen, Schusswinkel und Zielposition gemeinsam zu betrachten.

Praktisches Vorgehen

  1. Bekannte Entfernung wählen.
  2. Testschuss durchführen.
  3. Einschlag beobachten.
  4. Winkel anpassen.
  5. Erneut testen.
11 // LOGISTICS

Für größere Anlagen sollte deshalb ein eigenes Munitionslager eingerichtet werden.

12 // SAFETY

Sicherer Betrieb

SYSTEM WARNING

Große Waffenanlagen sollten nicht direkt neben wichtigen Produktionsanlagen oder wertvollen Gebäuden getestet werden. Baue zunächst eine kontrollierte Testposition.

Eine separate Testanlage erleichtert außerdem die Entwicklung neuer Geschütze und Munitionssysteme.

13 // TROUBLESHOOTING

Häufige Probleme

Geschütz funktioniert nicht

Prüfe zuerst die Konstruktion, den Verschluss, die Munition und die technische Versorgung.

Munition wird nicht geladen

Kontrolliere die einzelnen Schritte des Ladevorgangs und prüfe die verwendete Munitionsart über JEI.

Schüsse treffen nicht das Ziel

Nutze kontrollierte Testschüsse und verändere den Schusswinkel schrittweise.

Automatisierung funktioniert nicht

Zerlege das System und teste Transport, Redstone und mechanische Komponenten einzeln.

14 // DEVELOPMENT DOCTRINE

Empfohlene Entwicklungsreihenfolge

  1. Einfaches Geschütz bauen.
  2. Manuelles Laden testen.
  3. Erste Testmunition verwenden.
  4. Zielsystem und Ausrichtung testen.
  5. Nachschubsystem bauen.
  6. Geschütz in eine Struktur integrieren.
  7. Erst danach komplexe Automatisierung hinzufügen.
PROFESSOR METHOD

Komplexität sollte immer erst dann erhöht werden, wenn die vorherige technische Stufe stabil funktioniert.

CREATE FACTORY

Create Factory erweitert die industrielle Ausrichtung von Create und konzentriert sich auf automatisierte Fertigung, Verarbeitung und den Aufbau größerer Produktionsanlagen. Im RISE OF NATIONS Modpack passt das System besonders gut zu zentralen Fabriken, Werkstätten und industriellen Versorgungsketten.

01 // SYSTEM OVERVIEW

Was ist Create Factory?

Create Factory ergänzt das Create-Ökosystem um zusätzliche Möglichkeiten für industrielle Produktion und automatisierte Fertigungsabläufe.

Der wichtigste Gedanke ist dabei die Verbindung mehrerer Produktionsschritte zu einer einzigen funktionierenden Fabrik.

FACTORY PRINCIPLE

Eine Fabrik wird nicht durch einzelne Maschinen groß, sondern durch die Verbindung mehrerer Produktionsstufen.

02 // FOUNDATION

Grundlagen

Vor dem Bau komplexer Produktionsanlagen sollten die grundlegenden Create-Systeme beherrscht werden.

  • Mechanische Energie
  • Rotation
  • Stress und Belastung
  • Item-Transport
  • Flüssigkeitssysteme
  • Automatisierte Verarbeitung

JEI sollte dabei als zentrale Referenz für Rezepte und Produktionsketten verwendet werden.

03 // FACTORY ARCHITECTURE

Aufbau einer Fabrik

Eine übersichtliche Fabrik kann in mehrere funktionale Bereiche aufgeteilt werden.

ZONE FUNKTION
RAW MATERIAL Rohstoffe und Eingangsmaterial
PROCESSING Grundverarbeitung
ASSEMBLY Zusammenbau von Zwischenprodukten
FINAL PRODUCTION Herstellung fertiger Produkte
STORAGE Lagerung und Verteilung
04 // PRODUCTION CHAINS

Produktionsketten planen

Der Bau sollte immer vom gewünschten Endprodukt rückwärts geplant werden.

  1. Endprodukt bestimmen.
  2. Benötigtes Rezept mit JEI prüfen.
  3. Zwischenprodukte identifizieren.
  4. Benötigte Rohstoffe bestimmen.
  5. Maschinen auswählen.
  6. Transportwege planen.
  7. Automatisierung aufbauen.
PLANNING RULE

Baue nicht zuerst die Fabrik und überlege danach, was sie produzieren soll. Definiere zuerst das Ziel und konstruiere anschließend die Produktionskette.

05 // POWER SYSTEM

Mechanische Energie

Jede größere Produktionsanlage benötigt eine zuverlässige Energieversorgung.

Bei der Planung beachten

  • Gesamtbelastung der Maschinen prüfen.
  • Antriebsquellen zentral planen.
  • Übertragungswege möglichst übersichtlich halten.
  • Reserve für spätere Erweiterungen einplanen.
POWER WARNING

Eine Produktionslinie sollte nicht dauerhaft ohne Leistungsreserve betrieben werden. Erweiterungen erhöhen die Belastung schnell.

06 // MATERIAL LOGISTICS

Materialtransport

Eine automatisierte Fabrik benötigt einen ebenso gut geplanten Materialfluss.

SYSTEM AUFGABE
INPUT Material in die Fabrik bringen
PROCESSING Material zwischen Maschinen bewegen
BUFFER Produktionsschwankungen abfangen
OUTPUT Fertige Produkte ausgeben

Kleine Puffer zwischen Produktionsstufen können helfen, unterschiedliche Verarbeitungsgeschwindigkeiten auszugleichen.

07 // AUTOMATION

Automatisierung

Eine Produktionsanlage kann schrittweise automatisiert werden.

  1. Manuelle Maschine aufbauen.
  2. Automatischen Input hinzufügen.
  3. Automatischen Output hinzufügen.
  4. Zwischenprodukte automatisch weiterleiten.
  5. Mehrere Produktionsstufen verbinden.

Dadurch kann eine einfache Werkstatt langsam zu einer vollständigen Fabrik wachsen.

08 // MODULAR DESIGN

Modulare Fabriken

Große Anlagen sollten aus einzelnen Modulen bestehen.

  • Schmelzmodul
  • Verarbeitungsmodul
  • Montagemodul
  • Flüssigkeitsmodul
  • Lagerungsmodul
  • Verteilungsmodul

Der Vorteil: Einzelne Produktionsbereiche können verändert werden, ohne die gesamte Anlage neu bauen zu müssen.

09 // STORAGE

Lager und Produktionspuffer

Lagerung ist ein Bestandteil der Fabrik und sollte nicht erst am Ende improvisiert werden.

LAGER FUNKTION
RAW STORAGE Rohstoffe
INTERMEDIATE STORAGE Zwischenprodukte
FINAL STORAGE Fertige Produkte
RESERVE Material für Produktionsspitzen
10 // SCALING

Fabriken vergrößern

Wenn die Produktionsmenge nicht mehr ausreicht, sollte zuerst der eigentliche Engpass gefunden werden.

  1. Produktionsrate messen.
  2. Langsamsten Verarbeitungsschritt identifizieren.
  3. Maschine oder Produktionsstufe erweitern.
  4. Input und Output anpassen.
  5. Mechanische Energie prüfen.
SCALING RULE

Nicht jede Maschine muss vervielfacht werden. Erweitere zuerst die Produktionsstufe, die tatsächlich den Gesamtfluss begrenzt.

11 // INDUSTRIAL NETWORK

Verbindung mit anderen Systemen

Create Factory entfaltet seine Stärke besonders innerhalb eines größeren industriellen Netzwerks.

  • Create für die grundlegende Maschineninfrastruktur
  • Create Diesel Generators für Energie
  • Create New Age für elektrische Systeme
  • Create Ore Excavation für Rohstoffversorgung
  • Create Railways Navigator für Transport
  • Create Encased für zusätzliche Maschinen
  • Create Big Cannons für industrielle Militärproduktion
12 // TROUBLESHOOTING

Fehleranalyse

Produktion steht still

Prüfe zuerst Energieversorgung, Input und das Rezept. Danach sollte der Materialfluss zwischen den einzelnen Maschinen kontrolliert werden.

Material staut sich

Ein Stau deutet häufig darauf hin, dass eine nachfolgende Produktionsstufe langsamer arbeitet oder ihr Lager voll ist.

Produktion ist zu langsam

Suche den langsamsten Schritt der Kette. Dieser bestimmt meistens die maximale Gesamtleistung.

Fabrik wird unübersichtlich

Teile die Anlage in Produktionszonen auf und führe klar definierte Transportwege ein.

13 // ADVANCED FACTORY

Fortgeschrittene Fabrikarchitektur

Eine große industrielle Anlage kann mehrere Ebenen besitzen.

EBENE AUFGABE
RESOURCE Rohstoffbeschaffung
PROCESSING Grundverarbeitung
ASSEMBLY Zusammenbau
MANUFACTURING Endproduktion
DISTRIBUTION Verteilung und Lagerung

Diese Trennung erleichtert sowohl die Wartung als auch spätere Erweiterungen.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

Create Factory sollte als Werkzeug für strukturierte Produktionsketten verstanden werden.

  • Vom Endprodukt rückwärts planen.
  • Produktionsstufen modular aufbauen.
  • Materialfluss sauber organisieren.
  • Mechanische Energie mit Reserve planen.
  • Engpässe statt beliebiger Maschinen erweitern.
  • Fabriken mit Transport und Lagerung verbinden.
FINAL PRINCIPLE

Die stärkste Create-Fabrik ist nicht die größte, sondern diejenige, deren Produktionsfluss vollständig verstanden und kontrolliert wird.

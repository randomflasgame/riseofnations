CREATE LIQUID FUEL

Create Liquid Fuel erweitert die Create-Industrie um zusätzliche Möglichkeiten rund um flüssige Brennstoffe und deren Nutzung. Damit lassen sich Treibstoffproduktion, Flüssigkeitslogistik und industrielle Energieversorgung stärker miteinander verbinden.

01 // SYSTEM OVERVIEW

Was macht Create Liquid Fuel?

Create Liquid Fuel konzentriert sich auf Flüssigtreibstoffe und deren Einbindung in technische Produktionsketten.

Dadurch kann eine Fabrik nicht nur mechanische Energie, sondern auch flüssige Energieträger als Bestandteil ihrer Infrastruktur verwenden.

INDUSTRIAL PRINCIPLE

Treibstoff sollte als Produktionskette betrachtet werden: Rohstoffgewinnung, Verarbeitung, Speicherung, Transport und anschließende Nutzung gehören zusammen.

02 // FLUID SYSTEM

Flüssigkeiten verstehen

Create arbeitet stark mit Fluid-Netzwerken. Flüssigkeiten werden über Tanks, Pipes und Pumpen innerhalb technischer Anlagen bewegt.

  • Flüssigkeitsquelle identifizieren.
  • Produktion oder Verarbeitung planen.
  • Speicher bereitstellen.
  • Pumpen und Leitungen verbinden.
  • Verbraucher an das Netzwerk anschließen.
IMPORTANT

Bei komplexen Fluid-Systemen sollte immer klar sein, welche Flüssigkeit in welchem Abschnitt transportiert wird. Vermischte Leitungen können Produktionsketten unnötig kompliziert machen.

03 // FUEL PRODUCTION

Treibstoffproduktion

Die konkrete Herstellung eines Treibstoffs hängt von den verfügbaren Rezepten der installierten Modversion ab. Verwende deshalb JEI als primäre Referenz für die aktuelle Rezeptkette.

  1. Gewünschten Treibstoff in JEI suchen.
  2. Benötigte Ausgangsflüssigkeiten bestimmen.
  3. Benötigte Rohstoffe identifizieren.
  4. Verarbeitungsstufen aufbauen.
  5. Endprodukt in einem geeigneten Tank lagern.
04 // STORAGE

Treibstoff lagern

Flüssigtreibstoff sollte nicht direkt aus einer Produktionsmaschine in den Verbraucher geleitet werden, wenn die Anlage dauerhaft betrieben werden soll.

Ein Zwischenlager macht die gesamte Infrastruktur stabiler und erleichtert die Wartung.

ZONE FUNKTION
PRODUCTION Treibstoff herstellen
BUFFER Zwischenspeicher
LOGISTICS Transport
CONSUMER Treibstoff verwenden
05 // PUMPING

Pumpen und Leitungen

Eine gute Fluid-Anlage besitzt eine klare Fließrichtung. Pumpen sollten gezielt eingesetzt werden, statt das gesamte Netzwerk unnötig kompliziert zu machen.

Planungsregeln

  • Produktions- und Verbrauchsseite trennen.
  • Leitungen logisch beschriften.
  • Zwischenspeicher einplanen.
  • Wartungszugang offen lassen.
  • Unterschiedliche Flüssigkeiten nicht ohne Grund zusammenführen.
06 // FACTORY INTEGRATION

Integration in Create-Fabriken

Der eigentliche Vorteil entsteht, wenn der Treibstoff nicht als isolierte Maschine betrachtet wird.

Eine vollständige Fabrik kann beispielsweise aus Rohstoffproduktion, Verarbeitung, Lagerung und Transport bestehen.

STUFE INDUSTRIELLE AUFGABE
I Rohstoffe beschaffen
II Ausgangsmaterial verarbeiten
III Treibstoff herstellen
IV Flüssigkeit speichern
V Treibstoff verteilen
07 // LOGISTICS

Flüssigkeitslogistik

Bei großen Fabriken sollte die Fluid-Infrastruktur genauso sorgfältig geplant werden wie Item- und Zuglogistik.

  • Zentrale Treibstoffdepots.
  • Getrennte Produktionsleitungen.
  • Buffer Tanks für Verbrauchsspitzen.
  • Kontrollierte Verteilung an Maschinen.
  • Erweiterbare Leitungswege.
LOGISTICS DOCTRINE

Plane Leitungen so, dass spätere Erweiterungen möglich sind. Eine Fabrik wird meistens größer als ursprünglich geplant.

08 // AUTOMATION

Automatisierte Treibstoffversorgung

Sobald die Produktionskette funktioniert, kann sie mit den Automatisierungssystemen von Create erweitert werden.

  1. Rohstoffe automatisch zuführen.
  2. Verarbeitung kontinuierlich betreiben.
  3. Treibstoff automatisch in Tanks leiten.
  4. Verbraucher dauerhaft versorgen.
  5. Produktionskapazität an den Verbrauch anpassen.
09 // CAPACITY PLANNING

Kapazität berechnen

Eine funktionierende Anlage muss mehr Treibstoff produzieren, als ihre Verbraucher durchschnittlich benötigen.

PARAMETER BEDEUTUNG
INPUT Rohstoffzufuhr
PROCESSING Verarbeitungskapazität
STORAGE Pufferkapazität
OUTPUT Treibstoffproduktion
CONSUMPTION Verbrauch

Wenn der Verbrauch dauerhaft größer als die Produktion ist, wird auch ein großer Tank irgendwann leer.

10 // INDUSTRIAL DESIGN

Eine Treibstoffanlage bauen

Für große Fabriken empfiehlt sich eine klare räumliche Trennung der einzelnen Bereiche.

  • Rohstoffannahme.
  • Verarbeitungsbereich.
  • Tanklager.
  • Pumpenstation.
  • Verteilerbereich.
  • Verbraucher.

Dadurch bleibt die Anlage übersichtlich und kann später leichter erweitert werden.

11 // TROUBLESHOOTING

Fehleranalyse

Kein Treibstoff kommt beim Verbraucher an

Prüfe zuerst Tankinhalt, Leitungsverbindung, Pumpenrichtung und den angeschlossenen Verbraucher.

Tank bleibt leer

Prüfe die Produktionsmaschine und ob tatsächlich die korrekte Flüssigkeit erzeugt wird.

Produktion stoppt

Prüfe die Versorgung mit Rohstoffen, den verfügbaren Platz im Ausgangsbehälter und die mechanische Versorgung der beteiligten Create-Komponenten.

System ist zu kompliziert

Teile die Anlage in kleinere Produktions-, Speicher- und Verteilerabschnitte auf.

12 // ADVANCED SYSTEMS

Fortgeschrittene Infrastruktur

Große industrielle Basen können mehrere Treibstoffnetze besitzen.

  • Separates Hauptdepot.
  • Produktionsdepots.
  • Lokale Buffer Tanks.
  • Verteilerleitungen.
  • Reservekapazität.
PROFESSOR TIP

Ein dezentrales System kann bei großen Fabriken übersichtlicher sein als eine einzige riesige Flüssigkeitsleitung.

13 // JEI WORKFLOW

JEI als Planungswerkzeug

Da das Modpack viele Create-Erweiterungen verwendet, sollte JEI bei jeder neuen Treibstoffanlage geöffnet bleiben.

  1. Treibstoff auswählen.
  2. Rezept anzeigen.
  3. Alle Zwischenprodukte notieren.
  4. Verbraucher prüfen.
  5. Produktionskapazität planen.

So lässt sich vermeiden, dass eine Fabrik gebaut wird, bevor alle benötigten Produktionsstufen bekannt sind.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Treibstoffproduktion als vollständige Produktionskette planen.
  • Flüssigkeiten sauber voneinander trennen.
  • Buffer Tanks für stabile Versorgung einsetzen.
  • Produktionsleistung und Verbrauch vergleichen.
  • Fluid-Leitungen erweiterbar bauen.
  • JEI für die tatsächlichen Rezepte verwenden.
  • Große Anlagen modular aufbauen.
FINAL PRINCIPLE

Eine gute Treibstoffanlage ist nicht die Anlage mit den meisten Tanks, sondern die Anlage, deren Produktion, Speicherung und Verteilung zuverlässig zusammenarbeiten.

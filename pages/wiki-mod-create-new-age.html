01 // SYSTEM OVERVIEW

Was ist Create New Age?

Create New Age erweitert das technische Spektrum von Create um elektrische Systeme. Dadurch können industrielle Anlagen nicht mehr ausschließlich mechanisch gedacht werden.

Das macht die Mod besonders interessant für Spieler, die ihre Fabriken von klassischen mechanischen Maschinen in Richtung moderner Industrie entwickeln möchten.

RISE OF NATIONS // ELECTRICAL AGE

Eine moderne Fabrik kann mechanische und elektrische Systeme kombinieren. Die Stärke liegt nicht darin, eine Technik durch die andere zu ersetzen, sondern beide sinnvoll miteinander zu verbinden.

02 // REQUIREMENTS

Was sollte man vorher können?

Für eine sinnvolle Nutzung sollte das grundlegende Create- System bekannt sein.

  • Mechanical Power
  • Rotation und Geschwindigkeit
  • Stress-System
  • Automatisierung
  • Redstone
  • Produktionsketten

Zusätzlich sollte man verstehen, dass unterschiedliche Energiesysteme nicht automatisch direkt miteinander kompatibel sind.

03 // ELECTRICAL INFRASTRUCTURE

Elektrische Infrastruktur

Eine elektrische Fabrik benötigt eine klare Infrastruktur. Stromerzeugung, Übertragung und Verbrauch sollten getrennt geplant werden.

BEREICH FUNKTION
GENERATION Energie erzeugen
TRANSMISSION Energie übertragen
STORAGE Energie speichern
CONSUMPTION Energie verwenden
04 // POWER GENERATION

Energieerzeugung

Der erste Schritt einer elektrischen Infrastruktur ist eine zuverlässige Energiequelle.

Welche Energiequellen konkret verfügbar sind, hängt von der installierten Version und den jeweiligen Rezepten ab. Für exakte Produktionswerte sollte daher immer JEI verwendet werden.

Planungsgrundsatz

Die Energieproduktion sollte langfristig größer dimensioniert werden als der aktuelle Verbrauch.

So bleibt ausreichend Reserve für neue Maschinen und spätere Erweiterungen.

05 // POWER STORAGE

Energie speichern

Ein Energiesystem wird wesentlich stabiler, wenn Erzeugung und Verbrauch nicht permanent exakt gleich sein müssen.

Speicher können Produktionsspitzen abfangen und ermöglichen eine stabilere Versorgung bei wechselnder Energieproduktion.

IMPORTANT

Prüfe bei jeder Anlage die tatsächliche Kapazität und Leistung des verwendeten Speichers. Werte können je nach Version und Konfiguration abweichen.

07 // INDUSTRIAL DESIGN

Elektrische Fabriken planen

Elektrische Anlagen eignen sich hervorragend für größere Industriegebäude und Kraftwerke.

  • Kraftwerk
  • Transformator- oder Verteilerbereich
  • Energiespeicher
  • Produktionshallen
  • Maschinenräume

Dadurch kann auch die Architektur der Basis die technische Funktion sichtbar machen.

08 // AUTOMATION

Automatisierte Energieproduktion

Eine fortgeschrittene Anlage sollte möglichst wenig manuelle Eingriffe benötigen.

  1. Rohstoffgewinnung automatisieren.
  2. Brennstoff oder Energiequelle bereitstellen.
  3. Energie erzeugen.
  4. Energie speichern.
  5. Energie an Produktionsbereiche verteilen.
  6. Produktionsketten automatisieren.
PROFESSOR METHOD

Baue niemals zuerst das komplette Kraftwerk. Teste Erzeugung, Speicherung und Verbrauch jeweils einzeln.

09 // LOAD MANAGEMENT

Verbrauch überwachen

Eine Fabrik kann problemlos funktionieren, solange ihre Energieversorgung ausreichend dimensioniert ist. Probleme entstehen meistens bei größeren Erweiterungen.

Typische Warnzeichen

  • Maschinen verlieren Leistung.
  • Speicher entladen sich dauerhaft.
  • Energieproduktion läuft permanent am Limit.
  • Neue Maschinen können nicht mehr versorgt werden.

In diesem Fall sollte zuerst die Energieversorgung erweitert werden, bevor weitere Produktionsanlagen gebaut werden.

11 // TROUBLESHOOTING

Fehleranalyse

Keine Energie

Prüfe zuerst die Energiequelle und anschließend die Verbindung zwischen Erzeuger, Speicher und Verbraucher.

System bricht unter Last zusammen

Prüfe Produktionskapazität, Speicher und aktuelle Verbraucher. Ein einzelner zusätzlicher Produktionszweig kann ein kleines Netz stark belasten.

Neue Maschine funktioniert nicht

Prüfe zunächst, welches Energiesystem die Maschine tatsächlich benötigt und ob sie mit der vorhandenen Infrastruktur kompatibel ist.

12 // DEVELOPMENT PATH

Empfohlene Entwicklungsstufen

  1. Erste elektrische Energiequelle bauen.
  2. Kleine Testmaschine anschließen.
  3. Speicher integrieren.
  4. Mehrere Verbraucher verbinden.
  5. Zentrale Energieverteilung aufbauen.
  6. Produktion automatisieren.
  7. Großes industrielles Stromnetz errichten.
13 // RISE OF NATIONS DOCTRINE

Die moderne Industrie

Create New Age eignet sich besonders als Übergang zwischen klassischer mechanischer Industrie und moderner technischer Infrastruktur.

In Verbindung mit Create, Create Diesel Generators, Sophisticated Storage und JEI kann daraus ein vollständiges industrielles Produktionssystem entstehen.

FINAL PRINCIPLE

Plane Energie wie eine echte Infrastruktur: Erzeugung, Reserve, Verteilung und Erweiterbarkeit müssen gemeinsam gedacht werden.

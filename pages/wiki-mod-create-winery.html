CREATE WINERY

Create Winery erweitert Create um eine industrielle Verarbeitung rund um Weinbau, Flüssigkeiten und Getränke. Die Mod verbindet Landwirtschaft mit der technischen Produktionslogik von Create und eignet sich dadurch besonders für automatisierte Lebensmittel- und Getränkeproduktion.

01 // SYSTEM OVERVIEW

Was ist Create Winery?

Create Winery erweitert die industrielle Verarbeitung von Create um eine thematische Produktionskette rund um Weinherstellung und verwandte Produkte.

Dadurch entsteht eine Verbindung zwischen Landwirtschaft, Flüssigkeitsverarbeitung, Lagerung und automatisierter Produktion.

PRODUCTION PRINCIPLE

Die Stärke des Systems liegt nicht nur im Endprodukt, sondern in der vollständigen Kette aus Anbau, Verarbeitung, Flüssigkeitssystem und Lagerung.

02 // AGRICULTURE

Die landwirtschaftliche Grundlage

Jede Produktionskette beginnt mit ihren Ausgangsmaterialien. Für eine Weinproduktion muss deshalb zuerst die landwirtschaftliche Versorgung zuverlässig funktionieren.

  • Benötigte Pflanzen identifizieren.
  • Landwirtschaftliche Fläche vorbereiten.
  • Ernte automatisieren oder regelmäßig durchführen.
  • Rohmaterial sortieren.
  • Material an die Produktionsanlage liefern.
03 // PRODUCTION CHAIN

Produktionskette

Die genaue Verarbeitung sollte immer über JEI geprüft werden, da Rezepte versionsabhängig sein können.

  1. Ausgangsmaterial anbauen.
  2. Ernte sammeln.
  3. Verarbeitung starten.
  4. Flüssigkeitsprodukt erzeugen.
  5. Produkt lagern.
  6. Fertige Waren verteilen.
STUFE FUNKTION
INPUT Landwirtschaftliche Rohstoffe
PROCESSING Verarbeitung
FLUID Flüssiges Zwischen- oder Endprodukt
STORAGE Lagerung
OUTPUT Fertiges Produkt
04 // FLUID LOGISTICS

Flüssigkeiten transportieren

Flüssige Produkte werden innerhalb einer Create-Anlage anders behandelt als normale Items.

  • Geeignete Tanks bereitstellen.
  • Fluid-Leitungen logisch planen.
  • Pumpen gezielt einsetzen.
  • Produktions- und Lagerbereich verbinden.
  • Unterschiedliche Flüssigkeiten getrennt halten.
IMPORTANT

Bei mehreren Flüssigkeitsarten sollte jede Leitung eindeutig zugeordnet werden. Ein sauber geplantes Netzwerk erleichtert spätere Erweiterungen erheblich.

05 // STORAGE

Lagerung und Reifung

Je nach konkretem Produktionssystem können verschiedene Zwischen- und Endprodukte entstehen. Lagerung sollte deshalb von Beginn an eingeplant werden.

BEREICH AUFGABE
RAW STORAGE Rohstoffe lagern
PROCESSING Verarbeitung durchführen
FLUID STORAGE Flüssigkeiten speichern
PRODUCT STORAGE Fertige Produkte lagern
06 // AUTOMATION

Weinproduktion automatisieren

Das System lässt sich besonders gut mit einer automatisierten Create-Fabrik kombinieren.

  1. Landwirtschaftliche Produktion aufbauen.
  2. Ernte automatisch transportieren.
  3. Verarbeitung kontinuierlich betreiben.
  4. Flüssigkeiten automatisch speichern.
  5. Endprodukte zentral sammeln.

Dadurch muss der Spieler nur noch die Produktionsanlage überwachen und gegebenenfalls erweitern.

07 // FACTORY DESIGN

Eine Weinfabrik planen

Eine große Produktionsanlage kann funktional und optisch gleichzeitig als Teil einer Stadt oder eines Industriegebiets gestaltet werden.

  • Weinberge oder Anbauflächen.
  • Rohstoffannahme.
  • Verarbeitungsgebäude.
  • Tankbereich.
  • Lagerhallen.
  • Abfüll- oder Versandbereich.
BUILDING PRINCIPLE

Produktionsgebäude sollten einen klaren Materialfluss besitzen: Rohstoff kommt hinein, Verarbeitung findet statt, fertige Ware verlässt das Gebäude.

08 // LOGISTICS

Transport und Versand

Eine automatisierte Getränkefabrik benötigt sowohl Flüssigkeits- als auch Item-Logistik.

TRANSPORT VERWENDUNG
ITEM LOGISTICS Rohstoffe und Behälter
FLUID LOGISTICS Flüssige Produkte
TRAIN LOGISTICS Große Warenmengen
PLAYER TRANSPORT Manuelle Versorgung
09 // MULTIPLAYER ECONOMY

Produktion für den Serverhandel

Getränke und Lebensmittel eignen sich hervorragend als Handelsprodukte, weil sie regelmäßig konsumiert werden können.

  • Produktion für Spielerhandel.
  • Versorgung von Städten.
  • Restaurants und Tavernen beliefern.
  • Handelslager betreiben.
  • Große Mengen über Züge transportieren.

Zusammen mit einem Wirtschaftssystem wie Create Numismatics kann daraus eine eigene Produktions- und Handelsbranche entstehen.

10 // QUALITY CONTROL

Produktionsqualität

Bei einer großen Fabrik sollte nicht nur die Produktionsrate betrachtet werden. Auch der Materialfluss muss zuverlässig sein.

  • Input regelmäßig überprüfen.
  • Produktionsmaschinen nicht unnötig überlasten.
  • Ausgangslager ausreichend dimensionieren.
  • Flüssigkeitstanks überwachen.
  • Transportwege kurz und logisch halten.
11 // TROUBLESHOOTING

Fehleranalyse

Rohstoffe fehlen

Prüfe zunächst die landwirtschaftliche Produktion und anschließend den Transport zur Fabrik.

Flüssigkeit wird nicht weitergeleitet

Prüfe Tank, Leitungen, Pumpen und die Verbindung zum Verbraucher.

Produktion stoppt

Kontrolliere Input, Output und gegebenenfalls die mechanische Versorgung der Maschine.

Lager läuft voll

Erhöhe den Verbrauch, erweitere den Speicher oder reduziere die Produktionsrate.

12 // EXPANSION

Von der Farm zur Großproduktion

Eine kleine Produktionslinie kann später zu einer vollständigen industriellen Anlage ausgebaut werden.

  1. Kleine Anbaufläche.
  2. Manuelle Verarbeitung.
  3. Automatisierte Produktion.
  4. Großes Rohstofflager.
  5. Mehrere Produktionslinien.
  6. Zentrales Tanklager.
  7. Automatischer Versand.

14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Landwirtschaft als Rohstoffbasis betrachten.
  • Produktionsketten vollständig planen.
  • Flüssigkeiten sauber lagern und transportieren.
  • Automatisierung möglichst früh einsetzen.
  • Produktionsgebäude modular aufbauen.
  • Überschüsse für Handel und Lager nutzen.
  • JEI für konkrete Rezepte verwenden.
FINAL PRINCIPLE

Eine gute Getränkefabrik verbindet Landwirtschaft, Verarbeitung, Flüssigkeitslogistik und Handel zu einem einzigen funktionierenden Produktionssystem.

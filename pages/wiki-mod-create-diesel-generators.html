CREATE DIESEL GENERATORS

Create Diesel Generators erweitert das Create-Universum um dieselbasierte Energieerzeugung. Die Mod ist besonders für industrielle Anlagen interessant, bei denen große Produktionsketten zuverlässig mit Energie versorgt werden müssen.

01 // SYSTEM OVERVIEW

Was macht die Mod?

Create Diesel Generators führt dieselbasierte Generatoren und die dazugehörige Infrastruktur in das Create-System ein.

Dadurch entsteht eine weitere Möglichkeit, mechanische Energie innerhalb einer industriellen Anlage bereitzustellen. Besonders große Fabriken profitieren von einer zentral geplanten Energieversorgung.

RISE OF NATIONS // POWER GRID

Energie sollte in einer großen Basis wie eine eigene Infrastruktur behandelt werden. Produktionsmaschinen benötigen eine stabile und planbare Versorgung.

02 // CREATE FOUNDATION

Grundlagen

Die wichtigste Voraussetzung ist ein solides Verständnis des Create-Energiesystems.

  • Rotation und Geschwindigkeit
  • Stress und Belastung
  • Wellen und Zahnräder
  • Getriebe und Übersetzungen
  • Mechanische Energieübertragung

Der Generator ist nicht nur ein einzelner Block. Seine Leistung muss anschließend sinnvoll im gesamten Fabriknetz verteilt werden.

03 // FUEL SYSTEM

Brennstoffversorgung

Ein Dieselgenerator benötigt einen geeigneten Brennstoff. Deshalb sollte die Energieproduktion immer gemeinsam mit einem Brennstofflager geplant werden.

BEREICH FUNKTION
FUEL PRODUCTION Herstellung des benötigten Brennstoffs
FUEL STORAGE Zwischenlagerung
GENERATOR Energieerzeugung
POWER NETWORK Verteilung der erzeugten Energie
04 // GENERATOR INSTALLATION

Generator richtig einsetzen

Ein Generator sollte möglichst dort stehen, wo er sinnvoll in das industrielle Netzwerk eingebunden werden kann.

Empfohlener Aufbau

  1. Brennstoffversorgung vorbereiten.
  2. Generator aufstellen.
  3. Mechanische Verbindung herstellen.
  4. Geschwindigkeit und Belastung prüfen.
  5. Produktionsmaschinen anschließen.
  6. Gesamtsystem unter Last testen.
05 // STRESS MANAGEMENT

Stress und Leistung

Bei Create ist die erzeugte Energie nicht automatisch unbegrenzt verfügbar. Maschinen verbrauchen Belastbarkeit innerhalb des mechanischen Systems.

Wenn mehr Maschinen angeschlossen werden, steigt die Belastung. Deshalb sollte ein Fabriknetz regelmäßig geprüft und bei Bedarf erweitert werden.

IMPORTANT

Ein Generator, der im Leerlauf ausreichend erscheint, kann unter maximaler Produktionslast zu klein sein.

06 // POWER DISTRIBUTION

Energie im Fabriknetz verteilen

Große Produktionsanlagen sollten nicht als ein einziger riesiger Maschinenblock betrachtet werden.

Sinnvoller ist eine Aufteilung in mehrere Produktionsbereiche.

  • Rohstoffverarbeitung
  • Metallverarbeitung
  • Lebensmittelproduktion
  • Logistik
  • Schwere Industrie
  • Forschung und Spezialmaschinen

So lässt sich später leichter feststellen, welcher Bereich zusätzliche Leistung benötigt.

07 // CREATE INTEGRATION

Zusammenspiel mit Create

Die Stärke der Mod entsteht vor allem durch ihre Kombination mit den restlichen Create-Systemen.

08 // INDUSTRIAL ARCHITECTURE

Eine echte Industrieanlage planen

Für große Basen lohnt sich ein eigener Energiebezirk.

  • Generatorhalle
  • Brennstofflager
  • Wartungsbereich
  • Hauptübertragung
  • Produktionshallen
  • Notversorgung

Dadurch entsteht nicht nur eine funktionierende Maschine, sondern eine glaubwürdige industrielle Infrastruktur.

09 // AUTOMATION

Automatisierte Energieversorgung

Der nächste Entwicklungsschritt besteht darin, den Brennstoffkreislauf möglichst weit zu automatisieren.

  1. Rohstoffe automatisch zuführen.
  2. Brennstoff produzieren.
  3. Brennstoff lagern.
  4. Generator automatisch versorgen.
  5. Produktionsnetz überwachen.
PROFESSOR METHOD

Automatisiere zuerst die Versorgung. Erst danach lohnt sich eine komplexe zentrale Steuerung.

10 // FAILURE ANALYSIS

Wenn die Fabrik ausfällt

Generator läuft nicht

Prüfe Brennstoffversorgung, Generatorzustand und die mechanische Verbindung zum restlichen System.

Maschinen stoppen

Prüfe, ob das gesamte System unter zu hoher Belastung steht und ob die Energieübertragung korrekt aufgebaut wurde.

Brennstoff geht zu schnell aus

Prüfe Produktionsrate und Verbrauch. Ein großes Fabriknetz kann deutlich mehr Brennstoff benötigen als eine kleine Testanlage.

11 // EXPANSION

Wann sollte man erweitern?

Ein bestehendes System sollte erweitert werden, wenn die Produktionsanlagen regelmäßig an ihre Leistungsgrenzen stoßen oder zusätzliche Fabrikbereiche geplant werden.

Statt einen einzelnen Generator immer weiter zu belasten, kann eine modulare Energieinfrastruktur langfristig einfacher zu verwalten sein.

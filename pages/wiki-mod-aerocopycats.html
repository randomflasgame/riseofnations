AEROCOPYCATS

AeroCopycats erweitert das Copycats-Prinzip in Richtung der luftfahrt- und technikorientierten Create-Erweiterungen. Der Fokus liegt dabei auf der visuellen und konstruktiven Integration individueller Bauteile in technische Anlagen.

01 // SYSTEM OVERVIEW

Was ist AeroCopycats?

AeroCopycats gehört zum technischen Umfeld von Create und erweitert die Möglichkeiten, individuelle Formen und technische Bauteile in Create-orientierte Konstruktionen einzubauen.

Der große Vorteil solcher Systeme liegt darin, dass eine technische Maschine nicht nur funktionieren, sondern auch exakt an das Design des Projekts angepasst werden kann.

ENGINEERING PRINCIPLE

Funktion und Optik müssen nicht getrennt betrachtet werden. Ein gut geplantes Create-System kann gleichzeitig mechanisch funktional und architektonisch überzeugend sein.

02 // COPYCAT CONCEPT

Das Copycats-Prinzip

Copycat-Systeme erlauben es, die Form beziehungsweise das äußere Erscheinungsbild bestimmter technischer Bauteile an andere Baumaterialien anzupassen.

Dadurch können Maschinen besser in Fabriken, Fahrzeuge, Gebäude und dekorative Anlagen integriert werden.

OHNE COPYCAT MIT COPYCAT-SYSTEM
Standard-Maschinenoptik Anpassbares Erscheinungsbild
Technik steht sichtbar hervor Technik kann integriert werden
Weniger Designmöglichkeiten Mehr architektonische Freiheit
03 // AERONAUTICS

Luftfahrt und technische Formen

Bei Fluggeräten und Luftfahrtanlagen spielt die äußere Form eine besonders große Rolle. Gerade bei Tragflächen, Verkleidungen, Rumpfbereichen oder technischen Einbauten können angepasste Formen einen großen Unterschied machen.

  • Flugzeughallen gestalten.
  • Technische Außenverkleidungen erstellen.
  • Maschinen optisch in Gebäude integrieren.
  • Industrielle Innenräume aufwerten.
  • Fahrzeug- und Flugzeugprojekte detaillierter gestalten.
04 // INDUSTRIAL DESIGN

Industrielle Anwendung

AeroCopycats ist besonders interessant für große technische Bauwerke, bei denen viele Maschinen nebeneinander stehen.

Fabriken

Maschinen können farblich und materiell an die Fabrikarchitektur angepasst werden.

Werkstätten

Technische Arbeitsbereiche erhalten ein einheitliches Materialdesign.

Fahrzeughallen

Mechanische Komponenten können optisch in Hangars und Wartungsanlagen integriert werden.

06 // FACTORY ARCHITECTURE

Fabriken glaubwürdig bauen

Eine hochwertige Create-Fabrik besteht nicht nur aus Maschinen. Sie benötigt eine klare räumliche Struktur.

  1. Hauptgebäude errichten.
  2. Produktionslinien festlegen.
  3. Maschinen positionieren.
  4. Transportwege definieren.
  5. Technische Komponenten verkleiden.
  6. Wartungsbereiche ergänzen.
  7. Beleuchtung und Sicherheitsbereiche hinzufügen.
07 // VEHICLE DESIGN

08 // DETAIL LEVEL

Detailplanung

Copycat-Bauteile sollten nicht wahllos verwendet werden. Zu viele kleine Details können eine Konstruktion unübersichtlich machen.

Eine gute technische Anlage besitzt eine Hierarchie:

  • Große Gebäudestruktur.
  • Große Maschinen.
  • Transportwege.
  • Mittlere technische Elemente.
  • Kleine Details.
  • Beleuchtung und Beschilderung.
09 // MULTIPLAYER

Multiplayer-Anwendung

Auf einem Server können unterschiedliche Spieler dieselbe technische Grundtechnik mit unterschiedlichen Materialien und Designsprachen verwenden.

Dadurch können beispielsweise verschiedene Firmen, Städte oder Spielergruppen einen eigenen industriellen Baustil entwickeln.

NATIONAL DESIGN

Da die Nationen in RISE OF NATIONS dynamisch durch die Spieler entstehen, können unterschiedliche Baugruppen ihre eigene visuelle Identität entwickeln, ohne dass eine feste Nation vorgegeben wird.

10 // PERFORMANCE

Performance

AeroCopycats ist primär ein Bau- und Gestaltungssystem. Trotzdem sollten große Konstruktionen grundsätzlich mit Bedacht geplant werden.

  • Extrem große Maschinenanlagen vermeiden.
  • Unnötige technische Animationen reduzieren.
  • Große Projekte modular aufbauen.
  • Bei Serverproblemen aktive Create-Systeme prüfen.
11 // TROUBLESHOOTING

Fehleranalyse

Bauteil sieht nicht wie erwartet aus

Zuerst prüfen, welches Material tatsächlich kopiert beziehungsweise dargestellt wird und ob das gewünschte Bauteil vom jeweiligen Copycat-System unterstützt wird.

Probleme mit Create-Komponenten

Bei Fehlern immer zuerst prüfen, ob Create und die dazugehörigen Erweiterungen auf kompatiblen Versionen installiert sind.

Darstellungsfehler

Bei ungewöhnlicher Darstellung kann ein Client- oder Rendererproblem vorliegen. In diesem Fall sollten Shader, Ressourcenpakete und weitere visuelle Mods testweise überprüft werden.

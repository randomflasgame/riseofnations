01 // SYSTEM OVERVIEW

Was ist Create Better Villagers?

Create Better Villagers ergänzt das Create-Ökosystem um Mechaniken rund um Dörfer und Dorfbewohner.

Dadurch können Dörfer stärker als Bestandteil einer industriellen oder wirtschaftlichen Infrastruktur betrachtet werden.

CORE PRINCIPLE

Dorfbewohner sind nicht nur NPCs. In einer automatisierten Welt können sie Arbeitskräfte, Händler und wichtige Bestandteile einer Siedlung sein.

02 // VILLAGE ECONOMY

Dörfer als Wirtschaftssystem

Ein gut aufgebautes Dorf kann mehrere Funktionen gleichzeitig erfüllen.

  • Handelszentrum.
  • Wohngebiet.
  • Arbeitsstandort.
  • Versorgungszentrum.
  • Ausgangspunkt für industrielle Projekte.
03 // INDUSTRIAL INTEGRATION

Dorf und Fabrik verbinden

Besonders interessant wird die Kombination mit Create, wenn ein Dorf in die umliegende Industrie eingebunden wird.

  1. Dorfzentrum bestimmen.
  2. Arbeitsbereiche identifizieren.
  3. Industrie außerhalb des Wohnbereichs errichten.
  4. Transportwege planen.
  5. Lager und Handelsbereiche verbinden.
04 // WORKSTATIONS

Arbeitsplätze organisieren

Bei größeren Siedlungen sollte die Position von Arbeitsplätzen bewusst geplant werden.

BEREICH FUNKTION
RESIDENTIAL Wohnbereich
COMMERCIAL Handel
INDUSTRIAL Produktion
AGRICULTURAL Landwirtschaft
LOGISTICS Lager und Transport
05 // VILLAGE DESIGN

Ein funktionierendes Dorf bauen

Ein gutes Dorf sollte nicht nur schön aussehen, sondern auch logisch aufgebaut sein.

  • Wohnbereiche zentral oder geschützt.
  • Handel gut erreichbar.
  • Landwirtschaft am Rand.
  • Industrie außerhalb dichter Wohngebiete.
  • Klare Straßen und Wege.
  • Ausreichende Beleuchtung.
06 // AUTOMATION

Create und Dorfsysteme

Create kann verwendet werden, um die Infrastruktur rund um ein Dorf zu automatisieren.

  • Rohstofftransport.
  • Lebensmittelproduktion.
  • Lagerung.
  • Verarbeitung.
  • Transport zwischen Produktionsstandorten.
DESIGN PRINCIPLE

Automatisiere möglichst die Versorgung der Siedlung, statt jede einzelne Aufgabe direkt am Wohnort zu erledigen.

07 // TRADING

Handel

Dorfbewohner können wichtige Handelsoptionen bereitstellen. Für größere Projekte sollte deshalb ein eigener Handelsbereich eingeplant werden.

  • Händler zentral sammeln.
  • Arbeitsplätze sauber organisieren.
  • Handelsbereich schützen.
  • Wichtige Handelsangebote dokumentieren.
  • Versorgung und Zugang sicherstellen.
08 // SECURITY

Sicherheit für Dörfer

Ein großes Dorf mit wertvollen Handelsmöglichkeiten sollte entsprechend geschützt werden.

  • Beleuchtung.
  • Kontrollierte Zugänge.
  • Geschützte Händlerbereiche.
  • Ausreichende Verteidigung.
  • Abstand zu gefährlichen Industrieanlagen.
SECURITY WARNING

Maschinen, gefährliche Produktionsanlagen und Wohnbereiche sollten möglichst klar voneinander getrennt werden.

09 // MULTIPLAYER

Dörfer als gemeinsame Infrastruktur

Auf einem Multiplayer-Server können Dörfer als neutrale wirtschaftliche Zentren dienen.

  • Handelsplätze.
  • Gemeinsame Versorgung.
  • Spielerwohnungen.
  • Industriegebiete.
  • Transportknoten.
COMMUNITY APPLICATION

Ein gemeinsam aufgebautes Dorf kann sich zu einem wichtigen sozialen und wirtschaftlichen Mittelpunkt des Servers entwickeln.

10 // MOD SYNERGY

Zusammenspiel mit anderen Mods

Create Better Villagers kann besonders gut mit den anderen Siedlungs- und Wirtschaftssystemen des Modpacks kombiniert werden.

  • Create für Automation.
  • Guard Villagers für stärkere Dorfverteidigung.
  • Farmer’s Delight für Lebensmittelversorgung.
  • Waystones für Reiseverbindungen.
  • Macaw’s-Serie für Stadtarchitektur.
  • Lightman’s Currency für Wirtschaftssysteme.
  • Open Parties and Claims für Gebietsverwaltung.
11 // EXPANSION

Vom Dorf zur Stadt

Ein bestehendes Dorf kann als Kern einer größeren Stadtentwicklung verwendet werden.

  1. Dorfzentrum sichern.
  2. Wohngebiete erweitern.
  3. Handelszentrum ausbauen.
  4. Landwirtschaft organisieren.
  5. Industriegebiet außerhalb errichten.
  6. Straßen und Transportwege ergänzen.
  7. Stadt mit weiteren Standorten verbinden.
12 // TROUBLESHOOTING

Fehleranalyse

Dorfbewohner arbeiten nicht wie erwartet

Prüfe zunächst Arbeitsplatz, Umgebung und die Zuordnung des jeweiligen Dorfbewohners.

Dorf wirkt chaotisch

Trenne Wohn-, Handels-, Landwirtschafts- und Industriebereiche räumlich voneinander.

Industrie stört das Dorf

Verlege Maschinen, Lager und laute Produktionsanlagen in ein separates Industrieviertel.

Handel ist schwer zugänglich

Richte einen zentralen Marktplatz beziehungsweise Handelsbereich mit klaren Wegen ein.

13 // RISE OF NATIONS APPLICATION

Einsatz im Modpack

Create Better Villagers passt hervorragend zu einer Welt, in der Städte, Handel, Industrie und Spielerprojekte miteinander verbunden werden.

  • Städtische Handelszentren.
  • Industrielle Randgebiete.
  • Landwirtschaftliche Gemeinden.
  • Versorgungsdörfer.
  • Spielerstädte.
  • Gemeinsame Wirtschaftszentren.
14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Dörfer können Teil einer größeren Industrie sein.
  • Handel sollte zentral und geschützt organisiert werden.
  • Wohn- und Industriegebiete sollten getrennt werden.
  • Create eignet sich für die Versorgung und Logistik rund um Dörfer.
  • Ein kleines Dorf kann zum Kern einer vollständigen Stadt werden.
  • Im Multiplayer können Dörfer wichtige neutrale Wirtschaftszentren sein.
FINAL PRINCIPLE

Plane ein Dorf nicht nur als Ansammlung von Häusern. Plane es als funktionierende Siedlung mit Wohnraum, Arbeit, Handel, Versorgung, Logistik und Schutz.

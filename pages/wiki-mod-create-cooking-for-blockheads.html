CREATE + COOKING FOR BLOCKHEADS

Cooking for Blockheads organisiert das Kochen und die Lebensmittelverwaltung in Minecraft. In Kombination mit Create und Farmer’s Delight entsteht eine besonders praktische Grundlage für industrielle Küchen, Kantinen, Restaurants und automatisierte Lebensmittelproduktion.

01 // SYSTEM OVERVIEW

Was ist Cooking for Blockheads?

Cooking for Blockheads verbessert die Organisation rund um das Kochen. Statt jedes Rezept einzeln auswendig zu kennen, kann der Spieler verfügbare Zutaten und mögliche Gerichte übersichtlich verwalten.

Das macht den Mod besonders interessant für Modpacks mit vielen zusätzlichen Lebensmitteln und Rezepten.

CORE PRINCIPLE

Cooking for Blockheads ist vor allem ein Organisations- und Kochsystem. Die eigentliche Produktion kann anschließend durch Farmer’s Delight, Create und weitere Food-Mods erweitert werden.

02 // KITCHEN SYSTEM

Die Küche als zentrales System

Das Konzept von Cooking for Blockheads basiert auf einer vernetzten Küche. Verschiedene Küchenblöcke arbeiten zusammen und ermöglichen einen wesentlich komfortableren Zugriff auf Zutaten und Rezepte.

  • Cooking Table.
  • Cooking Oven.
  • Tool Rack.
  • Fridge.
  • Sink.
  • Verbundene Kücheninventare.

Die genaue Verfügbarkeit einzelner Funktionen hängt von der installierten Version und den unterstützten Rezepten ab.

03 // RECIPE MANAGEMENT

04 // FARMER'S DELIGHT

Zusammenspiel mit Farmer’s Delight

In RISE OF NATIONS ist Farmer’s Delight besonders relevant, weil das Mod zahlreiche neue Zutaten, Kochprozesse und Gerichte bereitstellt.

Cooking for Blockheads kann dabei helfen, diese große Anzahl an Rezepten übersichtlicher zugänglich zu machen.

  • Gemüse und Feldfrüchte.
  • Fleisch und tierische Produkte.
  • Verarbeitete Zutaten.
  • Komplexere Gerichte.
  • Küchenorganisation.
05 // CREATE INTEGRATION

Create und industrielle Küche

Create bringt Maschinen, Transport und Automatisierung in das Lebensmittelsystem. Dadurch kann eine Küche weit über simples Hand-Crafting hinausgehen.

Eine mögliche Produktionskette sieht beispielsweise so aus:

  1. Feldfrüchte anbauen.
  2. Rohstoffe ernten.
  3. Material transportieren.
  4. Zutaten verarbeiten.
  5. Gerichte herstellen.
  6. Fertige Nahrung lagern.
  7. Produkte an Spieler oder Einrichtungen verteilen.

07 // STORAGE

Lagerung und Zutaten

Eine gute Küche benötigt nicht nur Kochblöcke, sondern auch ein durchdachtes Lagersystem.

  • Frische Zutaten.
  • Verarbeitete Zutaten.
  • Gewürze und Hilfsmittel.
  • Fertige Mahlzeiten.
  • Reservebestände.

Für große Fabriken empfiehlt sich die Kombination aus Cooking for Blockheads und einem größeren Lager- bzw. Transportsystem.

08 // CREATE LOGISTICS

Materialtransport

Create kann die Lebensmittelproduktion mit mechanischem Transport verbinden.

  • Förderbänder für Zutaten.
  • Funnels für Ein- und Ausgabe.
  • Chutes für vertikalen Transport.
  • Depots für Zwischenstationen.
  • Storage-Systeme für Rohstoffe.
DESIGN TIP

Die eigentliche Küche sollte möglichst kompakt bleiben. Große Transportwege können außerhalb des Küchenbereichs organisiert werden.

11 // SURVIVAL

Überleben und Ernährung

In einem großen Modpack gibt es häufig deutlich mehr Nahrung als im Vanilla-Spiel. Eine zentrale Küche hilft dabei, den Überblick zu behalten.

  • Grundnahrung dauerhaft verfügbar halten.
  • Komplexe Mahlzeiten gezielt vorbereiten.
  • Zutatenbestände kontrollieren.
  • Landwirtschaft mit der Küche verbinden.
12 // TROUBLESHOOTING

Fehleranalyse

Ein Rezept erscheint nicht

Zuerst prüfen, ob das Rezept tatsächlich vom jeweiligen Mod registriert wird und ob alle benötigten Zutaten verfügbar sind.

Zutat wird nicht erkannt

Bei Modpack-Rezepten kann es Unterschiede zwischen ähnlichen Items geben. JEI verwenden, um das tatsächliche Rezept zu kontrollieren.

Küche funktioniert nicht vollständig

Alle erforderlichen Küchenkomponenten überprüfen und sicherstellen, dass sie korrekt miteinander verbunden sind.

Nach einem Mod-Update fehlen Rezepte

Die betroffenen Food-Mods und deren Integrationen überprüfen.

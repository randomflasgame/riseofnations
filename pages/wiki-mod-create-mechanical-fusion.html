CREATE MECHANICAL FUSION

Create Mechanical Fusion erweitert die Create-Technologie um zusätzliche mechanische Produktionsprozesse und fortgeschrittene Verarbeitung. Die Mod eignet sich vor allem für Spieler, die komplexe industrielle Produktionsketten aufbauen möchten.

01 // SYSTEM OVERVIEW

Was ist Create Mechanical Fusion?

Create Mechanical Fusion ist eine Erweiterung innerhalb des Create-Ökosystems. Der Schwerpunkt liegt auf zusätzlichen technischen Produktionsmöglichkeiten und komplexeren Verarbeitungsketten.

Für RISE OF NATIONS ist die Mod vor allem dann interessant, wenn die normale Create-Industrie bereits verstanden wurde und eine Fabrik weiter ausgebaut werden soll.

PROGRESSION PRINCIPLE

Fortgeschrittene Create-Addons sollten nicht als einzelne Maschinen betrachtet werden. Ihr größter Nutzen entsteht innerhalb einer bereits geplanten Produktionskette.

02 // CREATE FOUNDATION

Grundlagen von Create

Vor der Nutzung komplexerer Create-Erweiterungen sollten die wichtigsten Create-Grundlagen beherrscht werden.

  • Rotation und Drehzahl.
  • Stress und Belastung.
  • Wellen und Zahnräder.
  • Belts und Item-Transport.
  • Funnels und Inventarzugriff.
  • Flüssigkeitssysteme.
  • Automatisierte Produktionsketten.

Wer diese Systeme beherrscht, kann die zusätzlichen Mechaniken deutlich leichter in bestehende Fabriken integrieren.

03 // PRODUCTION CHAINS

Produktionsketten planen

Bei komplexen Rezepten ist die wichtigste Fähigkeit nicht das Craften einzelner Maschinen, sondern die Planung der gesamten Produktionskette.

  1. Endprodukt bestimmen.
  2. Rezept in JEI öffnen.
  3. Zwischenprodukte identifizieren.
  4. Rohstoffquellen bestimmen.
  5. Maschinen und Verarbeitung planen.
  6. Transportwege festlegen.
  7. Endprodukt automatisiert erzeugen.
04 // MECHANICAL INFRASTRUCTURE

Mechanische Infrastruktur

Eine große Create-Fabrik benötigt eine zuverlässige mechanische Basis.

SYSTEM FUNKTION

LOGISTICS Material transportieren

05 // JEI RESEARCH

JEI richtig verwenden

Bei einer umfangreichen Mod wie RISE OF NATIONS sollte JEI als technische Datenbank betrachtet werden.

Empfohlener Ablauf

  1. Gewünschten Gegenstand suchen.
  2. Rezept öffnen.
  3. Alle Zwischenprodukte untersuchen.
  4. Alternative Rezepte vergleichen.
  5. Benötigte Maschinen notieren.
RESEARCH DOCTRINE

Wenn ein Rezept unbekannt ist, nicht blind ausprobieren. Erst die vollständige Produktionskette untersuchen und anschließend die Fabrik bauen.

06 // AUTOMATION

Automatisierung

Der wichtigste Einsatzbereich von Create Mechanical Fusion liegt in automatisierten Produktionsketten.

  • Rohstoffe automatisch zuführen.
  • Verarbeitungsschritte verbinden.
  • Zwischenprodukte transportieren.
  • Flüssigkeiten automatisiert bereitstellen.
  • Endprodukte automatisch lagern.

Eine gute Anlage benötigt dabei möglichst wenige manuelle Eingriffe.

07 // FACTORY ARCHITECTURE

Fabriken modular bauen

Komplexe Produktionsanlagen sollten in einzelne Module aufgeteilt werden.

MODUL AUFGABE
RAW MATERIAL Rohstoffe empfangen
PROCESSING Material verarbeiten
ASSEMBLY Komponenten herstellen
QUALITY / BUFFER Produkte puffern
OUTPUT Fertige Produkte lagern
08 // STRESS MANAGEMENT

Stress und Leistung

Wie bei anderen Create-Anlagen müssen mechanische Systeme hinsichtlich ihrer Belastung geplant werden.

  • Produktion nicht unnötig überdimensionieren.
  • Große Maschinenparks sinnvoll aufteilen.
  • Drehzahlen an die tatsächliche Aufgabe anpassen.
  • Mechanische Engpässe früh erkennen.
COMMON ERROR

Mehr Maschinen bedeuten nicht automatisch mehr Produktionsleistung. Die mechanische Versorgung kann selbst zum Engpass werden.

09 // MATERIAL FLOW

Materialfluss

Jeder Produktionsschritt sollte einen klaren Input und Output besitzen.

  1. Input definieren.
  2. Verarbeitung durchführen.
  3. Output automatisch weiterleiten.
  4. Zwischenlager nur dort einsetzen, wo es sinnvoll ist.
  5. Endprodukt zentral sammeln.

Dadurch lässt sich eine Anlage leichter erweitern und Fehler lassen sich schneller finden.

10 // ADVANCED INDUSTRY

Fortgeschrittene Industrie

Sobald mehrere Create-Erweiterungen kombiniert werden, entsteht ein echtes industrielles Netzwerk.

  • Create für die mechanische Basis.
  • Create Diesel Generators für industrielle Energie.
  • Create New Age für elektrische Systeme.
  • Create Ore Excavation für Rohstoffversorgung.
  • Create Railways Navigator für Transport.
  • Create Factory für zusätzliche Produktionsmöglichkeiten.

Dadurch kann aus einzelnen Maschinen eine vollständige industrielle Infrastruktur entstehen.

11 // TROUBLESHOOTING

Fehleranalyse

Das Rezept funktioniert nicht

Prüfe zuerst die exakte JEI-Anzeige und ob alle benötigten Voraussetzungen vorhanden sind.

Die Maschine produziert nichts

Prüfe Energieversorgung, Input, Output, mechanische Verbindung und gegebenenfalls Flüssigkeitsversorgung.

Die Anlage ist zu langsam

Untersuche zunächst den tatsächlichen Engpass. Häufig ist nicht die letzte Maschine das Problem, sondern die Rohstoffzufuhr oder der Transport.

Die Fabrik ist unübersichtlich

Teile sie in Produktionsmodule und beschrifte die wichtigsten Leitungen und Lagerbereiche.

12 // OPTIMIZATION

Produktionsoptimierung

Eine optimale Anlage produziert nicht einfach maximal, sondern passend zum tatsächlichen Bedarf.

PROBLEM LÖSUNG
Input fehlt Rohstoffversorgung erhöhen
Output überläuft Lager oder Verbrauch erhöhen
Mechanischer Engpass Antrieb optimieren
Transport langsam Logistik verbessern
Unnötige Produktion Produktionsrate reduzieren
13 // MULTIPLAYER INDUSTRY

Gemeinsame Fabriken

Im Multiplayer kann eine komplexe Create-Anlage auf mehrere Spieler verteilt werden.

  • Spieler A betreibt Rohstoffgewinnung.
  • Spieler B betreibt Verarbeitung.
  • Spieler C betreibt Logistik.
  • Spieler D betreibt Endproduktion.

Dadurch wird die Fabrik zu einem gemeinsamen wirtschaftlichen Projekt statt zu einer Einzelspieler-Anlage.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Create-Grundlagen zuerst beherrschen.
  • Rezepte vollständig analysieren.
  • Produktionsketten modular planen.
  • Materialfluss und mechanische Versorgung trennen.
  • Engpässe statt Symptome beheben.
  • Automatisierung vor manueller Produktion bevorzugen.
  • JEI als technische Datenbank verwenden.
FINAL PRINCIPLE

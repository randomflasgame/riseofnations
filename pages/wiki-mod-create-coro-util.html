COROUTIL

CoroUtil ist eine technische Bibliothek, die von verschiedenen Minecraft-Mods als gemeinsame Grundlage verwendet wird. Im RISE-OF-NATIONS-Modpack ist sie vor allem als Abhängigkeit und technische Infrastruktur relevant und weniger als eigenständiger Content-Mod.

01 // SYSTEM OVERVIEW

Was ist CoroUtil?

CoroUtil ist eine gemeinsam verwendbare technische Bibliothek. Solche Bibliotheken stellen Funktionen bereit, die andere Mods nicht jedes Mal selbst implementieren müssen.

Für den normalen Spieler bedeutet das: CoroUtil ist normalerweise kein Mod, den man aktiv spielt. Seine Bedeutung liegt darin, dass andere Mods seine bereitgestellten Systeme verwenden können.

CORE PRINCIPLE

CoroUtil ist Infrastruktur. Wenn ein anderer Mod davon abhängt, muss die Bibliothek vorhanden sein, damit dieser Mod korrekt funktionieren kann.

02 // LIBRARY ROLE

Warum gibt es solche Libraries?

Viele komplexere Mods benötigen ähnliche technische Funktionen: Entitäten, Bewegungslogik, KI, Wettereffekte, Hilfsfunktionen oder gemeinsame Datenstrukturen.

Eine Library verhindert, dass jeder Mod diese Systeme komplett neu entwickeln muss.

  • Gemeinsame technische Funktionen.
  • Wiederverwendbarer Code.
  • Gemeinsame Entity-Systeme.
  • Hilfsfunktionen für andere Mods.
  • Reduzierung von doppelter Implementierung.
03 // DEPENDENCIES

Abhängigkeiten verstehen

Wenn Minecraft beim Start meldet, dass eine Library fehlt, bedeutet das meistens nicht, dass die Library selbst ein Problem verursacht. Vielmehr benötigt ein anderer Mod ihre Funktionen.

04 // PLAYER EXPERIENCE

Was merkt der Spieler davon?

In einem stabil laufenden Modpack meistens: nichts.

Das ist bei Libraries sogar ein gutes Zeichen. Die technische Infrastruktur soll im Hintergrund funktionieren, während der eigentliche Content-Mod die sichtbaren Funktionen liefert.

FIELD NOTE

Eine Library muss nicht viele eigene Items oder Blöcke besitzen, um für das gesamte Modpack wichtig zu sein.

05 // ENTITY INFRASTRUCTURE

Technische Entity-Funktionen

CoroUtil gehört zum technischen Umfeld von Mods, die komplexe Entitäten und Weltinteraktionen verwenden. Solche Bibliotheken können beispielsweise gemeinsame Logik für Entitäten und Simulationen bereitstellen.

Welche konkrete Funktion im Einzelfall genutzt wird, hängt vom jeweiligen abhängigen Mod ab.

06 // MODPACK ARCHITECTURE

Position im Modpack

RISE OF NATIONS enthält viele Mods, die wiederum weitere Libraries und APIs benötigen. Dadurch entsteht eine Abhängigkeitsstruktur.

  1. Minecraft stellt die Spielwelt bereit.
  2. NeoForge stellt die Modding-Plattform bereit.
  3. Libraries stellen gemeinsame Funktionen bereit.
  4. Content-Mods verwenden diese Funktionen.
  5. Das Modpack verbindet alle Systeme.
07 // INSTALLATION

Installation

Wenn CoroUtil Bestandteil des Modpacks ist, sollte die Version aus dem Modpack verwendet werden.

  • Nicht einfach eine beliebige Version austauschen.
  • Auf Minecraft-Version achten.
  • Auf Loader-Kompatibilität achten.
  • Abhängigkeiten anderer Mods berücksichtigen.
CAUTION

Bei einem bestehenden Modpack sollte eine Library nicht ohne Grund aktualisiert werden. Eine scheinbar kleine Versionsänderung kann Abhängigkeiten inkompatibel machen.

09 // TROUBLESHOOTING

Fehleranalyse

„Missing dependency“

Prüfen, ob CoroUtil tatsächlich im Mods-Ordner vorhanden ist und zur verwendeten Minecraft-Version passt.

Minecraft startet nicht mehr nach einem Update

Die zuletzt geänderten Mods identifizieren. Besonders wichtig sind Libraries, die von mehreren Mods gemeinsam verwendet werden.

Nur ein bestimmter Mod funktioniert nicht

Prüfen, ob dieser Mod CoroUtil benötigt und ob seine erwartete Library-Version installiert ist.

Mehrere Versionen derselben Library

Doppelte oder widersprüchliche Library-Dateien können zu unerwartetem Verhalten führen. Der Mods-Ordner sollte auf überflüssige Versionen kontrolliert werden.

10 // UPDATE STRATEGY

Wie man Libraries aktualisiert

Libraries sollten möglichst zusammen mit dem Modpack und den abhängigen Mods aktualisiert werden.

  1. Modpack sichern.
  2. Abhängigkeiten prüfen.
  3. Library-Version kontrollieren.
  4. Betroffene Mods prüfen.
  5. Testwelt starten.
  6. Server separat testen.
11 // MULTIPLAYER

Serverbetrieb

Auf einem Multiplayer-Server muss die benötigte Library ebenfalls auf der entsprechenden Seite vorhanden sein, sofern der abhängige Mod dies verlangt.

Client und Server sollten grundsätzlich dieselbe Modpack-Konfiguration verwenden, wenn ein Mod dies voraussetzt.

SERVER DOCTRINE

Wenn ein Server nach einer Änderung plötzlich nicht mehr startet, zuerst die zuletzt geänderten Mods und deren Dependencies prüfen.

12 // PERFORMANCE

Performance

Eine Library wie CoroUtil ist nicht automatisch ein Performance-Mod. Ihre Aufgabe besteht primär darin, technische Funktionen für andere Mods bereitzustellen.

Ob ein abhängiger Mod Leistung kostet, hängt daher vom jeweiligen Mod und dessen Nutzung ab und nicht allein von der Existenz der Library.

13 // COMMON MISTAKES

Häufige Fehler

  • Library mit einem Content-Mod verwechseln.
  • Beliebige Version installieren.
  • Abhängigkeiten ignorieren.
  • Mehrere Versionen gleichzeitig im Mods-Ordner behalten.
  • Eine funktionierende Modpack-Version ohne Backup austauschen.
14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • CoroUtil ist eine technische Library.
  • Sie stellt Funktionen für andere Mods bereit.
  • Der Spieler muss sie normalerweise nicht direkt bedienen.
  • Die korrekte Version ist für abhängige Mods wichtig.
  • Libraries sollten nicht wahllos aktualisiert werden.
  • Bei Startfehlern zuerst Abhängigkeiten überprüfen.
FINAL PRINCIPLE

Wenn eine Library ihren Job richtig macht, bemerkst du sie meistens gar nicht. Genau das ist bei technischer Infrastruktur gewollt.

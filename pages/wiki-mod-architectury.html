ARCHITECTURY

Eine zentrale technische Bibliothek innerhalb von RISE OF NATIONS. Architectury stellt gemeinsame Programmierschnittstellen bereit und ermöglicht es Mod-Entwicklern, bestimmte Funktionen über verschiedene Mod-Loader hinweg einheitlich umzusetzen.

01 // ÜBERSICHT

Architectury ist kein klassischer Content-Mod, der dem Spieler neue Waffen, Blöcke, Dimensionen oder Maschinen zur Verfügung stellt. Stattdessen handelt es sich um eine technische Grundlage für andere Mods.

Die Bibliothek abstrahiert bestimmte Minecraft-Funktionen und stellt Entwicklern eine gemeinsame API zur Verfügung. Dadurch können Mods leichter für unterschiedliche technische Umgebungen entwickelt und gewartet werden.

WICHTIG: Wenn Architectury installiert ist, bedeutet das nicht automatisch, dass der Spieler neue Inhalte oder ein eigenes Benutzerinterface erhält. Die wichtigste Funktion der Mod liegt im Hintergrund.

02 // WARUM IST ARCHITECTURY INSTALLIERT?

In einem großen Modpack wie RISE OF NATIONS werden zahlreiche Mods gleichzeitig geladen. Viele davon benötigen Bibliotheken, damit ihre eigenen Funktionen korrekt ausgeführt werden können.

Architectury kann dabei als gemeinsame technische Schicht dienen. Wenn ein installierter Mod Architectury voraussetzt, muss die Bibliothek ebenfalls vorhanden sein.

Grundprinzip:

Content-Mod → benötigt technische API → Architectury stellt diese Schnittstelle bereit → der eigentliche Content-Mod funktioniert.

04 // API-KONZEPT

Eine API ist eine definierte Programmierschnittstelle. Sie beschreibt, wie unterschiedliche Software-Komponenten miteinander kommunizieren können.

Für Mod-Entwickler ist das besonders wichtig, weil Minecraft-Mods teilweise auf unterschiedliche technische Plattformen und Loader ausgerichtet sind.

Architectury stellt dafür abstrahierte Funktionen bereit. Entwickler können dadurch bestimmte Aufgaben über eine gemeinsame Schnittstelle ansprechen, statt jede Implementierung komplett getrennt behandeln zu müssen.

05 // WAS MERKT DER SPIELER?

Normalerweise sehr wenig. Das ist bei einer Bibliothek ein gutes Zeichen.

Wenn ein anderer Mod Architectury benötigt und dieser korrekt geladen wurde, arbeitet die Bibliothek im Hintergrund. Der Spieler verwendet anschließend hauptsächlich die Funktionen des Mods, der Architectury voraussetzt.

MERKSATZ: Architectury ist Infrastruktur. Der sichtbare Inhalt stammt in der Regel von einem anderen Mod.

06 // ABHÄNGIGKEITEN

Bibliotheken sind besonders wichtig für die Mod-Abhängigkeiten. Entfernt man eine benötigte Library, kann der eigentliche Content-Mod nicht mehr starten.

Deshalb sollte Architectury nicht einfach aus dem Mod-Ordner gelöscht werden, nur weil keine eigenen Blöcke oder Items sichtbar sind.

ACHTUNG: Das Entfernen einer Bibliothek kann dazu führen, dass ein oder mehrere andere Mods beim Start einen Dependency-Fehler melden.

07 // CLIENT ODER SERVER?

Ob eine bestimmte Architectury-Komponente auf Client oder Server benötigt wird, hängt von den Mods ab, die sie verwenden.

In einem Multiplayer-Modpack sollte daher nicht automatisch davon ausgegangen werden, dass eine Library nur auf dem Client installiert werden darf.

Situation Vorgehen
Client startet nicht wegen fehlender Library Installierte Abhängigkeiten prüfen
Server meldet Dependency-Fehler Server-Modliste mit Client-Anforderungen vergleichen
Mod verlangt Architectury Passende Version der Library verwenden

08 // VERSION 13.0.11

Im RISE OF NATIONS Modpack wird Architectury in der Version 13.0.11 eingesetzt.

Da Libraries Bestandteil der technischen Mod-Abhängigkeitskette sind, sollte die verwendete Version zur Minecraft-Version und zu den abhängigen Mods passen.

VERSIONSDISZIPLIN: Nicht einfach irgendeine neuere Architectury-Version installieren. Bei Bibliotheken kann eine Versionsänderung Auswirkungen auf mehrere andere Mods haben.

09 // FEHLERBEHEBUNG

Spiel startet überhaupt nicht

Zuerst den Log nach Begriffen wie architectury, dependency, missing oder incompatible durchsuchen.

Fehlende Abhängigkeit

Wenn Minecraft meldet, dass Architectury fehlt, muss die passende Version in den entsprechenden Mod-Ordner installiert werden.

Versionskonflikt

Bei einer Meldung über eine inkompatible Version sollte nicht blind aktualisiert werden. Zuerst feststellen, welcher andere Mod die konkrete Architectury-Version erwartet.

Client funktioniert, Server nicht

In diesem Fall die Abhängigkeiten auf beiden Seiten vergleichen. Besonders bei einem umfangreichen Modpack kann eine einzelne fehlende Library den Serverstart verhindern.

10 // ARCHITECTURY UND MODPACK-PFLEGE

Bei großen Modpacks sollte eine Library wie Architectury möglichst zentral verwaltet werden.

  1. Aktuell installierte Version dokumentieren.
  2. Abhängige Mods identifizieren.
  3. Änderungen zuerst in einer Testinstallation prüfen.
  4. Client und Server auf Kompatibilität kontrollieren.
  5. Erst danach die produktive Modpack-Version aktualisieren.

11 // PERFORMANCE

Architectury ist keine klassische Performance-Mod. Die Library ist in erster Linie eine technische Grundlage für andere Mods.

Wenn bei einem Modpack Performance-Probleme auftreten, sollte daher nicht automatisch Architectury als Ursache angenommen werden. Zuerst sollte festgestellt werden, welcher eigentliche Content- oder System-Mod die betreffende Funktion verwendet.

12 // HÄUFIGE FEHLER

„Architectury macht nichts.“

Das ist bei einer Library normal. Ihre Aufgabe besteht darin, anderen Mods technische Funktionen zur Verfügung zu stellen.

„Ich kann Architectury löschen, weil ich keine Items sehe.“

Nein. Andere Mods können Architectury als Abhängigkeit benötigen.

„Ich habe einfach die neueste Version installiert.“

Das kann bei Libraries zu Versionskonflikten führen. Entscheidend ist die Kompatibilität mit dem gesamten Modpack.

13 // TIPPS FÜR RISE OF NATIONS

  • Architectury nicht ohne Grund aus dem Modpack entfernen.
  • Die Version 13.0.11 dokumentiert lassen.
  • Bei Dependency-Fehlern zuerst die Fehlermeldung lesen.
  • Bibliotheken nicht unabhängig vom restlichen Modpack aktualisieren.
  • Client und Server bei Änderungen gemeinsam testen.
  • Bei einem Crash nach einem Mod-Update auch die Libraries prüfen.

14 // FAQ

Brauche ich Architectury als Spieler?

Wenn ein installierter Mod die Library benötigt: ja. Sie muss dann einfach vorhanden sein. Eine zusätzliche Bedienung ist normalerweise nicht erforderlich.

Gibt es ein eigenes Architectury-Menü?

Architectury ist primär eine technische Bibliothek und kein eigenständiger Content-Mod.

Kann Architectury einfach gelöscht werden?

Nur wenn nachweislich kein anderer installierter Mod davon abhängig ist. In einem großen Modpack sollte das nicht ohne Prüfung erfolgen.

Ist Architectury ein Performance-Mod?

Nein. Die Hauptaufgabe ist die Bereitstellung gemeinsamer APIs und technischer Abstraktionen.

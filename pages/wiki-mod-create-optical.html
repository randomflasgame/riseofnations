01 // SYSTEM OVERVIEW

Was ist Create Optical?

Create Optical erweitert das industrielle Create-Ökosystem um optische Elemente und Systeme.

Damit können technische Bereiche einer Fabrik nicht nur funktional, sondern auch visuell und infrastrukturell detaillierter dargestellt werden.

RISE OF NATIONS // OPTICAL SYSTEMS

Licht kann in einer Industrieanlage als Beleuchtung, Orientierung, Anzeige oder Bestandteil einer technischen Konstruktion eingesetzt werden.

02 // CORE CONCEPT

Die Idee hinter optischen Systemen

Optische Systeme unterscheiden sich von normalen Beleuchtungsblöcken dadurch, dass sie stärker in technische Konstruktionen integriert werden können.

  • Industriebeleuchtung
  • Maschinenbereiche
  • Kontrollräume
  • Fabrikfassaden
  • Signalbereiche
  • Dekorative technische Anlagen
03 // FACTORY LIGHTING

Beleuchtung für Industrieanlagen

Große Fabriken profitieren von einer klar geplanten Beleuchtungsstruktur.

BEREICH EMPFOHLENE FUNKTION
PRODUCTION FLOOR Arbeitsbereich sichtbar halten
MACHINE ROOM Maschinen und Wartungsbereiche hervorheben
CONTROL ROOM Technische Atmosphäre und Orientierung
STORAGE Lagerbereiche übersichtlich halten
04 // TECHNICAL DESIGN

Optische Systeme in Create-Anlagen

Create lebt stark von sichtbaren Maschinen, beweglichen Komponenten und technischen Konstruktionen.

Optische Elemente können diese Konstruktionen hervorheben, ohne den eigentlichen Produktionsfluss zu verändern.

Besonders geeignet

  • Große Produktionshallen
  • Kraftwerke
  • Bahnhöfe
  • Fabriktürme
  • Werkstätten
  • Militärische Industrieanlagen
05 // SIGNALING

Signale und Orientierung

Beleuchtung kann innerhalb einer großen Basis auch als Orientierungssystem verwendet werden.

Unterschiedliche Bereiche können beispielsweise durch unterschiedliche Beleuchtungsstärken oder Positionen erkennbar gemacht werden.

COMMAND CENTER PRINCIPLE

Gute Beleuchtung sollte nicht nur schön aussehen. Sie sollte dem Spieler helfen, sich in einer großen technischen Anlage zurechtzufinden.

06 // INDUSTRIAL ARCHITECTURE

Integration in Gebäude

Optische Systeme wirken besonders überzeugend, wenn sie bereits beim Bau eines Gebäudes eingeplant werden.

  1. Hauptgebäude festlegen.
  2. Produktionsbereiche bestimmen.
  3. Maschinen positionieren.
  4. Kabel-, Rohr- und Transportwege planen.
  5. Beleuchtung entlang dieser Infrastruktur platzieren.
  6. Kontroll- und Wartungsbereiche hervorheben.

08 // RAILWAY APPLICATIONS

Bahnhöfe und Transport

Eisenbahnanlagen sind besonders gut für technische Beleuchtung geeignet.

  • Bahnsteige
  • Bahnhofshallen
  • Signalanlagen
  • Wartungshallen
  • Güterterminals
  • Lokomotivdepots

Zusammen mit Create-Trains kann daraus eine glaubwürdige industrielle Verkehrsinfrastruktur entstehen.

09 // NIGHT OPERATIONS

Nachtbetrieb

Besonders große Basen verändern sich bei Nacht vollständig. Eine geplante Beleuchtung kann Produktionsanlagen auch bei schlechten Sichtbedingungen deutlich erkennbar machen.

Für RISE OF NATIONS eignet sich das besonders für Häfen, Fabriken, Militärbasen, Bahnhöfe und Industriegebiete.

DESIGN WARNING

Zu viel Licht kann eine industrielle Szene schnell überladen. Hauptbereiche sollten stärker beleuchtet sein als Nebenbereiche.

10 // PERFORMANCE

Beleuchtung und Performance

Große Basen können aus hunderten technischen und dekorativen Blöcken bestehen. Deshalb sollte Beleuchtung nicht wahllos überall eingesetzt werden.

  • Wichtige Bereiche priorisieren.
  • Wiederholende Beleuchtung sinnvoll gruppieren.
  • Unnötige Lichtquellen vermeiden.
  • Große Anlagen zuerst testen.

Bei Performance-Problemen sollte die gesamte Beleuchtungs- und Dekorationsstruktur überprüft werden.

11 // BUILDING DOCTRINE

Professionelle Fabrikgestaltung

Eine überzeugende technische Anlage besteht nicht nur aus Maschinen. Auch Beleuchtung, Wartungswege, Lagerbereiche, Kontrollräume und Verkehrswege tragen zur Glaubwürdigkeit bei.

  1. Funktion des Gebäudes bestimmen.
  2. Maschinenlayout planen.
  3. Transportwege definieren.
  4. Beleuchtungsbereiche festlegen.
  5. Technische Details ergänzen.
  6. Gesamtanlage bei Tag und Nacht prüfen.
12 // COMMON MISTAKES

Häufige Fehler

Alles gleich hell beleuchten

Dadurch verschwinden Hierarchien innerhalb eines Gebäudes. Hauptbereiche sollten visuell stärker hervorgehoben werden.

Nur dekorativ bauen

Optische Elemente wirken am besten, wenn sie mit einer tatsächlichen Funktion oder einem technischen Bereich verbunden sind.

Beleuchtung erst ganz am Ende planen

Bei großen Anlagen kann nachträgliche Beleuchtung unnötige Umbauten verursachen. Besser ist es, die Lichtplanung frühzeitig einzubeziehen.

14 // FINAL KNOWLEDGE

Was sollte man sich merken?

Create Optical ist weniger eine einzelne Produktionsmod als vielmehr eine Erweiterung für technische und optische Infrastruktur innerhalb des Create-Ökosystems.

  • Optische Systeme frühzeitig einplanen.
  • Beleuchtung funktional einsetzen.
  • Hauptbereiche visuell hervorheben.
  • Große Create-Anlagen mit Licht strukturieren.
  • Nachtbetrieb bei der Planung berücksichtigen.
  • Performance bei großen Projekten beobachten.

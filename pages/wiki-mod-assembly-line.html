ASSEMBLY LINE

Assembly Line erweitert das industrielle Spielprinzip um stärker strukturierte Produktionsabläufe. Statt einzelne Gegenstände isoliert herzustellen, wird die Produktion als zusammenhängende Fertigungskette betrachtet.

01 // SYSTEM OVERVIEW

Was ist Assembly Line?

Assembly-Line-Systeme bilden industrielle Fertigung nach. Rohstoffe werden nicht einfach an einer einzigen Maschine verarbeitet, sondern durchlaufen mehrere Produktionsstufen.

Das macht den Mod besonders interessant für große Fabriken, bei denen Materialflüsse geplant, automatisiert und erweitert werden sollen.

INDUSTRIAL PRINCIPLE

Die eigentliche Herausforderung ist nicht das Herstellen eines einzelnen Gegenstands, sondern der Aufbau einer stabilen Produktionskette.

02 // PRODUCTION CHAIN

Produktionsketten verstehen

STUFE FUNKTION
INPUT Rohstoffe und Grundmaterialien
PROCESSING Verarbeitung zu Zwischenprodukten
ASSEMBLY Zusammenbau mehrerer Komponenten
OUTPUT Fertiges Produkt

Eine gute Produktionsanlage sollte möglichst klar erkennen lassen, welche Materialien hineingehen und welches Endprodukt am Ende herauskommt.

03 // INPUT MANAGEMENT

Rohstoffe organisieren

Jede automatisierte Fabrik beginnt mit zuverlässigen Inputs.

  • Erz und Metalle.
  • Holz und organische Materialien.
  • Zwischenprodukte.
  • Energie oder technische Ressourcen.
  • Flüssigkeiten, sofern benötigt.

Für größere Fabriken sollte bereits vor dem Bau geklärt werden, welche Ressourcen dauerhaft benötigt werden.

04 // FACTORY PLANNING

Fabrikplanung

  1. Endprodukt bestimmen.
  2. Benötigte Zwischenprodukte ermitteln.
  3. Produktionsschritte sortieren.
  4. Maschinenbedarf bestimmen.
  5. Input-Lager einrichten.
  6. Produktionslinie bauen.
  7. Output-Lager anschließen.
PLANNING WARNING

Nicht zuerst die Maschinen aufstellen und danach überlegen, wie sie verbunden werden. Bei großen Fabriken führt das schnell zu chaotischen Transportwegen.

05 // CREATE CONNECTION

Zusammenspiel mit Create

In RISE OF NATIONS ist Create die zentrale Grundlage für mechanische Automatisierung. Deshalb lässt sich ein Assembly-Line- Konzept hervorragend mit Create kombinieren.

  • Belts für Materialtransport.
  • Funnels für Ein- und Ausgabe.
  • Chutes für vertikalen Transport.
  • Brass-Systeme für komplexere Logistik.
  • Mechanical Crafters für mehrstufiges Crafting.
  • Mechanical Presses für Verarbeitung.
  • Mechanical Mixers für Produktionsrezepte.
  • Trains für große Entfernungen.
06 // MATERIAL FLOW

Materialfluss

Eine Produktionsanlage funktioniert nur so gut wie ihr Materialtransport.

PROBLEM MÖGLICHE URSACHE
Maschine wartet Input fehlt
Lager läuft voll Output wird nicht abgeführt
Produktion stockt Zwischenprodukt fehlt
Transport überlastet Zu wenig Logistik für die Produktionsmenge
07 // MODULAR FACTORIES

Modulare Produktion

Große Fabriken sollten in einzelne Module aufgeteilt werden.

  • Rohstoffannahme.
  • Schmelzwerk.
  • Komponentenfertigung.
  • Montage.
  • Endproduktion.
  • Verpackung und Lagerung.

Dadurch kann ein Produktionszweig später erweitert werden, ohne die gesamte Fabrik neu bauen zu müssen.

08 // SCALING

Produktion skalieren

Wenn ein Produkt dauerhaft zu langsam hergestellt wird, sollte nicht sofort die gesamte Anlage verändert werden.

Zuerst muss festgestellt werden, welche Produktionsstufe der Engpass ist.

  1. Produktion beobachten.
  2. Engpass identifizieren.
  3. Betroffene Maschine vervielfachen.
  4. Input erhöhen.
  5. Output-Transport prüfen.
09 // MULTIPLAYER INDUSTRY

Industrie im Multiplayer

Auf einem Multiplayer-Server kann eine Assembly-Line-Fabrik sogar als eigenes Spielerprojekt betrieben werden.

Ein Spieler kann Rohstoffe liefern, während andere Spieler Zwischenprodukte herstellen oder die fertigen Waren transportieren.

ECONOMIC PRINCIPLE

Spezialisierung kann auf einem Server effizienter sein als wenn jeder Spieler dieselbe komplette Produktionskette selbst aufbaut.

10 // PERFORMANCE

Performance und Serverlast

Große automatisierte Fabriken können durch viele gleichzeitig aktive Maschinen und Transportobjekte zusätzliche Serverlast erzeugen.

  • Produktionslinien kompakt planen.
  • Unnötige Dauerproduktion vermeiden.
  • Überfüllte Transportsysteme verhindern.
  • Bei Problemen Spark zur Analyse verwenden.
11 // TROUBLESHOOTING

Fehleranalyse

Produktionslinie produziert nichts

Zuerst prüfen, ob der erste Produktionsschritt überhaupt Input erhält. Danach die gesamte Kette Schritt für Schritt verfolgen.

Zwischenprodukt fehlt

Prüfen, ob die entsprechende Produktionsmaschine korrekt versorgt wird und ob das Rezept tatsächlich verfügbar ist.

Output wird nicht transportiert

Lager, Funnel, Belt oder sonstige Transportverbindungen kontrollieren. Auch falsche Ein- und Ausgaberichtungen können eine komplette Linie blockieren.

Nach Mod-Update verändert

Bei Änderungen an Rezepten oder Maschinen immer die aktuelle JEI- Darstellung verwenden und nicht blind nach alten Produktionsplänen bauen.

12 // ADVANCED ENGINEERING

Fortgeschrittene Produktionsplanung

Für sehr große Anlagen lohnt sich eine Produktionsmatrix.

FRAGE PLANUNG
Was wird produziert? Endprodukt definieren
Was wird benötigt? Rohstoffe auflisten
Wo entsteht der Engpass? Produktionsrate vergleichen
Wie wird transportiert? Logistiknetz festlegen
Wie wird erweitert? Reserveflächen einplanen
13 // RISE OF NATIONS APPLICATION

Einsatz im Modpack

Das Modpack besitzt eine außergewöhnlich große technische Modlandschaft. Ein strukturiertes Assembly-Line-Konzept passt daher besonders gut zu industriellen Megaprojekten.

  • Create.
  • Create Factory.
  • Create Ultimate Factory.
  • Create Diesel Generators.
  • Create New Age.
  • Create Mechanical Fusion.
  • Electrodynamics.
  • Nuclear Science.
  • Voltaic.
  • Modular Force Fields.

Damit können Produktionsanlagen vom einfachen Rohstoffbetrieb bis zu hochkomplexen Industriezentren aufgebaut werden.

14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Produktionsketten sollten vor dem Bau geplant werden.
  • Materialfluss ist genauso wichtig wie die Maschinen selbst.
  • Engpässe müssen gezielt analysiert werden.
  • Modulare Fabriken lassen sich leichter erweitern.
  • JEI sollte zur Kontrolle aktueller Rezepte verwendet werden.
  • Create eignet sich hervorragend als Logistikgrundlage.
  • Große Fabriken sollten auf Serverperformance geprüft werden.
FINAL PRINCIPLE

Eine echte Fabrik ist kein Haufen Maschinen. Sie ist ein System, in dem jeder Produktionsschritt den nächsten zuverlässig versorgt.

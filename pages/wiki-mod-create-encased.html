01 // SYSTEM OVERVIEW

Was ist Create Encased?

Create Encased ergänzt die technische Welt von Create um zusätzliche Maschinen- und Verarbeitungssysteme.

Die Erweiterung eignet sich besonders für Spieler, die ihre Produktionsketten stärker industrialisieren und Maschinen als Teil einer größeren Fabrikinfrastruktur einsetzen möchten.

INDUSTRIAL PRINCIPLE

Jede zusätzliche Maschine sollte einen klaren Platz in einer Produktionskette besitzen. Nicht die Anzahl der Maschinen entscheidet über die Qualität einer Fabrik, sondern deren Zusammenspiel.

02 // CREATE FOUNDATION

Grundlagen

Create Encased baut auf dem technischen Grundprinzip von Create auf. Wer bereits mit mechanischer Energie, Antrieben, Wellen und Produktionsmaschinen arbeitet, kann die Erweiterung deutlich leichter verstehen.

  • Mechanical Power
  • Rotation
  • Stress
  • Automatisierung
  • Materialtransport
  • Produktionsketten
03 // MACHINERY

Maschinen als Produktionsmodule

Erweiterte Maschinen sollten als einzelne Module innerhalb einer Produktionsanlage betrachtet werden.

MODUL AUFGABE
INPUT Rohmaterial aufnehmen
PROCESSING Material verarbeiten
OUTPUT Produkt ausgeben
LOGISTICS Material weitertransportieren

Diese Struktur macht es einfacher, komplexe Anlagen später zu erweitern.

04 // MECHANICAL POWER

Mechanische Energie

Wie bei Create muss die mechanische Versorgung der Anlage berücksichtigt werden.

Vor dem Ausbau prüfen

  • Welche Maschinen laufen gleichzeitig?
  • Wie hoch ist die Belastung?
  • Ist ausreichend Antriebsleistung vorhanden?
  • Kann das System später erweitert werden?
LOAD WARNING

Eine Produktionslinie sollte nicht dauerhaft am theoretischen Belastungslimit betrieben werden. Plane Reserve für spätere Maschinen ein.

05 // MATERIAL FLOW

Materialfluss

Eine Maschine funktioniert nur so gut wie die Logistik vor und nach ihr.

  1. Rohstofflager
  2. Input-Transport
  3. Verarbeitungsmaschine
  4. Output-Puffer
  5. Weiterverarbeitung
  6. Endlager

Besonders bei mehreren Maschinen sollte der Materialfluss bereits vor dem eigentlichen Bau geplant werden.

06 // AUTOMATION

Produktionslinien automatisieren

Create Encased eignet sich vor allem für Produktionslinien, bei denen Maschinen miteinander verbunden werden.

STUFE STRUKTUR
I Einzelmaschine
II Maschine mit automatischem Input
III Maschine mit automatischem Output
IV Mehrere Maschinen in Reihe

07 // FACTORY DESIGN

Maschinen richtig platzieren

Eine effiziente Fabrik sollte nicht nur funktionieren, sondern auch Wartung und Erweiterung ermöglichen.

  • Maschinen nicht zu eng platzieren.
  • Transportwege sichtbar halten.
  • Wartungswege freihalten.
  • Input und Output logisch ausrichten.
  • Energieversorgung früh einplanen.
FACTORY DESIGN

Eine Produktionslinie sollte später erweitert werden können, ohne die komplette Fabrik auseinanderbauen zu müssen.

08 // JEI WORKFLOW

Rezepte mit JEI analysieren

In einem großen Modpack ist JEI das wichtigste Werkzeug, um die tatsächlichen Produktionsmöglichkeiten einer Maschine zu prüfen.

  1. Endprodukt suchen.
  2. Rezept öffnen.
  3. Verarbeitungsmaschine feststellen.
  4. Benötigte Zwischenprodukte prüfen.
  5. Rohstoffbedarf zurückverfolgen.

Dadurch kann eine komplette Produktionskette geplant werden, bevor Ressourcen für den Bau ausgegeben werden.

09 // STORAGE

Lagerung und Puffer

Zwischen einzelnen Produktionsstufen sind kleine Materialpuffer oft sinnvoll.

BEREICH FUNKTION
INPUT BUFFER Rohstoffe bereitstellen
PROCESS BUFFER Produktionsschwankungen abfangen
OUTPUT BUFFER Fertige Produkte sammeln
FINAL STORAGE Langfristige Lagerung
10 // SCALING

Produktionslinien skalieren

Wenn eine Produktionslinie nicht mehr genug Produkte liefert, sollte nicht automatisch die gesamte Anlage ersetzt werden.

Häufig ist es effizienter, den Engpass gezielt zu vervielfältigen.

  1. Engpass identifizieren.
  2. Produktionsrate prüfen.
  3. Zusätzliche Maschine planen.
  4. Mechanische Leistung erweitern.
  5. Input und Output anpassen.
11 // TROUBLESHOOTING

Fehleranalyse

Maschine läuft nicht

Prüfe zuerst Energieversorgung, Rezept, Input und die Voraussetzungen der jeweiligen Maschine.

Maschine hat keinen Input

Prüfe Transportwege, Filter, Funnel und die Ausrichtung der angeschlossenen Komponenten.

Output wird nicht abgeholt

Prüfe, ob das Ausgabesystem korrekt angeschlossen ist und ob der nachfolgende Speicher ausreichend Kapazität besitzt.

Gesamte Anlage stockt

Suche den ersten Produktionsschritt, an dem sich Material staut oder nicht mehr weiterbewegt. Dort befindet sich meistens der eigentliche Engpass.

12 // ADVANCED FACTORY

Fortgeschrittene Produktionsarchitektur

Für größere Fabriken empfiehlt sich die Trennung in Produktionssektoren.

  • Rohstoffsektor
  • Grundverarbeitung
  • Zwischenprodukte
  • Endproduktion
  • Lagerung
  • Versand

Jede Zone kann über definierte Transportwege mit der nächsten Zone verbunden werden.

14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

Create Encased sollte nicht isoliert betrachtet werden. Die eigentliche Stärke entsteht durch die Kombination aus Maschinen, Energie, Logistik, Lagerung und automatisierten Produktionsketten.

  • Maschinen modular planen.
  • Mechanische Energie früh berücksichtigen.
  • Input und Output sauber trennen.
  • JEI für Rezepte und Produktionsketten verwenden.
  • Engpässe gezielt beseitigen.
  • Produktionsanlagen erweiterbar bauen.
FINAL PRINCIPLE

Eine gute Fabrik ist kein Haufen Maschinen. Sie ist ein System, in dem jede Maschine eine definierte Aufgabe innerhalb einer größeren Produktionskette erfüllt.

01 // SYSTEM OVERVIEW

Was macht der Fix?

Create besitzt mit seinen mechanischen Bohrern ein leistungsfähiges System zum automatisierten Abbauen von Blöcken. Gleichzeitig bringen Strukturmods eigene Blöcke und besondere Strukturelemente in die Welt.

Ein Kompatibilitäts-Fix sorgt dafür, dass bestimmte Blöcke oder Blockzustände bei der Verarbeitung durch Create korrekt behandelt werden.

CORE PRINCIPLE

Der Fix verändert nicht das grundlegende Create-Borensystem. Er soll vor allem verhindern, dass spezielle Blöcke unerwartet Probleme verursachen.

02 // CREATE DRILLS

Das Create-Borensystem

Create-Bohrer können Teil komplexer Contraptions sein und große Mengen an Blöcken automatisiert abbauen.

  • Mining-Contraptions.
  • Bohrmaschinen.
  • Automatisierte Tunnel.
  • Ressourcenabbau.
  • Großflächige Erdarbeiten.

Dadurch können sie auch auf Blöcke treffen, die von anderen Mods hinzugefügt wurden.

03 // STRUCTURE BLOCKS

Warum Strukturen relevant sind

Große Strukturmods fügen der Welt zahlreiche neue Blöcke hinzu. Ein Bohrer kann theoretisch auf jeden dieser Blöcke treffen.

04 // AUTOMATED MINING

Automatisierter Abbau

Create-Bohrsysteme können für große Mining-Projekte eingesetzt werden. Besonders effizient sind sie, wenn Materialtransport und Lagerung direkt mit der Bohrmaschine verbunden werden.

  • Bohrer platzieren.
  • Contraption mit Antrieb versehen.
  • Abbaupfad definieren.
  • Material aufnehmen.
  • Rohstoffe in ein Lager transportieren.
05 // DUNGEONS

Dungeons und automatisierte Bohrer

In RISE OF NATIONS existieren mehrere Mods, die zusätzliche Strukturen und Dungeons in die Welt bringen. Ein automatisiertes Bohrsystem kann daher auf sehr unterschiedliche Blocktypen treffen.

Der Fix ist insbesondere für die Kompatibilität zwischen Create und solchen Strukturen interessant.

CAUTION

Große Dungeons sollten nicht blind mit automatisierten Maschinen zerlegt werden. Dabei können wichtige Strukturbereiche zerstört werden, bevor sie erkundet wurden.

06 // WORLD EXPLORATION

Erkunden vor Automatisieren

Gerade bei einem Modpack mit vielen Strukturmods lohnt es sich, neue Gebiete zunächst vollständig zu erkunden.

  1. Struktur entdecken.
  2. Gebiet untersuchen.
  3. Wichtige Räume sichern.
  4. Loot einsammeln.
  5. Erst danach über automatisierten Abbau nachdenken.
07 // FACTORY APPLICATION

Create-Fabriken und Mining

Der größte praktische Nutzen entsteht, wenn das Bohrsystem direkt mit einer industriellen Produktionskette verbunden wird.

  • Bohrer.

  • Depots.
  • Lager.
  • Verarbeitung.

So kann aus einer einfachen Bohrmaschine eine vollständige Rohstoffgewinnungsanlage entstehen.

09 // TROUBLESHOOTING

Fehleranalyse

Ein Block wird nicht korrekt verarbeitet

Prüfe zunächst, ob der betroffene Block von einem anderen Mod stammt und ob genau dieser Block das Problem verursacht.

Bohrer stoppt unerwartet

Contraption vereinfachen und den problematischen Block einzeln testen.

Problem tritt nur in bestimmten Strukturen auf

Das deutet auf eine mögliche Wechselwirkung zwischen dem Strukturmod und dem Create-Borensystem hin.

Fehler begann nach einem Update

Create, Strukturmod und Fix-Version miteinander vergleichen.

10 // VERSION CONTROL

Kompatibilität kontrollieren

Kleine Fix-Mods sind stark von den Versionen der Mods abhängig, für die sie entwickelt wurden.

  • Create-Version prüfen.
  • Betroffenen Strukturmod prüfen.
  • Fix-Version prüfen.
  • Fehler mit kleinem Testaufbau reproduzieren.
  • Erst danach die große Maschine wieder einsetzen.
11 // MULTIPLAYER

Auf dem Server

Automatisierte Mining-Systeme können auf Multiplayer-Servern sehr leistungsfähig sein, sollten aber mit Bedacht eingesetzt werden.

  • Große Maschinen nicht unnötig dauerhaft laufen lassen.
  • Mining-Bereiche sinnvoll begrenzen.
  • Gemeinsame Ressourcenprojekte koordinieren.
  • Wichtige Strukturen vor automatisiertem Abbau schützen.
SERVER DOCTRINE

Auf einem gemeinsamen Server sollte automatisierter Abbau niemals wichtige Bauwerke oder geplante Gebiete anderer Spieler ungefragt zerstören.

12 // PERFORMANCE

Performance

Große Mining-Contraptions können viele Blöcke verarbeiten und bewegen. Eine übermäßig große Anlage kann dadurch unnötige Belastung erzeugen.

  • Mining-Anlagen modular bauen.
  • Nur benötigte Bereiche aktiv halten.
  • Transportwege kurz halten.
  • Unnötig riesige Bohrmaschinen vermeiden.
13 // RISE OF NATIONS APPLICATION

Einsatz im Modpack

Der Fix ist besonders interessant, weil RISE OF NATIONS sowohl Create als auch zahlreiche Struktur- und Dungeon-Mods verwendet.

  • Großflächiger Ressourcenabbau.
  • Industrielle Mining-Anlagen.
  • Unterirdische Fabriken.
  • Automatisierte Tunnel.
  • Rohstoffversorgung großer Städte.

Damit wird aus einem kleinen Kompatibilitäts-Fix ein Bestandteil eines wesentlich größeren technischen Systems.

14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Der Mod ist ein Kompatibilitäts-Fix.
  • Er ergänzt Create statt ein neues Mining-System einzuführen.
  • Er ist besonders bei modifizierten Strukturblöcken relevant.
  • Create-Bohrer können in große Automatisierungssysteme eingebunden werden.
  • Große Dungeons sollten zuerst erkundet werden.
  • Versionen der beteiligten Mods müssen zusammenpassen.
FINAL PRINCIPLE

Automatisierung ist mächtig. Aber eine gute Fabrik beginnt damit, zu wissen, was man überhaupt abbauen will.

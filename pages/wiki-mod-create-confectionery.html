CREATE CONFECTIONERY

Create Confectionery erweitert Create um eine industrielle Süßwarenproduktion. Der Schwerpunkt liegt auf der Herstellung verschiedener Süßigkeiten und deren Einbindung in automatisierte Produktionsketten.

01 // SYSTEM OVERVIEW

Was ist Create Confectionery?

Create Confectionery erweitert das industrielle Create-Ökosystem um Süßwaren und entsprechende Produktionsketten.

Dadurch kann eine einfache Lebensmittelproduktion zu einer größeren Süßwarenindustrie ausgebaut werden.

CORE PRINCIPLE

Süßwaren sollten als Produktionskette betrachtet werden: Rohstoffe werden verarbeitet, kombiniert und anschließend als fertige Produkte gelagert oder verteilt.

02 // PRODUCTION CHAIN

Produktionslogik

Die genaue Rezeptstruktur hängt vom jeweiligen Produkt ab. Das allgemeine Prinzip bleibt jedoch gleich.

  1. Rohstoffe bereitstellen.
  2. Ausgangsmaterialien verarbeiten.
  3. Zwischenprodukte herstellen.
  4. Komponenten kombinieren.
  5. Fertigprodukt erzeugen.
  6. Produkt lagern oder ausliefern.
03 // RAW MATERIALS

Rohstoffe und Zutaten

Eine automatisierte Süßwarenfabrik benötigt eine zuverlässige Versorgung ihrer Zutaten.

  • Grundlegende Lebensmittelrohstoffe.
  • Verarbeitete Zwischenprodukte.
  • Spezielle Süßwarenzutaten.
  • Weitere Zutaten aus kompatiblen Food-Mods.
SUPPLY WARNING

Bei komplexen Rezeptketten sollte jede wichtige Zutat über einen ausreichenden Puffer verfügen.

04 // AUTOMATION

Süßwaren automatisieren

05 // PRODUCTION DESIGN

Aufbau einer Süßwarenfabrik

Eine übersichtliche Produktionsanlage sollte nach Produktionsstufen organisiert werden.

  1. Rohstofflager.
  2. Zutatenaufbereitung.
  3. Hauptproduktion.
  4. Zwischenproduktlager.
  5. Endproduktion.
  6. Fertigwarenlager.
  7. Versand.
DESIGN PRINCIPLE

Der physische Aufbau sollte dem logischen Produktionsfluss folgen. Dadurch lassen sich Fehler und Engpässe leichter erkennen.

06 // STORAGE

Lagerstruktur

Eine Süßwarenproduktion profitiert von mehreren getrennten Lagerstufen.

LAGER ZWECK
RAW STORAGE Grundmaterialien
PROCESSING STORAGE Zwischenprodukte
PRODUCT STORAGE Fertige Süßwaren
EXPORT STORAGE Produkte für den Versand
07 // BOTTLENECKS

Produktionsengpässe

Bei automatisierten Produktionslinien ist meistens nicht die komplette Anlage das Problem. Häufig ist nur eine einzelne Produktionsstufe langsamer.

  • Zutatenversorgung prüfen.
  • Zwischenlager kontrollieren.
  • Transportgeschwindigkeit prüfen.
  • Langsamste Maschine identifizieren.
  • Nur den tatsächlichen Engpass erweitern.

Süßwaren als Handelsprodukt

11 // LOGISTICS

Verteilung und Transport

Fertige Produkte können über verschiedene Transportwege verteilt werden.

  • Lokale Lager.
  • Create-Belts innerhalb der Fabrik.
  • Transportsysteme zwischen Gebäuden.
  • Create-Züge für größere Entfernungen.
  • Zentrale Verteilzentren.
12 // FACTORY SCALING

Produktion vergrößern

Eine kleine Produktionslinie kann schrittweise zu einer industriellen Anlage erweitert werden.

  1. Produktionsengpass finden.
  2. Betroffene Stufe vervielfachen.
  3. Rohstoffversorgung erhöhen.
  4. Transportkapazität erweitern.
  5. Zwischenlager vergrößern.
  6. Fertigwarenlager erweitern.
13 // TROUBLESHOOTING

Fehleranalyse

Eine Rezeptkette funktioniert nicht

Prüfe zuerst die einzelnen Produktionsstufen und vergleiche die tatsächlich benötigten Zutaten mit dem vorhandenen Material.

Items stauen sich

Wahrscheinlich ist eine nachgelagerte Produktionsstufe zu langsam oder das Ziellager voll.

Maschinen stehen still

Prüfe Antrieb, Input und Output der betroffenen Station.

Fabrik läuft ungleichmäßig

Suche nach fehlenden Puffern zwischen unterschiedlich schnellen Produktionsschritten.

Baue keine einzelne Maschine – baue eine Produktionskette. Die eigentliche Stärke entsteht durch das Zusammenspiel von Rohstoffen, Verarbeitung, Logistik, Lagerung und Vertrieb.

01 // SYSTEM OVERVIEW

Was ist Create Dimension?

Create Dimension verbindet das technische Create-System mit dimensionalem Gameplay. Dadurch können industrielle Projekte und Erkundung stärker miteinander verbunden werden.

Für RISE OF NATIONS ist das besonders interessant, weil entfernte Ressourcenstandorte, Produktionsanlagen und Außenposten miteinander verbunden werden können.

CORE PRINCIPLE

Dimensionale Infrastruktur sollte nicht isoliert betrachtet werden. Der eigentliche Nutzen entsteht, wenn Reisen, Ressourcen und Logistik zusammenarbeiten.

02 // DIMENSIONAL LOGIC

Dimensionen als neue Gebiete

Eine zusätzliche Dimension kann wie ein eigenständiger Wirtschafts- oder Forschungsraum behandelt werden.

  • Neue Ressourcen erschließen.
  • Neue Gebiete erkunden.
  • Außenposten errichten.
  • Produktionsstandorte aufbauen.
  • Reisewege organisieren.
03 // INFRASTRUCTURE

Infrastruktur aufbauen

Vor dem langfristigen Einsatz sollte ein sicherer Zugangspunkt eingerichtet werden.

  1. Zugang zur Dimension herstellen.
  2. Basisbereich absichern.
  3. Versorgung organisieren.
  4. Ressourcenquellen erfassen.
  5. Transportwege planen.
DEPLOYMENT WARNING

Eine neue Dimension sollte zunächst erkundet werden, bevor große Mengen wertvoller Maschinen und Produktionsanlagen dorthin verlegt werden.

04 // RESOURCE EXTRACTION

Dimensionale Gebiete können als zusätzliche Ressourcenstandorte verwendet werden.

05 // CREATE INTEGRATION

Create in einer anderen Dimension

Das Create-System kann auch als Grundlage für dimensionale Außenposten dienen.

  • Automatisierte Rohstoffverarbeitung.
  • Lokale Produktionsanlagen.
  • Transportstationen.
  • Lagerhäuser.
  • Versorgungsanlagen.

Dadurch kann eine Dimension zu einem echten Teil der industriellen Infrastruktur werden.

06 // OUTPOST DESIGN

Außenposten

Ein guter Außenposten muss nicht groß sein. Entscheidend sind sichere Versorgung, Lagerung und ein klarer Zugang.

  • Spawn- beziehungsweise Zugangspunkt.
  • Grundlegendes Lager.
  • Versorgung mit wichtigen Materialien.
  • Arbeits- und Produktionsbereich.
  • Verteidigung.
  • Transportanbindung.
07 // LOGISTICS

Transport zwischen Welten

Die eigentliche Herausforderung besteht häufig nicht in der Produktion, sondern darin, Ressourcen zuverlässig zwischen verschiedenen Gebieten zu bewegen.

  1. Quelle identifizieren.
  2. Ressourcen lokal sammeln.
  3. Zwischenlager einrichten.
  4. Transportweg festlegen.
  5. Zentrales Lager versorgen.
LOGISTICS PRINCIPLE

Ein zentraler Verarbeitungskomplex kann effizienter sein als viele kleine Fabriken, sofern der Transport zuverlässig funktioniert.

08 // DIMENSIONAL BASE

Große Basis planen

Bei einem dauerhaften Aufenthalt kann eine Dimension wie ein eigenständiges Industriegebiet aufgebaut werden.

  • Hauptbasis.
  • Rohstofflager.
  • Produktionshalle.
  • Forschungsbereich.
  • Transportknotenpunkt.
  • Verteidigungsbereich.
09 // EXPLORATION

Erkundung

Vor dem Aufbau einer großen Anlage sollte das Gebiet systematisch untersucht werden.

  • Terrain analysieren.
  • Ressourcen dokumentieren.
  • Interessante Strukturen markieren.
  • Gefahren identifizieren.
  • Geeigneten Basisstandort auswählen.
10 // SECURITY

Sicherheit in Außenbereichen

Dimensionale Außenposten sollten nicht nur funktional, sondern auch gegen die lokale Umgebung abgesichert sein.

  • Zugang kontrollieren.
  • Beleuchtung einplanen.
  • Lagerbereiche schützen.
  • Wichtige Maschinen zentral aufstellen.
  • Flucht- und Rückkehrmöglichkeiten offenhalten.
FIELD SECURITY

Wertvolle Maschinen sollten nicht ungeschützt an einem abgelegenen Erkundungsort stehen.

11 // MOD SYNERGY

Zusammenspiel mit anderen Mods

Create Dimension kann besonders stark mit Mods kombiniert werden, die Exploration, Reisen, Ressourcen und Automatisierung erweitern.

  • Create für Maschinen und Automation.
  • Waystones für schnelle Reisen.
  • JourneyMap für Kartierung.
  • JEI für Produktionsinformationen.
  • Create Railways Navigator für Transportplanung.
  • Create Space für weiterführende technische Projekte.
12 // MULTIPLAYER APPLICATION

Dimensionale Infrastruktur im Multiplayer

In einem Multiplayer-Server können dimensionale Außenposten zwischen Spielern oder Unternehmen aufgeteilt werden.

  • Ressourcenstationen.
  • Forschungsstützpunkte.
  • Handelsstationen.
  • Industrieanlagen.
  • Gemeinsame Transportknotenpunkte.
13 // TROUBLESHOOTING

Fehleranalyse

Zugang funktioniert nicht

Prüfe die verwendete Struktur beziehungsweise Mechanik und ob alle benötigten Voraussetzungen erfüllt sind.

Außenposten wird nicht versorgt

Kontrolliere Lagerbestände, Transportwege und Versorgungspunkte.

Ressourcen fehlen trotz funktionierender Mine

Das Problem liegt wahrscheinlich im Transport oder im Übergang zwischen lokaler und zentraler Lagerung.

Basis ist schwer erreichbar

Richte einen klar definierten Hauptzugang ein und kombiniere ihn mit einem geeigneten Reisesystem.

14 // RISE OF NATIONS APPLICATION

Einsatz im Modpack

Create Dimension passt hervorragend zum größeren Erkundungs- und Industriesystem von RISE OF NATIONS.

  • Dimensionale Forschungsstationen.
  • Rohstoff-Außenposten.
  • Industrielle Produktionsbasen.
  • Militärische Versorgungsstützpunkte.
  • Handels- und Transportknoten.
  • Große Expeditionen.
15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Eine neue Dimension sollte zunächst erkundet werden.
  • Außenposten benötigen sichere Versorgung und Lagerung.
  • Ressourcen müssen Teil eines größeren Logistiksystems werden.
  • Create kann auch außerhalb der Hauptwelt als Industrieplattform dienen.
  • Reise- und Transportmods ergänzen das System erheblich.
  • Große dimensionale Projekte sollten modular aufgebaut werden.
FINAL PRINCIPLE

Eine Dimension ist kein isolierter Ort. Behandle sie als neues Gebiet innerhalb deines gesamten wirtschaftlichen, technischen und logistischen Netzwerks.

CREATE THREADED TRAINS

Create Threaded Trains erweitert das Zug- und Transportkonzept von Create. Der Schwerpunkt liegt auf leistungsfähigen Eisenbahn-Netzwerken, automatisierten Transportwegen und der Verbindung mehrerer Produktionsstandorte zu einem gemeinsamen Logistiksystem.

01 // SYSTEM OVERVIEW

Was ist Create Threaded Trains?

Create Threaded Trains gehört zum erweiterten Eisenbahn-Ökosystem rund um Create und ergänzt den Transportbereich um zusätzliche Möglichkeiten für Zugnetzwerke und automatisierte Logistik.

Im Mittelpunkt steht nicht ein einzelner Zug, sondern die Frage, wie mehrere Produktionsanlagen miteinander verbunden werden können.

CORE PRINCIPLE

Ein Zugnetz funktioniert dann besonders gut, wenn Produktionsstätten, Bahnhöfe, Lager und Verteilzentren als ein gemeinsames System geplant werden.

02 // RAIL NETWORK

Grundlagen eines Schienennetzes

Bevor komplexe Automatisierung aufgebaut wird, sollte ein stabiles Schienennetz vorhanden sein.

  • Hauptstrecken definieren.
  • Bahnhöfe sinnvoll positionieren.
  • Kreuzungen und Abzweigungen planen.
  • Ausweichmöglichkeiten für Züge berücksichtigen.
  • Produktionsstandorte logisch anbinden.
03 // TRAIN OPERATIONS

Züge als Logistiksystem

Create-Züge können große Mengen an Items und anderen Transportgütern zwischen weit entfernten Standorten bewegen.

KOMPONENTE FUNKTION
LOKOMOTIVE Bewegung des Zuges
WAGONS Transportkapazität
STATION Be- und Entladepunkt
SIGNAL SYSTEM Verkehrssteuerung
RAIL NETWORK Verbindung mehrerer Standorte
04 // STATION DESIGN

Bahnhöfe richtig planen

Ein Bahnhof sollte nicht nur als Haltestelle betrachtet werden. In einer großen Industrieanlage ist er ein Logistikterminal.

  • Ein- und Ausfahrten trennen.
  • Beladebereiche übersichtlich halten.
  • Entladebereiche direkt an Lager anbinden.
  • Wartebereiche für Züge einplanen.
  • Mehrere Produktionslinien getrennt verwalten.
NETWORK WARNING

Ein zu kleiner Bahnhof kann zum Flaschenhals der gesamten Fabrik werden. Bei hohem Verkehrsaufkommen sollte der Bahnhof von Anfang an erweiterbar sein.

05 // SIGNALS

Verkehrssteuerung

Mit wachsendem Schienennetz wird die Steuerung des Zugverkehrs entscheidend.

Warum Signale wichtig sind

Mehrere Züge auf derselben Strecke benötigen kontrollierte Fahrbereiche. Ohne geeignete Blockaufteilung können Züge unnötig warten oder Strecken gegenseitig blockieren.

Grundprinzip

  • Strecken in kontrollierbare Abschnitte teilen.
  • Bahnhöfe als eigene Verkehrsbereiche betrachten.
  • Engstellen früh erkennen.
  • Alternative Routen bei großen Netzwerken planen.
06 // INDUSTRIAL LOGISTICS

Fabriken per Zug verbinden

Die größte Stärke eines Zugnetzwerks zeigt sich bei weit voneinander entfernten Produktionsketten.

  1. Rohstoffregion bestimmen.
  2. Rohstofflager errichten.
  3. Produktionsanlage anbinden.
  4. Zwischenprodukte transportieren.
  5. Endprodukte in ein Zentrallager liefern.

Damit können einzelne Fabriken auf bestimmte Aufgaben spezialisiert werden, anstatt jede Ressource an jedem Standort produzieren zu müssen.

Das zentrale Logistikzentrum

Für große Serverwelten kann ein zentraler Bahnhof als logistisches Rückgrat dienen.

BEREICH AUFGABE

EXPORT Fertige Waren verteilen
STORAGE Zwischenlagerung

08 // AUTOMATION

Automatisierte Lieferketten

Eine vollständig automatisierte Produktionskette kann mehrere unabhängige Anlagen miteinander verbinden.

  1. Rohstofffabrik produziert Material.
  2. Ein Zug holt das Material ab.
  3. Material wird zum Verarbeitungsterminal gebracht.
  4. Die nächste Fabrik verarbeitet das Material.
  5. Endprodukte werden zentral gelagert.
AUTOMATION RULE

Jeder Transportweg sollte eine eindeutige Aufgabe besitzen. Das macht Fehler deutlich leichter zu finden.

09 // MULTI-TRAIN NETWORKS

Mehrere Züge gleichzeitig

Große Produktionswelten benötigen häufig mehrere Züge. Dabei muss das Netzwerk so aufgebaut werden, dass sich Züge nicht gegenseitig dauerhaft blockieren.

  • Verkehrsaufkommen analysieren.
  • Hauptstrecken ausreichend dimensionieren.
  • Wartebereiche vor wichtigen Stationen einplanen.
  • Engpässe vermeiden.
  • Routen logisch trennen.
10 // CITY INFRASTRUCTURE

Züge als Teil einer Nation

Im RISE-OF-NATIONS-Setting können Eisenbahnlinien weit mehr sein als reine Transportmittel.

  • Städte miteinander verbinden.
  • Industriegebiete anbinden.
  • Häfen und Handelszentren versorgen.
  • Rohstoffregionen erschließen.
  • Große Warenströme darstellen.

Dadurch entsteht eine sichtbare Infrastruktur, die die wirtschaftliche Entwicklung einer Spielerregion unterstützt.

11 // TROUBLESHOOTING

Fehleranalyse

Zug fährt nicht los

Prüfe zunächst Strecke, Station, Fahrplan und die grundlegende Zugkonfiguration.

Zug wartet dauerhaft

Kontrolliere die Verkehrsführung und mögliche Blockierungen durch andere Züge.

Ware kommt nicht an

Prüfe die Belade- und Entladebedingungen sowie die angeschlossenen Lager- und Transportsysteme.

Netzwerk ist überlastet

Zusätzliche Strecken, Wartebereiche oder eine bessere Aufteilung der Transportaufgaben können erforderlich sein.

12 // ADVANCED NETWORK DESIGN

Große Eisenbahnnetze

Ab einer bestimmten Größe sollte das Schienennetz wie ein echtes Logistiksystem behandelt werden.

  • Hauptbahnhof als zentralen Knoten definieren.
  • Industriegebiete über eigene Linien anbinden.
  • Rohstoffregionen mit dedizierten Transportwegen versorgen.
  • Wichtige Strecken redundant planen.
  • Verkehrsaufkommen regelmäßig überprüfen.

14 // RISE OF NATIONS APPLICATION

Einsatz im Modpack

Create Threaded Trains passt besonders gut zu einem Modpack, das Create stark als industrielles Fundament nutzt.

  • Create-Fabriken miteinander verbinden.
  • Große Rohstoffmengen transportieren.
  • Produktionsstandorte spezialisieren.
  • Städte und Industriegebiete verbinden.
  • Handelsrouten zwischen Spielern aufbauen.
  • Große Logistikzentren errichten.
15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Züge sind ein Logistiksystem, kein bloßes Transportmittel.
  • Bahnhöfe sollten als Terminals geplant werden.
  • Große Netze brauchen klare Verkehrsstrukturen.
  • Produktionsanlagen sollten logisch verbunden werden.
  • Wartebereiche verhindern viele Verkehrsprobleme.
  • Jede Zugroute sollte eine eindeutige Aufgabe besitzen.
  • Bei großen Netzwerken immer Erweiterungen mitplanen.
FINAL PRINCIPLE

Ein gutes Zugnetz transportiert nicht einfach Items. Es verbindet die komplette industrielle Infrastruktur einer Welt zu einem einzigen funktionierenden System.

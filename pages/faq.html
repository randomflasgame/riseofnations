MODPACK INSTALLIEREN

PROCEDURE // 01
STEP 01

CurseForge installieren

Installiere den CurseForge Launcher und öffne ihn. Du brauchst kein komplett neues Minecraft-Profil außerhalb von CurseForge anzulegen.

STEP 02

Eigenes Profil erstellen

Erstelle in CurseForge ein eigenes Minecraft-Profil. Das Profil muss für die Version 1.21.1 erstellt werden. Als Modloader wird NeoForge 21.1.248 verwendet.

STEP 03

Profil einmal starten

Starte das neue Profil einmal. Dadurch erstellt CurseForge automatisch die benötigte Ordnerstruktur. Warte, bis Minecraft vollständig gestartet wurde und schließe es anschließend wieder.

STEP 04

Profilordner öffnen

Gehe in CurseForge zu deinem Profil. Neben dem PLAY Button befindet sich das Menü ⋯. Öffne dort Open Folder.

Genau diesen Ordner brauchen wir.

STEP 05

Modpack-ZIP öffnen

Nimm die bereitgestellte Datei:
im minecraft ordner entpacken.zip Öffne die ZIP-Datei. Darin befindet sich der fertige mods-Ordner.

STEP 06

Mods-Ordner kopieren

Kopiere den mods-Ordner aus der ZIP-Datei in den gerade über CurseForge geöffneten Profilordner. Am Ende muss der Ordner ungefähr so aussehen:
DEIN_CURSEFORGE_PROFIL/mods/

STEP 07

CurseForge erneut öffnen

Schließe die ZIP-Datei. Starte anschließend dein CurseForge-Profil erneut. CurseForge sollte jetzt die Mods erkennen.

STEP 08

Modpack starten

Drücke PLAY und warte. Der erste Start kann deutlich länger dauern als ein normales Minecraft. Das ist bei einem großen Modpack normal.

GOLDEN RULE // VERY IMPORTANT

NICHT selbst nach dem normalen Minecraft-Ordner suchen. Öffne immer zuerst dein CurseForge-Profil und gehe über ⋯ → Open Folder . Genau dort gehört der mods Ordner hinein.

Wenn du den falschen Minecraft-Ordner öffnest, kann es passieren, dass CurseForge die Mods nicht erkennt.

EMPFOHLENE EINSTELLUNGEN

CONFIGURATION // 02

RAM / ARBEITSSPEICHER

Für das Modpack empfehlen wir grundsätzlich 8 bis 12 GB RAM für das CurseForge-Profil.

Ich selbst verwende für mein Profil 14 GB. Mehr RAM ist aber nicht automatisch besser. Wenn dein PC insgesamt wenig Arbeitsspeicher besitzt, solltest du nicht unnötig viel reservieren.

EMPFEHLUNG: 8–12 GB

JAVA

Für das Modpack soll die Java-Einstellung von CurseForge auf Default Version bleiben. Du musst normalerweise keine eigene Java-Version herunterladen oder manuell auswählen.

JAVA: DEFAULT VERSION

RENDER DISTANCE

Eine hohe Sichtweite sieht gut aus, benötigt bei großen Welten und vielen Mods aber deutlich mehr Leistung. Wenn du FPS-Probleme hast, reduziere zuerst die Render Distance.

BEI PROBLEMEN REDUZIEREN

SIMULATION DISTANCE

Die Simulation Distance bestimmt, wie weit Minecraft Spielmechaniken aktiv simuliert. Eine niedrigere Einstellung kann CPU-Leistung sparen.

MODERAT EINSTELLEN

SHADER

Shader sind nicht notwendig. Wenn du Probleme mit FPS oder Speicherverbrauch hast, solltest du Shader zunächst deaktivieren.

BEI SCHWACHER HARDWARE: AUS

PARTICLES

Bei Performance-Problemen können Partikel reduziert werden. Besonders bei großen Maschinen, Explosionen und vielen Effekten kann dies helfen.

BEI FPS-PROBLEMEN REDUZIEREN

ENTITY DISTANCE

Eine hohe Entity Distance kann bei vielen Tieren, Maschinen, Fahrzeugen und anderen Objekten zusätzliche Leistung benötigen.

NICHT UNNÖTIG MAXIMIEREN

JAVA / MODPACK GRUNDREGEL

Wenn das Modpack funktioniert, solltest du Java nicht manuell verändern. Erst wenn tatsächlich ein Java-Problem angezeigt wird, sollte die Java-Konfiguration untersucht werden.

HÄUFIGE FRAGEN

FAQ // 03

Warum sehe ich meine Mods nicht?

Kontrolliere zuerst, ob du wirklich den richtigen CurseForge-Profilordner geöffnet hast. Gehe über ⋯ → Open Folder und kontrolliere, ob dort ein mods Ordner vorhanden ist.

Ich habe jetzt mods/mods. Was ist passiert?

Das ist ein häufiger Fehler. Du brauchst nicht den Inhalt des Mods-Ordners in einen zweiten Mods-Ordner zu kopieren. Es muss ungefähr so aussehen:

Profilordner → mods → Mod-Dateien

Nicht: Profilordner → mods → mods → Mod-Dateien

Muss ich jeden Mod einzeln installieren?

Nein. Die bereitgestellte ZIP-Datei enthält bereits den fertigen mods Ordner. Du musst nicht jeden Mod einzeln suchen und herunterladen.

Kann ich das Modpack mit normalem Minecraft starten?

Nein. Das Modpack ist für Minecraft 1.21.1 mit NeoForge 21.1.248 vorgesehen. Verwende das dafür erstellte CurseForge-Profil.

Welche Java-Version soll ich verwenden?

Lass CurseForge auf Default Version stehen. Eine manuelle Java-Auswahl ist normalerweise nicht notwendig.

Wie viel RAM soll ich einstellen?

Wir empfehlen 8 bis 12 GB RAM für das Profil. Das eigene Profil des Entwicklers ist mit 14 GB konfiguriert. Mehr ist jedoch nicht automatisch besser.

Minecraft braucht ewig zum Starten. Ist das normal?

Bei einem großen Modpack kann der Start deutlich länger dauern als bei Vanilla Minecraft. Besonders der erste Start kann lange dauern. Nicht sofort den Launcher schließen.

Das Spiel stürzt beim Start ab. Was soll ich tun?

Prüfe zuerst:

Minecraft-Version: 1.21.1
NeoForge: 21.1.248
Java: Default Version
Mods-Ordner: richtig platziert

Wenn alles stimmt, sollte der genaue Crash-Fehler weiter untersucht werden.

Kann ich zusätzliche Mods installieren?

Technisch möglicherweise ja. Für den offiziellen Server können zusätzliche Mods aber zu Problemen oder Versionskonflikten führen. Für das Standard-Setup solltest du das Modpack unverändert verwenden.

Kann ich Mods entfernen?

Nicht empfohlen. Manche Mods sind voneinander abhängig oder verändern gemeinsame Spielsysteme. Das Entfernen einzelner Mods kann deshalb zu Abstürzen oder fehlenden Inhalten führen.

Mein Spiel hat wenig FPS. Was mache ich?

Reduziere zuerst die Render Distance und Simulation Distance . Deaktiviere außerdem Shader und reduziere Partikel. Erst danach sollte man weitere Einstellungen verändern.

Ist mehr RAM immer besser?

Nein. 16, 20 oder 24 GB RAM führen nicht automatisch zu mehr FPS. Wichtig ist, dass dein PC genug RAM für Minecraft und gleichzeitig für Windows und andere Programme behält. Deshalb empfehlen wir zunächst 8–12 GB .

TROUBLESHOOTING // 04

MODS FEHLEN

CurseForge-Profil öffnen → ⋯ → Open Folder. Kontrollieren, ob der mods-Ordner direkt im Profilordner liegt.

SPIEL CRASHT

Versionen kontrollieren: Minecraft 1.21.1, NeoForge 21.1.248, Java Default Version.

NIEDRIGE FPS

Render Distance reduzieren, Simulation Distance reduzieren, Shader deaktivieren und Partikel reduzieren.

START DAUERT LANG

Bei großen Modpacks normal. Besonders der erste Start kann deutlich länger dauern.

ZU WENIG RAM

Profil auf 8–12 GB einstellen, sofern dein PC genug Gesamtspeicher besitzt.

FALSCHER ORDNER

Niemals einfach irgendeinen Minecraft-Ordner auswählen. Immer über das CurseForge-Profil → ⋯ → Open Folder gehen.

SUPPORT PROTOCOL

Wenn das Modpack trotz dieser Anleitung nicht startet, bitte nicht einfach Mods löschen oder Dateien verändern. Für eine schnelle Fehleranalyse sind folgende Informationen hilfreich:

  • Minecraft Version: 1.21.1
  • NeoForge Version: 21.1.248
  • Java: Default Version
  • verwendeter RAM
  • genaue Fehlermeldung
  • Screenshot des Fehlers
  • falls vorhanden: Crash-Report

Je genauer die Informationen sind, desto schneller kann das Problem gefunden werden.

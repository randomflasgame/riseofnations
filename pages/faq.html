INSTALLATION STANDARD DEPLOYMENT PROCEDURE
STEP 01
PROFILE

CREATE CURSEFORGE PROFILE

Open CurseForge and create or select the Minecraft profile used for RISE OF NATIONS.

STEP 02
FOLDER

OPEN PROFILE FOLDER

Click the three dots next to the Play button and select Open Folder.

STEP 03
PACKAGE

DOWNLOAD PACKAGE

Download the official RISE OF NATIONS package from the Download section.

STEP 04
EXTRACT

EXTRACT THE PACKAGE

Extract the contents of the package directly into the CurseForge profile folder.

STEP 05
VERIFY

CHECK MODS FOLDER

Make sure the profile contains the actual mods folder and not another nested mods/mods directory.

STEP 06
LAUNCH

START MINECRAFT

Return to CurseForge and start the profile. The correct NeoForge installation should load.

IMPORTANT
The most common installation mistake is extracting the package into the wrong directory. Always use CurseForge → Profile → ⋯ → Open Folder before extracting the package.

COMMON PROBLEMS TROUBLESHOOTING
PROBLEM 01
INSTALLATION

MINECRAFT CRASHES ON START

Verify the Minecraft version, NeoForge version and CurseForge profile. Make sure the package was extracted into the correct profile folder.

CHECK VERSION
PROBLEM 02
MEMORY

GAME RUNS OUT OF MEMORY

Increase the allocated RAM if your computer has enough available memory. Around 8–12 GB is recommended for the modpack.

CHECK RAM
PROBLEM 03
FILES

MODS ARE NOT LOADING

Check whether the mods are located directly inside the profile's mods folder and not inside a second nested folder.

CHECK PATH
PROBLEM 04
PERFORMANCE

GAME RUNS SLOWLY

Lower render distance, simulation distance, particles and entity distance. Disable shaders if necessary.

TECHNICAL SUPPORT // PLAYER OPERATIONS

FAQ

Alles rund um Installation, CurseForge, Einstellungen, Performance und typische Probleme bei Rise of Nations.

⚠ WICHTIG VOR DER INSTALLATION

Rise of Nations ist ein Modpack. Du solltest es nicht einfach in deinen normalen Minecraft-Ordner werfen und hoffen, dass es funktioniert. Verwende ein eigenes CurseForge-Profil für das Modpack.

Die mitgelieferte ZIP-Datei enthält bereits einen fertigen mods-Ordner. Dieser muss in den richtigen CurseForge-Minecraft-Ordner.

01 // DEPLOYMENT

Modpack installieren

STEP 01

CurseForge installieren

Falls du CurseForge noch nicht benutzt, installiere den CurseForge Launcher und öffne Minecraft darüber.

Wichtig: Du brauchst keine einzelnen Mods herunterzuladen. Das Modpack bringt seine Mod-Dateien bereits mit.

STEP 02

Ein eigenes CurseForge-Profil erstellen

Öffne in CurseForge den Bereich für Minecraft.

Erstelle dort ein eigenes Profil für Rise of Nations.

Minecraft → Create Custom Profile

Verwende dabei exakt die Minecraft-Version und den Modloader, die für das Modpack angegeben sind.

STEP 03

Das Profil einmal starten

Starte das neue Profil einmal.

Dadurch erstellt CurseForge den benötigten Minecraft-Ordner für dieses Profil.

✓ Danach Minecraft wieder schließen.

STEP 04

Den richtigen Ordner öffnen

Gehe in CurseForge wieder zu deinem Profil.

⋯ → Open Folder

Genau dieser Ordner ist wichtig.

Nicht irgendein Minecraft-Ordner aus Windows öffnen. Nicht den normalen .minecraft-Ordner suchen, wenn CurseForge einen eigenen Profilordner verwendet.

STEP 05

Die ZIP-Datei öffnen

Öffne jetzt die heruntergeladene Datei:

im minecraft ordner entpacken.zip

Darin befindet sich bereits ein Ordner:

mods

STEP 06

Den mods-Ordner kopieren

Öffne den mods-Ordner aus der ZIP-Datei.

Markiere den Inhalt beziehungsweise den mods-Ordner und kopiere ihn in den CurseForge-Profilordner aus Schritt 4.

Am Ende sollte es ungefähr so aussehen:

CurseForge-Profil → mods → viele .jar-Dateien

STEP 07

CurseForge starten

Öffne CurseForge erneut und starte dein Rise-of-Nations-Profil.

✓ Wenn Minecraft startet und die Mods geladen werden, war die Installation erfolgreich.

STEP 08

Wenn CurseForge meldet, dass Mods fehlen

Keine Panik.

Prüfe zuerst, ob du wirklich den Open Folder-Ordner des richtigen CurseForge-Profils verwendet hast.

Der häufigste Fehler ist, dass die Mods in einen anderen Minecraft-Ordner kopiert wurden.

02 // GOLDEN RULE

Die wichtigste Regel

Wenn du nur eine Sache aus dieser Anleitung merkst:

Nicht selbst nach dem Minecraft-Ordner suchen.

Erstelle dein CurseForge-Profil → öffne die ⋯-Optionen → Open Folder → und genau dort kommen die Mod-Dateien hinein.

Dadurch landet das Modpack in dem Ordner, den CurseForge tatsächlich benutzt.

03 // SYSTEM CONFIGURATION

Empfohlene Einstellungen

RAM / ARBEITSSPEICHER

Für ein größeres Modpack sollte Minecraft genügend RAM bekommen. Zu wenig RAM führt zu Abstürzen, langen Ladezeiten und Nachladerucklern.

RENDER DISTANCE

Wenn du Performance-Probleme hast, reduziere zuerst die Sichtweite. Eine niedrigere Sichtweite bringt meistens deutlich mehr FPS.

SIMULATION DISTANCE

Bei schwächeren PCs ebenfalls reduzieren. Die Simulation Distance beeinflusst, wie viel in der Welt gleichzeitig aktiv bleibt.

SHADER

Wenn das Spiel stark ruckelt, zunächst ohne Shader spielen. Shader können bei einem großen Modpack sehr viel zusätzliche GPU-Leistung benötigen.

PARTICLES

Bei Performance-Problemen auf reduziert stellen. Besonders große Maschinen, Explosionen und Effekte können viele Partikel erzeugen.

ENTITY DISTANCE

Falls viele Tiere, Maschinen oder andere Entities vorhanden sind und die FPS sinken, kann diese Einstellung reduziert werden.

04 // FREQUENTLY ASKED QUESTIONS

Häufige Fragen

Kann ich die ZIP einfach doppelklicken?

Ja, du kannst sie öffnen. Wichtig ist aber, dass der enthaltene mods-Ordner anschließend in den richtigen CurseForge-Profilordner kopiert wird.

Muss ich jeden Mod einzeln installieren?

Nein. Genau das soll die ZIP verhindern. Die Mod-Dateien sind bereits vorbereitet.

Warum sehe ich keine Mods?

Meistens wurde der falsche Ordner geöffnet. Verwende immer ⋯ → Open Folder direkt beim richtigen CurseForge-Profil.

Kann ich mein normales Minecraft verwenden?

Für das Modpack solltest du das dafür vorgesehene CurseForge-Profil verwenden. Dadurch bleiben deine normalen Minecraft-Installationen sauber.

Das Spiel stürzt beim Start ab. Was mache ich?

Prüfe zuerst Minecraft-Version, Modloader und Profil. Danach kontrolliere, ob die Mods wirklich im richtigen Profilordner liegen.

Das Spiel lädt extrem lange.

Bei großen Modpacks kann der erste Start deutlich länger dauern. Nicht sofort mehrfach auf Start klicken. Gib Minecraft Zeit, die Mods zu laden.

Ich habe nur 8 GB RAM.

Das kann funktionieren, abhängig vom restlichen System. Allerdings muss Windows ebenfalls RAM verwenden. Wenn möglich, sollte Minecraft nicht den gesamten verfügbaren Arbeitsspeicher bekommen.

Kann ich zusätzliche Mods installieren?

Nicht empfohlen, solange du nicht weißt, ob sie mit dem Modpack kompatibel sind. Ein zusätzlicher Mod kann Abhängigkeiten, Konflikte oder Abstürze verursachen.

Kann ich Mods entfernen?

Ebenfalls nicht empfohlen. Viele Mods können voneinander abhängig sein. Entferne Mods nur, wenn ausdrücklich bekannt ist, dass sie optional sind.

Mein Spiel friert kurz ein.

Kurze Freezes können beim Laden neuer Chunks, beim Start oder bei großen Maschinen auftreten. Wenn das Spiel danach weiterläuft, ist das nicht automatisch ein Fehler.

Ich bekomme eine Java-Fehlermeldung.

Prüfe zuerst, ob CurseForge die für die verwendete Minecraft-Version benötigte Java-Version verwendet. Verwende möglichst die von CurseForge vorgeschlagene beziehungsweise integrierte Java-Konfiguration.

Meine FPS sind sehr niedrig.

Shader deaktivieren, Render Distance reduzieren, Simulation Distance reduzieren und Partikel reduzieren. Danach erneut testen.

05 // TROUBLESHOOTING

Wenn etwas nicht funktioniert

🔴 Minecraft startet gar nicht

1. CurseForge-Profil kontrollieren. 2. Minecraft-Version kontrollieren. 3. Modloader kontrollieren. 4. Mods-Ordner kontrollieren. 5. Fehlermeldung beziehungsweise Crash-Log aufbewahren.

🔴 „Missing Mods“ / „Mod fehlt“

Fast immer bedeutet das, dass Mods fehlen oder nicht im richtigen Profil liegen. Öffne erneut ⋯ → Open Folder und kontrolliere den mods-Ordner.

🔴 Spiel stürzt nach einem neuen Mod ab

Wenn du kurz davor einen zusätzlichen Mod installiert oder entfernt hast, diesen zuerst wieder zurücksetzen. Das offizielle Modpack möglichst unverändert verwenden.

🔴 Schwarzer Bildschirm / sehr lange Ladezeit

Zuerst warten. Große Modpacks können beim ersten Start lange brauchen. Wenn es dauerhaft hängen bleibt, Minecraft schließen, erneut starten und anschließend die Log- oder Crash-Datei sichern.

🔴 Welt lädt, aber alles ruckelt

Shader ausschalten → Render Distance reduzieren → Simulation Distance reduzieren → Partikel reduzieren. Wenn es danach deutlich besser läuft, liegt das Problem wahrscheinlich an der Systemleistung.

🔴 Ich habe keine Ahnung, was kaputt ist

Kein Problem. Nicht zehn Sachen gleichzeitig verändern. Schicke im Support möglichst die Fehlermeldung, einen Screenshot und – wenn vorhanden – den Crash-Log. So lässt sich der Fehler wesentlich schneller finden.

06 // SUPPORT PROTOCOL

Was du dem Support schicken solltest

Bitte nicht nur „geht nicht“ schreiben. 😭

Je mehr Informationen vorhanden sind, desto schneller kann geholfen werden.

  • Was wolltest du machen?
  • Was ist stattdessen passiert?
  • Welche Fehlermeldung erscheint?
  • Screenshot der Fehlermeldung
  • Crash-Log, falls vorhanden
  • Welche Minecraft-Version?
  • Welches CurseForge-Profil?
  • Wurde etwas am Modpack verändert?

✓ Mit diesen Informationen kann der Fehler meistens wesentlich schneller eingegrenzt werden.

NO PANIC // SYSTEM RECOVERY

Wenn die Installation nicht funktioniert, bedeutet das nicht, dass dein PC kaputt ist. In den meisten Fällen wurde entweder der falsche Ordner verwendet, eine Einstellung passt nicht oder eine Datei fehlt.

Erst die Grundlagen prüfen. Dann weitergehen.

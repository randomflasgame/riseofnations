CREATE SUBMARINE

Create Submarine erweitert die industrielle Welt von Create um unterwasserbezogene Technik und ermöglicht es, mechanische Create-Systeme mit maritimer Infrastruktur zu verbinden. Damit wird die Unterwasserwelt zu einem zusätzlichen Einsatzgebiet für technische Konstruktionen.

01 // SYSTEM OVERVIEW

Was ist Create Submarine?

Create Submarine ist eine Erweiterung für das Create-System, die sich auf Konstruktionen und Gameplay rund um Unterwasserfahrzeuge konzentriert.

Der interessante Teil für RISE OF NATIONS liegt dabei nicht nur im Fahrzeug selbst. Unterwasserfahrzeuge können als Bestandteil einer größeren Infrastruktur betrachtet werden: Hafen, Werft, Versorgung, Lagerung, Expeditionen und industrielle Produktion.

NAVAL DOCTRINE

Behandle ein Unterwasserfahrzeug nicht als isoliertes Spielzeug. Plane es als Teil eines kompletten Versorgungssystems.

02 // CREATE FOUNDATION

Grundwissen über Create

Für die effiziente Nutzung von Create Submarine sind die Grundlagen von Create besonders wichtig.

  • Mechanische Energie
  • Rotation
  • Contraptions
  • Materialtransport
  • Automatisierung
  • Maschinenbau

Spieler ohne Create-Erfahrung sollten zunächst einfache mechanische Anlagen bauen, bevor komplexe mobile Systeme geplant werden.

04 // MOBILE MACHINERY

Mobile Create-Systeme

Ein wichtiger Gedanke bei Create-basierten Fahrzeugen ist, dass eine Maschine nicht zwingend an einem festen Standort betrieben werden muss.

Mobile Konstruktionen ermöglichen es, technische Systeme direkt dorthin zu bringen, wo sie benötigt werden.

  • Mobile Arbeitsplattformen
  • Transportkonstruktionen
  • Expeditionsfahrzeuge
  • Unterwasseroperationen
  • Mobile Versorgung
05 // NAVIGATION

Navigation und Orientierung

Unterwasseroperationen sind schwieriger zu überblicken als normale Landexpeditionen. Deshalb sollte die Navigation bereits vor dem Einsatz geplant werden.

Vor dem Einsatz

  • Zielgebiet festlegen.
  • Startpunkt markieren.
  • Versorgung sicherstellen.
  • Rückweg berücksichtigen.
  • Transportkapazität planen.
NAVIGATION WARNING

Ein mobiles Fahrzeug sollte niemals nur für den Hinweg geplant werden. Rückkehr und Versorgung gehören zur eigentlichen Missionsplanung.

07 // LOGISTICS

Versorgungssysteme

Die eigentliche Stärke entsteht durch die Verbindung mit den restlichen Create-Systemen des Modpacks.

Eine Werft kann beispielsweise automatisch mit Rohstofflagern und Produktionsanlagen verbunden werden.

  1. Rohstoffe beschaffen.
  2. Material zur Werft transportieren.
  3. Fahrzeug vorbereiten.
  4. Expedition durchführen.
  5. Erbeutete oder geförderte Ressourcen zurückführen.
  6. Ressourcen in der Hauptfabrik weiterverarbeiten.
08 // EXPLORATION

Unterwasser-Expeditionen

Unterwassergebiete können als eigenständige Expeditionsbereiche behandelt werden.

  • Ressourcensuche
  • Strukturerkundung
  • Entdeckung unbekannter Gebiete
  • Transportmissionen
  • Dokumentation interessanter Fundorte
EXPLORATION PRINCIPLE

Expeditionen werden effizienter, wenn bekannte Fundorte dokumentiert und später gezielt erneut angefahren werden.

12 // TROUBLESHOOTING

Fehleranalyse

Das Fahrzeug bewegt sich nicht

Zuerst sollten Antrieb, Energieversorgung und die grundlegende Konstruktion überprüft werden.

Die Konstruktion verhält sich unerwartet

Prüfe, ob alle beteiligten Create-Komponenten korrekt verbunden sind und ob das Fahrzeugkonzept mit den Voraussetzungen der verwendeten Modversion kompatibel ist.

Die Expedition wird zu kompliziert

Reduziere die Zahl der gleichzeitig verwendeten Systeme. Ein kleineres, zuverlässiges Fahrzeug ist häufig besser als eine überladene mobile Fabrik.

Material fehlt während der Mission

Erstelle vor dem Einsatz eine feste Versorgungsliste und definiere Mindestreserven.

13 // ADVANCED OPERATIONS

Fortgeschrittene Nutzung

Fortgeschrittene Spieler können mobile Technik mit einer dauerhaft betriebenen Industrie kombinieren.

  1. Hauptfabrik produziert benötigte Materialien.
  2. Logistik transportiert sie zum Hafen.
  3. Werft bereitet das Fahrzeug vor.
  4. Unterwasserexpedition sammelt Ressourcen.
  5. Rücktransport bringt die Ladung zurück.
  6. Die Fabrik verarbeitet die neuen Ressourcen.

Damit entsteht ein geschlossener Kreislauf aus Industrie, Transport und Exploration.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

Create Submarine erweitert Create um eine mobile, maritime Perspektive. Die größte Stärke entsteht jedoch erst durch die Verbindung mit der restlichen Infrastruktur des Modpacks.

  • Fahrzeuge als Teil eines größeren Systems betrachten.
  • Werften als logistische Knotenpunkte planen.
  • Expeditionen vorab vorbereiten.
  • Versorgung und Rückweg berücksichtigen.
  • JEI für benötigte Produktionsketten nutzen.
  • Unterwassertechnik mit Create-Industrie verbinden.
FINAL PRINCIPLE

Das eigentliche Ziel ist nicht nur ein U-Boot. Das Ziel ist ein funktionierendes Netzwerk aus Werft, Industrie, Logistik und Exploration.

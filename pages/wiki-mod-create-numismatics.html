CREATE NUMISMATICS

Create Numismatics erweitert Create um ein wirtschaftliches System rund um Münzen, Geldverarbeitung und technische Handelsmechaniken. Dadurch kann eine industrielle Produktion direkt mit einem wirtschaftlichen Kreislauf verbunden werden.

01 // SYSTEM OVERVIEW

Was ist Create Numismatics?

Create Numismatics verbindet die mechanische Welt von Create mit einem Geld- und Handelssystem.

Münzen und wirtschaftliche Prozesse können dadurch in automatisierte Produktions- und Handelsketten integriert werden.

ECONOMIC PRINCIPLE

Geld ist in einer funktionierenden Wirtschaft nicht nur ein Gegenstand im Inventar. Es ist ein Mittel, mit dem Warenströme, Handel und Dienstleistungen miteinander verbunden werden.

02 // CURRENCY

Währung verstehen

Das zentrale Konzept von Create Numismatics ist die Verwendung von Münzen als wirtschaftliches Medium.

Für RISE OF NATIONS ist besonders interessant, dass wirtschaftliche Systeme mit bestehenden Transport- und Produktionssystemen verbunden werden können.

03 // MINTING

Münzen und Produktion

Ein wirtschaftliches System benötigt eine Quelle für seine Währung. Die genaue Herstellung und die verfügbaren Produktionsschritte hängen von der installierten Version und den jeweiligen Rezepten ab.

Nutze JEI, um die tatsächlich verfügbaren Rezepte zu prüfen. Besonders wichtig ist die Unterscheidung zwischen Rohmaterial, Zwischenprodukt und fertiger Währung.

  1. Benötigtes Geldsystem bestimmen.
  2. Herstellungsweg in JEI prüfen.
  3. Benötigte Rohstoffe beschaffen.
  4. Produktionsanlage errichten.
  5. Geld sicher lagern.

05 // TRADING

Handelssysteme

Create Numismatics eignet sich besonders für Spieler, die eine eigene wirtschaftliche Infrastruktur aufbauen möchten.

Mögliche Handelsmodelle

  • Spieler verkaufen Rohstoffe.
  • Spieler verkaufen verarbeitete Produkte.
  • Spieler bieten Dienstleistungen an.
  • Spieler betreiben eigene Geschäfte.
  • Spieler nutzen zentrale Handelsplätze.
MARKET PRINCIPLE

Eine funktionierende Wirtschaft benötigt sowohl Produzenten als auch Abnehmer. Geld allein erzeugt keinen Handel.

06 // STORAGE

Geld sicher verwalten

Währung sollte genauso geplant gelagert werden wie wertvolle Rohstoffe.

  • Persönliche Reserve getrennt halten.
  • Geschäftsvermögen dokumentieren.
  • Produktionsmittel vom Handelskapital trennen.
  • Große Geldmengen nicht unnötig offen herumliegen lassen.
SECURITY

In einem Multiplayer-Modpack sollte der Zugriff auf wirtschaftlich wichtige Lagerbereiche bewusst geplant werden.

07 // AUTOMATION

Wirtschaft automatisieren

Die Create-Technik ermöglicht es, wirtschaftliche Prozesse stärker in bestehende Fabriken einzubauen.

  1. Produktionsanlage errichten.
  2. Warenstrom automatisieren.
  3. Handelsware zentral lagern.
  4. Währungsfluss separat verwalten.
  5. Handelsstation oder Markt anbinden.

Die genaue technische Umsetzung hängt von den im Modpack verwendeten wirtschaftlichen Addons und deren Rezepten ab.

11 // ECONOMIC BALANCE

Eine stabile Wirtschaft

Eine gesunde Serverwirtschaft benötigt ein Verhältnis zwischen Geldmenge, Warenangebot und Nachfrage.

  • Nicht unbegrenzt Währung erzeugen.
  • Handel mit echten Waren verbinden.
  • Seltene Produkte wertvoll halten.
  • Produktionskosten berücksichtigen.
  • Preise regelmäßig an die Serverwirtschaft anpassen.
ECONOMIC WARNING

Eine stark automatisierte Geldproduktion kann ein Wirtschaftssystem schnell aus dem Gleichgewicht bringen. Produktionskosten und Geldmenge sollten deshalb bewusst gestaltet werden.

12 // TROUBLESHOOTING

Fehleranalyse

Ein Rezept ist nicht auffindbar

Nutze JEI und prüfe die tatsächlich installierte Modversion. Bei großen Modpacks können Rezepte durch andere Mods ergänzt oder verändert werden.

Die Wirtschaft funktioniert nicht

Prüfe zunächst, ob tatsächlich Waren angeboten werden und ob Spieler einen Grund haben, diese Waren zu kaufen.

Währung ist zu häufig vorhanden

Überprüfe die Geldproduktion und die Quellen, aus denen Spieler Währung erhalten.

Handel konzentriert sich auf wenige Spieler

Fördere unterschiedliche Produktionsrollen und schaffe mehrere sinnvolle Handelsmöglichkeiten.

14 // ADVANCED ECONOMY

Fortgeschrittene wirtschaftliche Systeme

Eine fortgeschrittene Serverwirtschaft kann mehrere Ebenen besitzen.

  1. Rohstoffproduktion.
  2. Verarbeitung.
  3. Industrieproduktion.
  4. Logistik.
  5. Handel.
  6. Währung.
  7. Investitionen in neue Produktionsanlagen.

Damit entsteht ein Kreislauf, in dem wirtschaftlicher Erfolg direkt wieder in neue Produktionsmöglichkeiten investiert werden kann.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

Create Numismatics ist besonders interessant, wenn auf dem Server tatsächlich eine Spielerwirtschaft entstehen soll.

  • Währung als Teil eines Warenkreislaufs betrachten.
  • Produktion und Handel voneinander trennen.
  • Spieler zu unterschiedlichen Rollen motivieren.
  • Marktplätze mit Logistik verbinden.
  • Währungsproduktion kontrollieren.
  • JEI für konkrete Rezepte verwenden.
FINAL PRINCIPLE

Eine funktionierende Wirtschaft entsteht nicht durch möglichst viel Geld, sondern durch wertvolle Waren, sinnvollen Handel und funktionierende Produktionsketten.

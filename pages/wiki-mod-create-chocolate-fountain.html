CREATE CHOCOLATE FOUNTAIN

Create Chocolate Fountain ergänzt das Create-Ökosystem um eine thematisch auf Schokolade und deren Verarbeitung ausgerichtete Produktionsmechanik. Der Mod eignet sich besonders für automatisierte Lebensmittelanlagen und dekorative gastronomische Konstruktionen.

01 // SYSTEM OVERVIEW

Was ist Create Chocolate Fountain?

Der Mod erweitert Create um Inhalte rund um Schokolade und gastronomische Verarbeitung. Dabei verbindet er Produktionsmechaniken mit einem auffälligen dekorativen Element.

Dadurch eignet sich das System sowohl für automatisierte Lebensmittelproduktion als auch für Cafés, Restaurants, Märkte und andere öffentliche Gebäude.

CORE PRINCIPLE

Schokolade kann innerhalb einer Create-Anlage nicht nur hergestellt, sondern als Teil eines sichtbaren Produktionsprozesses präsentiert werden.

02 // CHOCOLATE PRODUCTION

Schokoladenproduktion

Wie bei anderen Create-Erweiterungen sollte auch die Schokoladenproduktion als Produktionskette betrachtet werden.

  1. Ausgangsmaterialien bereitstellen.
  2. Verarbeitungsschritte durchführen.
  3. Schokoladenprodukt herstellen.
  4. Produkt zwischenlagern.
  5. Produkt weiterverarbeiten oder ausgeben.
03 // INGREDIENT LOGISTICS

Zutatenversorgung

Eine automatisierte Anlage benötigt einen stabilen Materialfluss.

  • Rohstoffe zentral bereitstellen.
  • Verarbeitungsschritte voneinander trennen.
  • Zwischenprodukte puffern.
  • Fertige Produkte automatisch abtransportieren.
LOGISTICS WARNING

Bei mehreren Produktionslinien sollte die Zutatenversorgung ausreichend dimensioniert sein. Ein einzelner fehlender Bestandteil kann sonst die gesamte Kette stoppen.

04 // FLUID LOGISTICS

Flüssigkeiten und Schokolade

Flüssigkeitsbasierte Produktionsprozesse benötigen besonders klare Leitungs- und Speicherstrukturen.

  • Tanks als Puffer einsetzen.
  • Pumpen sinnvoll positionieren.
  • Leitungen übersichtlich führen.
  • Ein- und Ausgänge eindeutig definieren.

In großen Fabriken empfiehlt sich eine zentrale Flüssigkeitsversorgung mit lokalen Puffern an den einzelnen Produktionsstationen.

05 // FOUNTAIN SYSTEM

Die Schokoladenfontäne

Das namensgebende Element eignet sich besonders für sichtbare gastronomische Anlagen.

Statt die Verarbeitung vollständig hinter Wänden zu verstecken, kann die Fontäne als Teil des Designs präsentiert werden.

  • Café-Theken.
  • Restaurants.
  • Marktplätze.
  • Fabrikhallen mit Lebensmittelproduktion.
  • Event- und Festgebäude.
06 // AUTOMATION

Automatisierung mit Create

Der eigentliche Mehrwert entsteht durch die Verbindung mit den normalen Create-Transport- und Automationssystemen.

07 // BUFFER SYSTEMS

Puffer und Lager

Zwischenlager sind besonders hilfreich, wenn die Schokoladenproduktion mit anderen Lebensmittelketten verbunden wird.

  • Rohstoffpuffer.
  • Flüssigkeitspuffer.
  • Zwischenproduktlager.
  • Fertigwarenlager.
STABILITY

Ein Puffer entkoppelt Produktionsschritte voneinander und verhindert, dass kleine Schwankungen sofort die komplette Anlage blockieren.

08 // CAFÉ INTEGRATION

Integration in ein Café

Eine Schokoladenfontäne eignet sich besonders für öffentliche Gebäude.

  1. Zutatenlager im hinteren Bereich.
  2. Produktionsstation in der Küche.
  3. Schokoladenversorgung zur Theke.
  4. Fontäne als sichtbares Zentrum.
  5. Ausgabe oder Dekoration im Gästebereich.
09 // INDUSTRIAL FOOD FACTORY

12 // TROUBLESHOOTING

Fehleranalyse

Keine Produktion

Prüfe zuerst, ob alle benötigten Ausgangsmaterialien verfügbar sind.

Flüssigkeit erreicht die Anlage nicht

Kontrolliere Tank, Pumpe und Leitungsverbindung.

Output wird nicht weitertransportiert

Prüfe die angeschlossenen Funnels, Belts und Lager.

Produktionskette stoppt sporadisch

Suche nach fehlenden Puffern oder einem Produktionsschritt, der langsamer als die übrige Anlage arbeitet.

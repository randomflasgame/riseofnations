CREATE TREADMILL

Create Treadmill erweitert das Create-Ökosystem um eine ungewöhnliche Möglichkeit, mechanische Energie über die Aktivität von Entitäten zu erzeugen. Damit entstehen interessante Systeme für automatische Anlagen, Testaufbauten und kreative Energiegewinnung.

01 // SYSTEM OVERVIEW

Was ist Create Treadmill?

Create Treadmill verbindet das Create-Energiesystem mit einer mechanischen Konstruktion, die Bewegung von Entitäten zur Erzeugung beziehungsweise Bereitstellung mechanischer Leistung nutzt.

Dadurch entsteht eine alternative und vor allem experimentelle Möglichkeit, mechanische Systeme anzutreiben.

CORE IDEA

Bewegung wird in mechanische Energie umgewandelt und anschließend in ein bestehendes Create-System eingespeist.

02 // CREATE POWER

Grundverständnis von Create-Energie

Create arbeitet bei seinen mechanischen Systemen mit Rotation, Geschwindigkeit und Belastung. Eine zusätzliche Energiequelle muss daher sinnvoll in das vorhandene Antriebssystem integriert werden.

  • Mechanische Energie erzeugen.
  • Rotation weiterleiten.
  • Geschwindigkeit kontrollieren.
  • Belastung der Maschinen berücksichtigen.
  • Produktionsmaschinen an das Netz anschließen.
03 // TREADMILL CONCEPT

Das Grundprinzip

Das Treadmill-Konzept basiert auf Bewegung. Eine geeignete Entität bewegt sich auf beziehungsweise innerhalb der vorgesehenen Konstruktion und erzeugt dadurch die mechanische Leistung des Systems.

  1. Treadmill-System aufbauen.
  2. Entität bereitstellen.
  3. Bewegung ermöglichen.
  4. Mechanische Energie abgreifen.
  5. Energie an das Create-Netz weiterleiten.

05 // SPEED MANAGEMENT

Geschwindigkeit kontrollieren

In Create ist nicht ausschließlich die Existenz von Rotation wichtig. Die Geschwindigkeit muss zur jeweiligen Maschine passen.

  • Zu hohe Geschwindigkeit vermeiden.
  • Zu niedrige Geschwindigkeit erkennen.
  • Übersetzungen sinnvoll einsetzen.
  • Belastung des Netzwerks überwachen.
ENGINEERING NOTE

Bei einem neuen Antrieb sollte zunächst ein kleines Testsystem gebaut werden. Erst danach lohnt sich die Integration in eine große Fabrik.

06 // ENTITY MANAGEMENT

Entitäten im System

Da das Konzept auf beweglichen Entitäten basiert, sollte der Bereich entsprechend abgesichert werden.

  • Ausreichend Platz bereitstellen.
  • Entitäten innerhalb des Systems halten.
  • Ungewolltes Entkommen verhindern.
  • Bereich gegen externe Einflüsse schützen.
  • Wartungszugang einplanen.
07 // AUTOMATION

Automatisierte Energieversorgung

Das System kann als permanente Energiequelle für eine kleinere oder experimentelle Create-Anlage dienen.

  1. Energiequelle installieren.
  2. Mechanisches Netzwerk anschließen.
  3. Übertragung überprüfen.
  4. Produktionsmaschine anschließen.
  5. System unter realer Last testen.

10 // EFFICIENCY

Effizienz beurteilen

Nicht jede Energiequelle ist automatisch die beste Lösung. Für große Produktionsanlagen sollte immer geprüft werden, ob andere Create-Antriebe geeigneter sind.

KRITERIUM FRAGE

STABILITY Bleibt das System dauerhaft aktiv?
SPACE Wie viel Platz benötigt die Anlage?
MAINTENANCE Wie leicht ist das System zu warten?
11 // TROUBLESHOOTING

Typische Probleme

Keine mechanische Leistung

Prüfe zunächst, ob das Treadmill korrekt aufgebaut wurde und ob sich die vorgesehene Entität tatsächlich bewegt.

Maschine läuft nicht

Kontrolliere die Verbindung zwischen Energiequelle und Maschine sowie die Geschwindigkeit des Netzwerks.

System stoppt

Prüfe, ob die Entität noch vorhanden ist und ob die Bewegungsbedingungen weiterhin erfüllt werden.

Fabrik ist überlastet

Reduziere die Last oder teile das mechanische Netzwerk in mehrere unabhängige Produktionsbereiche auf.

12 // ADVANCED SYSTEMS

Mehrere Energiequellen

Eine größere Fabrik kann mehrere mechanische Quellen besitzen. Dabei sollte das Netzwerk sinnvoll strukturiert werden.

  • Energiequellen nach Produktionsbereich trennen.
  • Große Maschinen nicht unnötig an kleine Netze hängen.
  • Übertragungswege kurz halten.
  • Einzelne Produktionslinien modular gestalten.
13 // BUILDING APPLICATION

Integration in Industriegebäude

Das Treadmill-System eignet sich hervorragend für sichtbare Technik.

  • Glaswände für sichtbare Mechanik.
  • Wartungsstege.
  • Technikräume.
  • Beleuchtung und Warnanzeigen.
  • Separate Maschinenhallen.

Damit kann aus einer rein technischen Mechanik ein glaubwürdiger Bestandteil einer Fabrikarchitektur werden.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Das Treadmill-Konzept nutzt Bewegung als Energiequelle.
  • Erst klein testen, dann in große Fabriken integrieren.
  • Geschwindigkeit und Belastung des Create-Netzes beachten.
  • Entitäten zuverlässig im vorgesehenen Bereich halten.
  • Mechanische Netzwerke modular planen.
  • Für große Fabriken verschiedene Energiequellen vergleichen.
FINAL PRINCIPLE

Das interessanteste Energiesystem ist nicht immer das effizienteste. In Create zählt auch, wie gut eine technische Idee in die gesamte Fabrik integriert wird.

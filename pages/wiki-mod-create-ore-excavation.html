CREATE ORE EXCAVATION

Create Ore Excavation erweitert die Rohstoffgewinnung innerhalb des Create-Ökosystems. Das System konzentriert sich auf die effiziente Gewinnung von Erz und anderen unterirdischen Ressourcen und eignet sich besonders für größere industrielle Produktionsketten.

01 // SYSTEM OVERVIEW

Was ist Create Ore Excavation?

Create Ore Excavation stellt Werkzeuge für eine automatisierte oder teilautomatisierte Rohstoffgewinnung bereit.

Damit lässt sich ein Teil der klassischen manuellen Mining-Arbeit in industrielle Produktionsketten überführen.

INDUSTRIAL PRINCIPLE

Das Ziel ist nicht einfach mehr Erz, sondern eine zuverlässige Rohstoffversorgung für eine größere Fabrik.

02 // WHY AUTOMATE MINING?

Warum Rohstoffgewinnung automatisieren?

Große Create-Fabriken benötigen erhebliche Mengen an Rohstoffen. Besonders bei Maschinen, Schienen, Komponenten und komplexen Produktionsketten kann manueller Abbau schnell zum Engpass werden.

  • Weniger manuelle Mining-Zeit
  • Planbare Rohstoffversorgung
  • Bessere Skalierbarkeit großer Fabriken
  • Integration in bestehende Logistik
  • Automatisierbare Materialzufuhr
03 // EXTRACTION SYSTEM

Das Extraktionsprinzip

Das grundlegende Konzept besteht darin, einen geeigneten Extraktionsmechanismus mit einer passenden Energie- und Materiallogistik zu verbinden.

BEREICH AUFGABE
EXTRACTION Rohstoffe gewinnen
POWER Maschine betreiben
OUTPUT Gewonnene Materialien sammeln
LOGISTICS Material weitertransportieren
04 // RESOURCE PLANNING

Welche Rohstoffe sollte man automatisieren?

Nicht jeder Rohstoff muss sofort automatisiert werden. Entscheidend ist, welche Materialien in der eigenen Produktionskette regelmäßig benötigt werden.

Hohe Priorität

  • Häufig benötigte Metalle
  • Rohstoffe für Create-Komponenten
  • Materialien für Maschinen
  • Rohstoffe für große Bauprojekte

Niedrige Priorität

Materialien, die nur selten benötigt werden, können weiterhin manuell gewonnen oder über andere Produktionswege beschafft werden.

05 // INDUSTRIAL PIPELINE

Von der Mine zur Fabrik

  1. Rohstoffbedarf bestimmen.
  2. Extraktionsanlage errichten.
  3. Energieversorgung bereitstellen.
  4. Ausgabe sammeln.
  5. Material sortieren.
  6. Material in das Hauptlager transportieren.
  7. Produktionsmaschinen versorgen.
LOGISTICS FIRST

Eine starke Mining-Anlage ist nutzlos, wenn ihre Ausgabe nicht zuverlässig abtransportiert und gelagert wird.

07 // POWER REQUIREMENTS

Energie und Maschinenbetrieb

Eine automatisierte Extraktionsanlage sollte in die Energieplanung der gesamten Fabrik eingebunden werden.

Gerade große Produktionsanlagen können gleichzeitig erhebliche mechanische oder elektrische Lasten erzeugen.

  • Eigene Energieversorgung prüfen.
  • Reserven einplanen.
  • Neue Verbraucher nicht blind anschließen.
  • Produktionsspitzen berücksichtigen.
08 // STORAGE

Materiallagerung

Die gewonnene Ressource sollte nicht einfach irgendwo in Kisten landen. Ein industrielles Lager benötigt eine klare Struktur.

Empfohlener Aufbau

  1. Extraktionsanlage
  2. Ausgabepuffer
  3. Sortierung
  4. Rohstofflager
  5. Produktionslager

Sophisticated Storage und Sophisticated Backpacks können dabei als zusätzliche Lager- und Logistikkomponenten dienen.

09 // PRODUCTION CHAIN

Rohstoffbedarf richtig planen

Der beste Ansatz besteht darin, von der gewünschten Endproduktion rückwärts zu planen.

  1. Endprodukt bestimmen.
  2. Benötigte Zwischenprodukte ermitteln.
  3. Benötigte Rohstoffe bestimmen.
  4. Verbrauch pro Produktionskette abschätzen.
  5. Mining-Kapazität entsprechend dimensionieren.
JEI INTEGRATION

JEI eignet sich hervorragend, um die benötigten Produktionsketten und Rezeptabhängigkeiten zu verfolgen.

10 // COMMON FAILURES

Häufige Probleme

Die Maschine produziert nicht

Zuerst Energieversorgung, Aktivierung und die benötigten Voraussetzungen prüfen.

Das Lager läuft über

Die Extraktion ist möglicherweise deutlich größer als der tatsächliche Verbrauch. In diesem Fall sollte die Lagerkapazität oder die Produktionsplanung angepasst werden.

Die Fabrik bekommt nicht genug Rohstoffe

Prüfe nicht nur die Mining-Menge, sondern auch Transport, Sortierung und Lagerung.

11 // SCALING

Von der kleinen Anlage zum Bergbaukomplex

Ein automatisiertes System sollte modular aufgebaut werden. So kann die Kapazität später erweitert werden, ohne die komplette Infrastruktur neu zu bauen.

STUFE ANLAGE
I Kleine Einzelanlage
II Mehrere Extraktionsmaschinen
III Zentrales Rohstofflager
IV Automatisierte Sortierung
V Großes industrielles Bergbauzentrum
12 // BASE DESIGN

Bergbau als Infrastruktur

Für RISE OF NATIONS kann die Rohstoffgewinnung als eigener Industriebereich innerhalb einer Stadt oder Basis geplant werden.

  • Mine
  • Förderanlage
  • Transportwege
  • Verarbeitungsanlage
  • Rohstofflager
  • Hauptfabrik

Dadurch wird aus einer einzelnen Maschine ein vollständiger industrieller Wirtschaftskreislauf.

13 // ADVANCED STRATEGY

Fortgeschrittene Planung

Fortgeschrittene Spieler sollten Mining nicht isoliert betrachten. Die Kapazität sollte auf die gesamte Produktionsinfrastruktur abgestimmt sein.

  • Rohstoffverbrauch dokumentieren.
  • Produktionsengpässe identifizieren.
  • Mining-Kapazität erweitern.
  • Transportwege optimieren.
  • Lagerbestände überwachen.
  • Überproduktion vermeiden.
EFFICIENCY WARNING

Mehr Mining ist nicht automatisch besser. Eine überdimensionierte Anlage verbraucht Ressourcen und Infrastruktur, ohne einen echten Produktionsvorteil zu erzeugen.

14 // RISE OF NATIONS DOCTRINE

Die industrielle Rohstoffbasis

Create Ore Excavation ist besonders interessant, sobald die eigene Basis einen hohen Rohstoffbedarf entwickelt.

Der entscheidende Gedanke lautet: Rohstoffgewinnung ist der Anfang der Produktionskette.

Wer Mining, Lagerung, Transport und Verarbeitung gemeinsam plant, kann deutlich größere industrielle Systeme betreiben, ohne ständig manuell eingreifen zu müssen.

CREATE VIBRANT VAULTS

Create Vibrant Vaults erweitert das Lager- und Materialhandling innerhalb des Create-Ökosystems. Der Schwerpunkt liegt auf großen, übersichtlichen Lagerlösungen und der Integration dieser Lager in automatisierte Produktionsanlagen.

01 // SYSTEM OVERVIEW

Was ist Create Vibrant Vaults?

Create Vibrant Vaults ist eine Erweiterung für das Create-Umfeld, die sich auf die Lagerung großer Mengen von Gegenständen konzentriert.

Für umfangreiche Fabriken ist Lagerung genauso wichtig wie die eigentliche Produktion. Eine Maschine kann noch so schnell arbeiten – wenn der Output nicht zuverlässig aufgenommen wird, kommt die Produktionskette zum Stillstand.

CORE PRINCIPLE

Lagerkapazität und Materialfluss müssen gemeinsam geplant werden. Ein großes Lager allein macht noch keine gute Logistik.

02 // VAULT CONCEPT

Das Vault-Prinzip

Create verwendet bereits verschiedene Speicherlösungen. Vaults sind besonders interessant, wenn sehr große Mengen eines Materials zentral gesammelt werden sollen.

  • Große Materialmengen zentral lagern.
  • Produktionslinien mit einem gemeinsamen Speicher verbinden.
  • Rohstoffe als Produktionspuffer verwenden.
  • Fertige Produkte zentral sammeln.
  • Transportwege innerhalb der Fabrik reduzieren.

04 // MATERIAL FLOW

Vaults in Produktionsketten

Ein Vault sollte nicht isoliert betrachtet werden. Entscheidend ist die Verbindung zwischen Lager und Produktionssystem.

  1. Material wird in das Lager eingespeist.
  2. Ein Produktionssystem entnimmt benötigte Items.
  3. Die Maschine verarbeitet das Material.
  4. Der Output wird wieder eingelagert.
  5. Weitere Produktionsstufen greifen darauf zu.
LOGISTICS WARNING

Ein Lager kann zum Flaschenhals werden, wenn Ein- und Ausgabepunkte nicht ausreichend dimensioniert sind.

05 // INPUT SYSTEMS

Material in das Lager bringen

Für eine automatisierte Fabrik sollte das Befüllen eines zentralen Lagers möglichst automatisch erfolgen.

  • Belts für kontinuierliche Materialzufuhr.
  • Funnels für gezielte Übergaben.
  • Chutes für vertikale Transportwege.
  • Weitere Create-Logistiksysteme für komplexe Anlagen.

Besonders bei großen Fabriken lohnt sich eine klare Trennung zwischen Rohstoffannahme und interner Produktion.

06 // OUTPUT SYSTEMS

Material aus dem Lager entnehmen

Die Entnahme sollte genauso geplant werden wie die Einlagerung.

  • Produktionsmaschinen gezielt versorgen.
  • Endprodukte automatisch ausgeben.
  • Überschüsse für andere Produktionslinien reservieren.
  • Exportlinien an zentrale Lager anbinden.
DESIGN TIP

Ein zentraler Lagerbereich kann mehrere Fabrikmodule versorgen und dadurch doppelte Lagerstrukturen vermeiden.

07 // BUFFER MANAGEMENT

08 // FACTORY INTEGRATION

Integration mit Create

Der eigentliche Nutzen entsteht durch die Kombination mit Create-Produktions- und Logistiksystemen.

  • Mechanische Produktionsmaschinen.
  • Belts und Funnels.
  • Contraptions.
  • Train-basierte Logistik.
  • Automatisierte Produktionslinien.

Dadurch kann ein Vault sowohl als lokales Maschinenlager als auch als zentraler Speicher einer kompletten Fabrik dienen.

09 // TRAIN LOGISTICS

Vaults und Eisenbahnlogistik

In großen Industrieanlagen können Vaults als Schnittstelle zwischen Bahntransport und lokaler Produktion dienen.

  1. Zug bringt Rohstoffe an.
  2. Material wird in einen Empfangspuffer entladen.
  3. Vaults übernehmen die zentrale Lagerung.
  4. Produktionsanlagen beziehen Material aus dem Lager.
  5. Fertige Produkte werden erneut gesammelt.
  6. Ein weiterer Zug übernimmt den Export.
INDUSTRIAL NETWORK

Damit wird ein Lager nicht nur zum Container, sondern zu einem Knotenpunkt eines größeren Logistiknetzwerks.

10 // STORAGE DISTRICTS

Große Lagerzentren

Für sehr große Fabriken empfiehlt sich die Aufteilung verschiedener Materialgruppen auf eigene Lagerbereiche.

  • Metalle.
  • Erze.
  • Baumaterialien.
  • Komponenten.
  • Lebensmittel.
  • Flüssigkeitsbezogene Materialien.
  • Fertige Industrieprodukte.
11 // TROUBLESHOOTING

Fehleranalyse

Das Lager ist leer

Prüfe zuerst die vorgelagerte Produktions- oder Transportlinie. Das Problem liegt häufig nicht beim Lager, sondern beim fehlenden Input.

Das Lager füllt sich zu schnell

Prüfe den Output der angeschlossenen Produktionslinie und ob ein ausreichender Weitertransport vorhanden ist.

Die Produktion bekommt kein Material

Kontrolliere die Verbindung zwischen Lager und Maschine sowie Filter und Ein-/Ausgabepunkte.

Das Lager funktioniert, aber die Fabrik steht

Suche nach dem eigentlichen Flaschenhals. Ein Lager kann Material speichern, ersetzt aber keine ausreichende Transport- oder Produktionskapazität.

12 // DESIGN DOCTRINE

Wie sollte ein gutes Lager aussehen?

  1. Kurze Wege zwischen Produktion und Lager.
  2. Klare Ein- und Ausgänge.
  3. Genügend Pufferkapazität.
  4. Modulare Erweiterungsmöglichkeiten.
  5. Separate Bereiche für unterschiedliche Materialarten.
  6. Gute Sichtbarkeit des aktuellen Materialflusses.

Besonders bei Create sollte ein Lager nicht nur funktional, sondern auch wartbar gebaut werden.

13 // MULTIPLAYER INDUSTRY

Gemeinsame Lager für Spielergruppen

Auf einem Multiplayer-Server kann ein großes Lager als gemeinsamer Industriepunkt dienen.

  • Gemeinsame Rohstoffreserven.
  • Zentrale Baumaterialversorgung.
  • Produktionskomponenten für mehrere Spieler.
  • Exportlager für Handel.
  • Versorgung militärischer oder ziviler Projekte.
14 // ADVANCED SYSTEMS

Fortgeschrittene Lagerplanung

Bei sehr großen Anlagen sollte das Lager als Teil der Gesamtarchitektur betrachtet werden.

  • Rohstoffannahme getrennt vom Hauptlager.
  • Produktionspuffer zwischen Fertigungsschritten.
  • Endprodukte in einem separaten Bereich.
  • Exportmaterial automatisch bereitstellen.
  • Zugstationen direkt an Lagerbereiche anbinden.

16 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Ein Lager ist ein Teil der Produktionskette.
  • Input und Output müssen beide geplant werden.
  • Puffer verhindern unnötige Produktionsstopps.
  • Große Lager sollten modular aufgebaut sein.
  • Materialgruppen sinnvoll voneinander trennen.
  • Zuglogistik kann große Lagerzentren versorgen.
  • Ein Lager ersetzt keine ausreichende Transportkapazität.
FINAL PRINCIPLE

Ein gutes Lager hält nicht einfach Items fest. Es sorgt dafür, dass die richtige Menge Material genau dort verfügbar ist, wo die Industrie sie benötigt.

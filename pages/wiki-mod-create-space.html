01 // SYSTEM OVERVIEW

Was ist Create Space?

Create Space baut auf den industriellen Grundprinzipien von Create auf und führt diese in Richtung Raumfahrt weiter.

Dadurch entsteht eine zusätzliche Progressionsstufe: Spieler beginnen mit mechanischer Produktion auf der Oberfläche und können langfristig komplexere Raumfahrt- Infrastruktur entwickeln.

SPACE INDUSTRY PRINCIPLE

Raumfahrt sollte als Endpunkt einer langen Produktionskette betrachtet werden. Eine Rakete oder Raumstation beginnt nicht beim Start, sondern bei den Rohstoffen und Fabriken, die sie ermöglichen.

02 // PROGRESSION

Die industrielle Progression

Für eine funktionierende Raumfahrt-Infrastruktur empfiehlt sich eine schrittweise Entwicklung.

  1. Grundlegende Rohstoffversorgung.
  2. Create-Produktionsanlagen.
  3. Automatisierte Fabriken.
  4. Fortgeschrittene Materialien.
  5. Raumfahrtkomponenten.
  6. Startsysteme.
  7. Weltrauminfrastruktur.

Dadurch fühlt sich Raumfahrt wie eine tatsächliche technologische Weiterentwicklung an und nicht wie ein einzelnes Rezept.

04 // RESOURCE PIPELINE

Rohstoffversorgung

Eine Raumfahrtindustrie benötigt eine stabile Versorgung mit Materialien.

  • Erze automatisiert gewinnen.
  • Materialien verarbeiten.
  • Metalle und Komponenten lagern.
  • Zwischenprodukte automatisieren.
  • Endprodukte für Raumfahrt bereitstellen.

Create Ore Excavation und andere industrielle Erweiterungen können dabei die Rohstoffbasis deutlich erweitern.

05 // FACTORY REQUIREMENTS

Die Raumfahrtfabrik

Eine Raumfahrtanlage sollte möglichst nicht direkt neben jeder normalen Produktionsmaschine entstehen. Eine eigene Fabrikzone erleichtert Organisation und Erweiterungen.

Empfohlene Bereiche

  • Materiallager.
  • Komponentenproduktion.
  • Montagebereich.
  • Treibstofflager.
  • Kontrollzentrum.
  • Startbereich.
06 // AUTOMATION

Automatisierung der Raumfahrtproduktion

Je komplexer die Raumfahrtkomponenten werden, desto wichtiger wird Automatisierung.

  1. Rohstoffe automatisch zuführen.
  2. Zwischenprodukte automatisch herstellen.
  3. Komponenten zentral lagern.
  4. Endmontage automatisieren.
  5. Fertige Bauteile getrennt lagern.
PROFESSOR TIP

Baue zuerst die Produktionskette für einzelne Komponenten und verbinde sie erst danach zu einer vollständigen Raumfahrtfabrik.

08 // SPACE LOGISTICS

Logistik für ein Raumfahrtprogramm

Raumfahrtanlagen profitieren besonders von sauberer Materiallogistik.

  • Zentrales Komponentenlager.
  • Getrennte Treibstofflager.
  • Automatisierte Item-Transporte.
  • Klare Produktionslinien.
  • Reservebestände für kritische Komponenten.

Bei großen Projekten können Create-Züge als Verbindung zwischen Minen, Fabriken und dem Raumfahrtzentrum dienen.

10 // MULTIPLAYER PROGRAM

Raumfahrt als Gemeinschaftsprojekt

Im Multiplayer kann ein Raumfahrtprogramm zu einem der größten gemeinsamen Projekte des Servers werden.

  • Mining-Team liefert Rohstoffe.
  • Industrie-Team produziert Komponenten.
  • Logistik-Team transportiert Material.
  • Technik-Team baut die Raumfahrtanlage.
  • Expeditionsteam übernimmt Missionen.
MULTIPLAYER PRINCIPLE

Ein großes Raumfahrtprojekt eignet sich besonders gut für Arbeitsteilung, weil zahlreiche unterschiedliche Produktionsschritte benötigt werden.

11 // TROUBLESHOOTING

Fehleranalyse

Eine Komponente fehlt

Öffne das entsprechende Rezept in JEI und verfolge die Produktionskette bis zum fehlenden Rohstoff zurück.

Produktion ist zu langsam

Prüfe zunächst den tatsächlichen Engpass. Häufig fehlt nicht die Endmaschine, sondern ein Zwischenprodukt.

Treibstoffversorgung reicht nicht aus

Überprüfe Produktion, Speicherung und Transport des verwendeten Treibstoffs.

Die Anlage ist zu groß geworden

Teile sie in eigenständige Produktionsmodule und verbinde diese über definierte Logistikwege.

12 // ADVANCED PLANNING

Große Raumfahrtprojekte planen

Bei langfristigen Projekten sollte nicht sofort alles gebaut werden. Erstelle zuerst eine technische Abhängigkeit.

  1. Endziel definieren.
  2. Benötigte Komponenten ermitteln.
  3. Rezepte in JEI untersuchen.
  4. Produktionsketten aufteilen.
  5. Rohstoffbedarf bestimmen.
  6. Fabriken errichten.
  7. Logistik verbinden.
  8. Raumfahrtanlage fertigstellen.
13 // INDUSTRIAL AESTHETICS

Ein Raumfahrtzentrum bauen

Technische Projekte wirken besonders überzeugend, wenn funktionale und dekorative Bereiche miteinander verbunden werden.

  • Große Montagehallen.
  • Kontrollräume.
  • Treibstoffdepots.
  • Wartungsplattformen.
  • Transportgleise.
  • Sicherheitsbereiche.
  • Startplattform.

Dadurch wird die Raumfahrt nicht nur ein Rezeptsystem, sondern ein sichtbarer Teil der Welt.

15 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Raumfahrt als langfristige Produktionskette betrachten.
  • Rohstoffversorgung zuerst stabilisieren.
  • Komponentenproduktion automatisieren.
  • Treibstoff und Logistik separat planen.
  • Startinfrastruktur als eigenes Projekt behandeln.
  • JEI für konkrete Rezepte verwenden.
  • Große Projekte modular aufbauen.
FINAL PRINCIPLE

Der eigentliche Fortschritt bei Create Space beginnt nicht beim Start der Rakete, sondern bei der Fabrik, die überhaupt erst ermöglicht, sie zu bauen.

CREATE ICE CREAMS

Create Ice Creams erweitert Create um ein spezialisiertes Dessert- und Produktionssystem. Zutaten, Verarbeitung und fertige Produkte lassen sich in eine industrielle Lebensmittelproduktion integrieren.

01 // SYSTEM OVERVIEW

Was ist Create Ice Creams?

Create Ice Creams fügt zusätzliche Lebensmittel und Produktionsmöglichkeiten rund um Eiscreme und verwandte Dessertprodukte hinzu.

Durch die Verbindung mit Create kann die Herstellung von einem einfachen Handwerksprozess zu einer automatisierten Produktionslinie ausgebaut werden.

CORE PRINCIPLE

Das interessante Element ist nicht nur das fertige Eis, sondern die Möglichkeit, Zutaten und Verarbeitung in eine vollständige Fabrik einzubauen.

02 // PRODUCTION CHAIN

Die Produktionskette

Eine industrielle Dessertproduktion lässt sich grundsätzlich in mehrere Stufen aufteilen.

  1. Grundzutaten beschaffen.
  2. Zutaten vorbereiten.
  3. Produkte verarbeiten.
  4. Eis beziehungsweise Dessert herstellen.
  5. Produkte lagern.
  6. Produkte transportieren.

07 // AUTOMATION

Automatisierte Produktion

Der größte Vorteil entsteht, wenn die Dessertproduktion ohne ständige manuelle Eingriffe funktioniert.

  • Automatische Zufuhr.
  • Automatische Verarbeitung.
  • Automatische Sortierung.
  • Automatische Lagerung.
  • Kontinuierliche Produktion.
EFFICIENCY WARNING

Eine vollautomatische Anlage sollte nicht größer sein als der tatsächliche Bedarf. Überproduktion verbraucht unnötig Energie, Platz und Ressourcen.

12 // TROUBLESHOOTING

Fehleranalyse

Rezept funktioniert nicht

Öffne das Rezept direkt in JEI und überprüfe, ob die verwendeten Zutaten und der richtige Produktionsweg eingesetzt werden.

Maschine erhält keine Zutaten

Kontrolliere Funnels, Filter, Inventare und die Bewegungsrichtung des Transportsystems.

Produktion steht still

Prüfe zunächst die Versorgung mit Rohstoffen. Danach solltest du Zwischenlager und Ausgangsseite kontrollieren.

Lager läuft über

Produktionsrate reduzieren oder ein größeres beziehungsweise intelligenteres Lagersystem einsetzen.

13 // ADVANCED PRODUCTION

Fortgeschrittene Anlagen

Eine größere Lebensmittelanlage kann verschiedene Produkte parallel herstellen.

  • Gemeinsames Rohstofflager.
  • Getrennte Produktionslinien.
  • Gemeinsamer Transportkorridor.
  • Zentrale Qualitäts- und Lagerkontrolle.
  • Separate Ausgabestationen.

Dabei sollte jede Produktionslinie möglichst unabhängig arbeiten können, damit ein Fehler nicht die komplette Fabrik stilllegt.

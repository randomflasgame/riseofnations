01 // SYSTEM OVERVIEW

Was ist der Roller Fix?

Create Aeronautics verwendet komplexe bewegliche Konstruktionen. Bei solchen Systemen können einzelne Bewegungs- oder Fahrmechaniken Probleme verursachen, obwohl der eigentliche Aufbau korrekt ist.

Der Roller Fix ist eine kleine Support-Erweiterung, die genau solche Probleme innerhalb des Aeronautics-Umfelds adressiert.

CORE PRINCIPLE

Ein Fix-Mod soll möglichst unsichtbar arbeiten: Das eigentliche Gameplay kommt von Aeronautics, während der Fix bestimmte technische Probleme im Hintergrund korrigiert.

02 // CREATE AERONAUTICS

Abhängigkeit vom Hauptsystem

Der Roller Fix ist kein eigenständiges Fahrzeug- oder Transportsystem. Er gehört in das Umfeld von Create Aeronautics und sollte entsprechend als unterstützende Komponente betrachtet werden.

03 // MOVEMENT SYSTEMS

Bewegliche Systeme

Bei Create-basierten Konstruktionen werden Teile eines Aufbaus teilweise als zusammenhängende bewegliche Systeme behandelt.

  • Fahrzeuge.
  • Fluggeräte.
  • Bewegliche Contraptions.
  • Mechanische Plattformen.
  • Transport- und Rollsysteme.

Je komplexer ein solcher Aufbau wird, desto wichtiger ist eine saubere Verarbeitung der Bewegung.

04 // ROLLER MECHANICS

Rollbewegungen und Fahrmechaniken

Rollende Komponenten können für Fahrzeuge, Startsysteme oder andere bewegliche Konstruktionen relevant sein.

Wenn eine solche Komponente nicht korrekt verarbeitet wird, kann das Fahrzeug beispielsweise unerwartet reagieren, sich nicht sauber bewegen oder mit anderen Teilen der Konstruktion interagieren.

ENGINEERING WARNING

Nicht jede Bewegungsstörung wird durch diesen Fix verursacht oder behoben. Bei Problemen sollte zuerst die komplette Konstruktion und anschließend die verwendete Modkombination untersucht werden.

05 // VEHICLE DESIGN

Fahrzeuge richtig planen

Ein funktionierendes Fahrzeug sollte möglichst logisch aufgebaut werden. Besonders bei komplexen Create-Konstruktionen hilft eine klare Trennung zwischen Fahrwerk, Aufbau und technischen Komponenten.

  • Fahrwerk symmetrisch planen.
  • Schwerpunkt berücksichtigen.
  • Bewegliche Komponenten sauber befestigen.
  • Unnötige Konstruktionsteile vermeiden.
  • Fahrwerk vor der Dekoration testen.
06 // TEST PROCEDURE

Testen eines neuen Fahrzeugs

  1. Grundrahmen bauen.
  2. Rollsystem integrieren.
  3. Bewegung ohne Dekoration testen.
  4. Fehlerhafte Komponenten isolieren.
  5. Fahrzeug schrittweise erweitern.
  6. Erst danach optische Details ergänzen.
PROFESSOR METHOD

Je kleiner die Testkonstruktion, desto leichter lässt sich ein Fehler auf eine einzelne Komponente zurückführen.

07 // LARGE CONSTRUCTIONS

Große Fahrzeuge und Maschinen

Bei großen Konstruktionen können mehrere Systeme gleichzeitig aktiv sein. Ein Problem, das bei einem kleinen Fahrzeug kaum auffällt, kann bei einer massiven Konstruktion deutlich stärker auftreten.

  • Große Fahrzeuge modular aufbauen.
  • Fahrwerk getrennt testen.
  • Bewegliche Komponenten dokumentieren.
  • Komplexität schrittweise erhöhen.
08 // MULTIPLAYER

Verwendung auf dem Server

Fahrzeuge und Fluggeräte können auf einem Multiplayer-Server wichtige Transportmittel werden.

  • Öffentliche Transportfahrzeuge.
  • Industrie-Logistik.
  • Militärische Fahrzeuge.
  • Flughafen- und Hafeninfrastruktur.
  • Spielerbasen verbinden.

Bei gemeinsam genutzten Konstruktionen sollte besonders auf Kompatibilität und stabile Modversionen geachtet werden.

09 // PERFORMANCE

Performance beachten

Bewegliche Create-Systeme können mehr Rechenarbeit verursachen als statische Gebäude. Große Fahrzeuge sollten deshalb nicht unnötig kompliziert konstruiert werden.

  • Nur benötigte bewegliche Komponenten verwenden.
  • Sehr große redundante Konstruktionen vermeiden.
  • Fahrzeuge modular planen.
  • Probleme zunächst mit einer kleinen Version reproduzieren.
10 // TROUBLESHOOTING

Fehleranalyse

Fahrzeug rollt nicht

Prüfe zunächst, ob die grundlegende Aeronautics-Konstruktion korrekt aufgebaut wurde und ob alle benötigten Komponenten vorhanden sind.

Fahrzeug bewegt sich unkontrolliert

Konstruktion vereinfachen und einzelne Bewegungs- beziehungsweise Fahrkomponenten nacheinander testen.

Fehler trat erst nach einem Update auf

Versionen von Create, Create Aeronautics und den zugehörigen Kompatibilitätsmods vergleichen.

13 // RISE OF NATIONS APPLICATION

Warum der Fix im Modpack relevant ist

RISE OF NATIONS verwendet Create Aeronautics zusammen mit zahlreichen weiteren Create-Erweiterungen. Dadurch entsteht ein sehr großes technisches Ökosystem.

Kleine Kompatibilitätsmods sind deshalb wichtig: Sie sorgen dafür, dass spezialisierte Systeme gemeinsam in einem großen Modpack betrieben werden können.

14 // PROFESSOR DOCTRINE

Das Wichtigste zum Mitnehmen

  • Der Roller Fix ist eine Support-Komponente.
  • Er erweitert nicht das komplette Aeronautics-System.
  • Er ist für bestimmte Bewegungs- und Rollerprobleme relevant.
  • Eine saubere Fahrzeugkonstruktion bleibt entscheidend.
  • Versionen von Hauptmod und Patch müssen zusammenpassen.
  • Bei Fehlern zuerst mit einer kleinen Testkonstruktion arbeiten.
FINAL PRINCIPLE

Bei technischen Fix-Mods gilt: Wenn ein Problem reproduzierbar ist, sollte zuerst die kleinste mögliche Konstruktion getestet werden. Erst danach lohnt sich die Fehlersuche in einer riesigen Maschine.

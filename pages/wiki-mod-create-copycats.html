COPYCATS

Copycats erweitert das Create-Bausystem um Möglichkeiten, das Aussehen und die Form von Blöcken wesentlich flexibler in mechanische und architektonische Konstruktionen einzubauen. Dadurch lassen sich Maschinen, Fassaden und bewegliche Contraptions deutlich individueller gestalten.

01 // SYSTEM OVERVIEW

Was ist Copycats?

Copycats ist ein Erweiterungsmod für das Create-Umfeld, der das Bauen mit sogenannten Copycat-Blöcken ermöglicht.

Das grundlegende Prinzip besteht darin, dass ein kompatibler Copycat-Block die optische Gestaltung eines anderen Blocks übernehmen kann.

CORE PRINCIPLE

Copycats trennen Funktion und Optik stärker voneinander. Ein technisches Bauteil kann dadurch in eine wesentlich besser passende industrielle oder architektonische Oberfläche integriert werden.

02 // COPYCAT CONCEPT

Das Copycat-Prinzip

Statt für jede mögliche Materialvariante einen eigenen speziellen Block zu benötigen, kann ein Copycat-Block die Oberfläche eines anderen Blocks übernehmen.

SYSTEM FUNKTION
BASE BLOCK funktionaler Copycat-Block
APPEARANCE übernommene Blockoptik
CREATE Integration in technische Konstruktionen

07 // BUILDING WORKFLOW

Empfohlener Bauablauf

Copycats funktionieren am besten, wenn die Gestaltung nicht erst nach dem technischen Aufbau begonnen wird.

  1. Funktion festlegen.
  2. Maschine oder Contraption bauen.
  3. Bewegungsbereiche testen.
  4. Gehäuse planen.
  5. Copycat-Blöcke einsetzen.
  6. Wartung und Zugang berücksichtigen.
  7. Details ergänzen.
BUILDING DOCTRINE

Technik zuerst. Fassade danach. So verhindert man, dass eine schöne Verkleidung später wegen einer beweglichen Maschine wieder abgebaut werden muss.

08 // RESOURCE MANAGEMENT

12 // TROUBLESHOOTING

Fehleranalyse

Copycat sieht nicht wie erwartet aus

Prüfen, ob der gewünschte Block für die entsprechende Copycat- Funktion geeignet ist und ob die Optik korrekt übernommen wurde.

Block funktioniert optisch, aber nicht mechanisch

Copycat-Blöcke sind primär ein Bau- und Darstellungswerkzeug. Die eigentliche Funktion kommt weiterhin vom verwendeten Create-Bauteil.

Problem innerhalb einer Contraption

Die Konstruktion zunächst ohne dekorative Schicht testen. Danach Copycat-Komponenten schrittweise hinzufügen.

Problem nach Update

Create und Copycats gemeinsam auf Versionskompatibilität prüfen.

13 // PERFORMANCE

Performance

Copycats können sehr viele zusätzliche Bauoptionen ermöglichen. Bei extrem großen Konstruktionen sollte trotzdem auf eine vernünftige Anzahl an Blockupdates und beweglichen Contraptions geachtet werden.

  • Große Contraptions modular bauen.
  • Dekoration nicht unnötig übertreiben.
  • Bewegliche Maschinen kompakt halten.
  • Große Fabriken in funktionale Bereiche aufteilen.

01 // SYSTEM OVERVIEW

Create ist eines der zentralen Technik-Systeme von RISE OF NATIONS. Das Mod erweitert Minecraft um mechanische Maschinen, rotierende Kraft, Produktionsanlagen, Transporttechnik, bewegliche Konstruktionen, Logistik und weitreichende Automatisierung.

Der wichtigste Unterschied zu vielen klassischen Tech-Mods: Create zwingt dich nicht einfach dazu, eine Maschine aufzustellen und auf einen Fortschrittsbalken zu warten. Du baust die Maschine selbst. Zahnräder, Wellen, Riemen, Übersetzungen, Antriebe und Transportsysteme müssen räumlich miteinander verbunden werden.

GRUNDPRINZIP: Create denkt in mechanischen Systemen. Wenn du ein Problem hast, solltest du zuerst überlegen: Wo kommt die Kraft her? Wie wird sie übertragen? Was soll sich bewegen? Und wie werden die Materialien transportiert?

02 // DER WICHTIGSTE GRUNDGEDANKE

Fast jede größere Create-Anlage lässt sich auf vier Bestandteile zurückführen:

01 // POWER Eine Quelle erzeugt Rotationsenergie. Beispiele sind Water Wheels, Windmills oder Steam Engines.
02 // TRANSMISSION Shafts, Cogwheels, Belts und ähnliche Komponenten transportieren die Rotation.
03 // PROCESSING Maschinen verwenden die Rotation, um Materialien zu verarbeiten oder Produktionsschritte auszuführen.
04 // LOGISTICS Belts, Funnels, Chutes, Depots, Pipes und andere Systeme bewegen Gegenstände und Flüssigkeiten.

03 // PONDER – DIE INGAME-DOKUMENTATION

Create besitzt ein eigenes Ingame-Dokumentationssystem namens Ponder. Viele Create-Komponenten können direkt im Spiel erklärt werden.

Wenn du einen Create-Gegenstand in JEI untersuchst und eine Ponder-Ansicht verfügbar ist, solltest du diese zuerst öffnen. Sie zeigt häufig Schritt für Schritt, wie eine Mechanik funktioniert.

Ponder ist besonders wichtig, weil Create sehr viele Maschinen besitzt. Statt jedes Rezept auswendig zu lernen, solltest du zuerst die Funktionsweise verstehen.

04 // ROTATION

Rotation ist das Fundament von Create. Eine Anlage funktioniert normalerweise nur dann, wenn sie mit einem passenden rotierenden Antrieb verbunden ist.

Geschwindigkeit

Rotierende Systeme arbeiten mit einer bestimmten Drehgeschwindigkeit. Je nach Maschine und Anwendung kann eine höhere oder niedrigere Drehzahl benötigt werden.

Richtung

Zahnräder können die Drehrichtung ändern. Dadurch lässt sich ein mechanisches Netzwerk gezielt aufbauen.

Übersetzung

Unterschiedlich große Zahnräder ermöglichen es, Drehzahl und Drehmoment innerhalb eines Systems zu verändern.

Eine Anlage sollte nicht einfach immer schneller gemacht werden. Geschwindigkeit, Belastung und die Anforderungen der einzelnen Maschinen müssen zusammenpassen.

05 // STRESS & BELASTUNG

Ein entscheidendes Create-Konzept ist die mechanische Belastung, häufig als Stress bezeichnet.

Eine Energiequelle kann nur eine bestimmte Menge an mechanischer Arbeit bereitstellen. Werden zu viele Maschinen an ein Netzwerk angeschlossen, kann das System überlastet werden.

Deshalb reicht es nicht aus, nur eine Rotationsquelle zu besitzen. Du musst auch darauf achten, wie viel Belastung dein gesamtes Netzwerk erzeugt.

Wenn eine große Fabrik plötzlich nicht mehr funktioniert, überprüfe zuerst dein mechanisches Netzwerk und seine Belastung, bevor du einzelne Maschinen abbaust.

06 // WICHTIGE ANTRIEBE

WATER WHEEL Ein früher und vergleichsweise einfacher Weg, Rotationsenergie zu erzeugen.
WINDMILL Nutzt Windkraft und eignet sich besonders für größere mechanische Anlagen.
STEAM ENGINE Eine leistungsfähige industrielle Energiequelle für fortgeschrittene Produktionsanlagen.
ENGINEERING Fortgeschrittene Anlagen kombinieren mehrere Antriebe, Übersetzungen und Produktionsbereiche.

07 // SHAFTS & COGWHEELS

Shafts übertragen Rotation über größere Distanzen. Sie sind damit die mechanischen Leitungen eines Create-Systems.

Cogwheels verbinden verschiedene Rotationsachsen miteinander. Unterschiedliche Größen ermöglichen mechanische Übersetzungen.

Für große Fabriken empfiehlt sich eine klare Struktur: Hauptantrieb → Übertragung → Maschinenbereich → Produktionslinie.

Baue große Maschinenparks nicht völlig ungeordnet. Eine saubere Trennung zwischen Antrieb und Verarbeitung macht spätere Erweiterungen wesentlich einfacher.

08 // BELTS & ITEM TRANSPORT

Create besitzt ein eigenes Transportsystem für Gegenstände. Besonders wichtig sind Förderbänder und die dazugehörigen Ein- und Ausgabekomponenten.

Dadurch können Produktionslinien gebaut werden, bei denen Items automatisch von einer Maschine zur nächsten transportiert werden.

Typische Produktionslinie

INPUT → TRANSPORT → PROCESSING → TRANSPORT → PROCESSING → OUTPUT

Das ist die Grundlage für automatisierte Fabriken. Je weiter deine Produktion wächst, desto wichtiger wird eine übersichtliche Item-Logistik.

09 // FUNNELS & FILTER

Funnels ermöglichen kontrollierte Übergaben von Items. In Kombination mit Filtern lassen sich Produktionslinien gezielt steuern.

Das ist besonders wichtig, wenn eine Maschine mehrere Materialien verarbeitet oder unterschiedliche Gegenstände an verschiedene Produktionsstationen verteilt werden müssen.

Nutze Filter frühzeitig. Eine saubere Sortierung verhindert, dass später komplette Produktionsanlagen umgebaut werden müssen.

10 // FLÜSSIGKEITEN

Create besitzt ebenfalls Systeme für Flüssigkeiten. Flüssigkeiten können gespeichert, transportiert und in Produktionsprozessen verwendet werden.

Bei komplexeren Anlagen solltest du Flüssigkeitsleitungen getrennt von Item-Transport und mechanischer Rotation planen.

SOURCE → FLUID TRANSPORT → MACHINE → OUTPUT

11 // CONTRAPTIONS

Eine der besonderen Stärken von Create sind sogenannte Contraptions.

Dabei handelt es sich um bewegliche Konstruktionen, die aus Minecraft-Blöcken und Create-Komponenten aufgebaut werden.

Damit lassen sich beispielsweise bewegliche Maschinen, Erntesysteme, Türen, Brücken, Bohrsysteme und andere mechanische Konstruktionen realisieren.

Contraptions sind nicht einfach normale Redstone-Maschinen. Denke in beweglichen mechanischen Konstruktionen.

12 // AUTOMATISIERUNG

Create eignet sich hervorragend für Produktionsketten. Statt jedes Item manuell herzustellen, kannst du mehrere Verarbeitungsschritte miteinander verbinden.

Beispiel einer einfachen Fabrik

MATERIAL ↓ INPUT ↓ MILL / CRUSH / CUT ↓ TRANSPORT ↓ SECONDARY PROCESSING ↓ STORAGE

Das Ziel sollte nicht sein, möglichst viele Maschinen nebeneinander zu stellen. Eine gute Create-Fabrik besitzt einen nachvollziehbaren Materialfluss.

13 // CREATE + JEI

In RISE OF NATIONS ist JEI ein wichtiger Bestandteil der Produktionsplanung.

Verwende JEI, um Rezepte zu finden und anschließend über Ponder beziehungsweise die Create-Dokumentation zu verstehen, wie die benötigte Maschine aufgebaut und betrieben wird.

JEI beantwortet hauptsächlich die Frage: „Was brauche ich?“ Create/Ponder beantwortet zusätzlich: „Wie funktioniert die Maschine?“

14 // PRODUKTIONSPLANUNG

Bei großen Anlagen solltest du zuerst den Produktionsprozess aufschreiben und erst danach bauen.

  • Welche Ressource kommt hinein?
  • Welche Zwischenprodukte entstehen?
  • Welche Maschinen werden benötigt?
  • Wie viel Rotation benötigen die Maschinen?
  • Wie werden Items transportiert?
  • Welche Flüssigkeiten werden benötigt?
  • Wo werden fertige Produkte gespeichert?
  • Kann die Anlage später erweitert werden?
Eine Fabrik, die von Anfang an erweiterbar gebaut wurde, ist langfristig wesentlich wertvoller als eine kompakte Anlage, die später komplett abgerissen werden muss.

15 // HÄUFIGE PROBLEME

Maschine bewegt sich nicht

Prüfe zuerst, ob überhaupt eine gültige Rotationsquelle vorhanden ist und ob die Maschine korrekt mit dem mechanischen Netzwerk verbunden wurde.

Netzwerk überlastet

Prüfe die Belastung des Systems und reduziere entweder die angeschlossenen Maschinen oder erweitere die Energieversorgung.

Items kommen nicht an

Prüfe die Transportrichtung, Übergabepunkte, Filter und die Position der Maschinen.

Produktionslinie produziert nichts

Prüfe den kompletten Ablauf vom Eingangsmaterial bis zum fertigen Produkt. Häufig liegt das Problem nicht an der letzten Maschine, sondern an einem vorherigen Verarbeitungsschritt.

16 // FORTGESCHRITTENE STRATEGIE

Wenn du Create wirklich beherrschen möchtest, solltest du nicht nur einzelne Maschinen lernen.

Das eigentliche Ziel ist, komplette industrielle Systeme zu planen.

  • zentrale Energieversorgung
  • mechanische Hauptleitungen
  • getrennte Produktionsbereiche
  • standardisierte Item-Logistik
  • automatische Materialzufuhr
  • Zwischenlager
  • Endlager
  • erweiterbare Fabrikstruktur

Genau hier wird Create für RISE OF NATIONS besonders interessant: Aus einzelnen Maschinen kann eine komplette industrielle Infrastruktur entstehen.
